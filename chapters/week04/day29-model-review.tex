\section*{一、学习目标}
\begin{enumerate}
  \item 建立“对象、过程、约束、守恒量”的统一解题框架。
  \item 能把复杂题拆成多个阶段，每阶段选择合适模型。
  \item 熟悉高中物理常见模型的适用条件和典型公式。
  \item 学会从题目关键词判断可能使用的物理方法。
  \item 避免公式堆砌，形成可迁移的建模能力。
\end{enumerate}
\section*{二、初高中衔接}

初学物理时，知识按章节出现：运动学、力学、电学、磁学。真正解题时，题目往往不会告诉你“这是第几章”。例如带电粒子在电场中运动，既有电场力，又有运动学；导体棒切割磁感线，既有电磁感应，又有安培力和能量转化。按模型复盘，就是把分散知识重新组织成解题工具箱。

\textbf{科学发展视角：} 真实科技问题通常不是单一章节题。新能源汽车涉及力学、电路、热学和电磁学；医学影像涉及电磁场、粒子运动和数据处理；航天任务同时需要轨道、能量、动量和控制模型。模型复盘的目的，是训练学生从复杂情境中主动选择工具。

\section*{三、核心概念}

\begin{conceptbox}{物理建模的四步}

\begin{enumerate}
  \item \textbf{选对象：} 研究单个物体、系统，还是某个电路回路？
  \item \textbf{分过程：} 运动是否分阶段？条件是否发生变化？
  \item \textbf{找约束：} 绳长不变、轨道约束、闭合回路、电荷守恒等。
  \item \textbf{选规律：} 牛顿定律、能量守恒、动量守恒、场力公式、电路定律等。
\end{enumerate}

\textbf{核心提醒：} 不要一看到速度就只想运动学，不要一看到高度就只想机械能；先看过程中的力、能量、动量和约束是否适用。
\end{conceptbox}

\begin{conceptbox}{方法选择树}

\begin{center}
\input{figures/tikz/method-decision-tree}

\figcaption{方法选择树：题目问法常提示首选模型}\label{fig:method-decision-tree}
\end{center}

\begin{itemize}
  \item 问位移、时间、速度，且加速度已知：优先运动学。
  \item 问加速度、拉力、支持力：优先受力分析和牛顿第二定律。
  \item 问高度、速度、压缩量、最远距离：优先能量。
  \item 碰撞、爆炸、反冲、人船模型：优先动量。
  \item 圆周运动、轨道、最高点最低点：优先径向受力。
  \item 电路稳定量：优先欧姆定律、闭合电路定律和等效电路。
  \item 电磁感应：优先磁通量变化、楞次定律和能量转化。
\end{itemize}
\end{conceptbox}

\section*{四、公式与适用条件}

\textbf{模型选择前检查：}
\nopagebreak[4]
\begin{enumerate}
  \item 先把题目分成“对象、过程、约束、目标”四部分，避免直接套熟悉公式。
  \item 判断主线是力、能量、动量、图像、电路还是场，再选对应模型。
  \item 每次切换模型都要说明适用条件，例如是否守恒、是否匀强、是否理想。
  \item 综合题先画过程图或状态表，再列方程，减少漏条件和重复设未知数。
\end{enumerate}

\section*{五、典型模型}

\subsection*{模型 1：运动学与图像}

若加速度恒定，优先用匀变速公式；若题目给图像，先看斜率和面积：
\[
x\text{-}t\text{ 图像斜率}=v,\qquad
v\text{-}t\text{ 图像斜率}=a,\qquad
v\text{-}t\text{ 有向面积}=\Delta x.
\]

\subsection*{模型 2：受力分析}

受力题先画受力图，再选坐标轴。斜面、圆周、带电粒子题都可以归结为“沿关键方向列牛顿第二定律”。

\subsection*{模型 3：能量和动量}

能量适合处理距离、速度、压缩量；动量适合处理相互作用时间很短或内力远大于外力的过程。两者常组合使用：碰撞前后用动量，碰撞后的运动用能量。

\subsection*{模型 4：场与电路}

静电场和重力场相似：静电力做功与路径无关，因此可以引入电势能。电路题则要先化简连接关系，再分析电源内阻和外电路变化。

\subsection*{模型 5：电磁感应综合}

导体棒题常把三件事连在一起：
\[
E=BLv,\qquad I=\frac{E}{R},\qquad F_A=BIL.
\]
若导体棒速度变化，还要结合牛顿第二定律或能量守恒。

\subsection*{模型 6：跨章节模型切换}

综合题真正的难点常常不是某个公式，而是“何时换模型”。例如小球先下滑、再碰撞、再压缩弹簧，三个阶段的适用规律完全不同。判断切换点时看条件是否改变：是否发生碰撞、是否进入粗糙面、是否进入场区、是否接入电路、是否达到临界状态。

\begin{center}
\input{figures/tikz/model-switching-map}

\figcaption{模型切换：条件改变处就是重新选择规律的地方}\label{fig:model-switching-map}
\end{center}

\textbf{连接量意识：} 上一阶段的结果通常不是最终答案，而是下一阶段的已知量。例如碰前速度、碰后共同速度、最大压缩量、进入磁场速度、回路电流，都可能是“接力棒”。

\subsection*{模型 7：光学、热学和近代物理也要建模}

后几天的光学、热学和近代物理看起来不像传统力学题，但同样要先建模型。光学题先决定用“光线模型”还是“波动模型”；热学题先区分状态量和过程量；近代物理题先看是光子账本、能级跃迁、半衰期统计，还是核反应守恒。

\begin{center}
\input{figures/tikz/model-review-late-topics}

\figcaption{光学、热学和近代物理的模型语言：后段章节同样需要先建模}\label{fig:model-review-late-topics}
\end{center}

\begin{itemize}
  \item \textbf{光学：} 几何光学先画法线、光路和像的位置；波动光学先判断光程差、波长和条纹间距。
  \item \textbf{热学：} 先问“研究对象是哪团气体？”“物质的量是否改变？”“过程是等温、等容、等压还是绝热？”再使用状态方程和第一定律。
  \item \textbf{近代物理：} 光电效应看单个光子能量，能级跃迁看能级差，核反应看质量数、电荷数和能量守恒。
\end{itemize}

\subsection*{模型 8：实验题的测量链条}

实验题看起来像操作步骤，其实也要建模。核心不是“仪器叫什么”，而是先分清：
\[
\text{直接测量量}\rightarrow\text{物理关系或图像关系}\rightarrow\text{目标物理量}.
\]
例如光电门直接测遮光时间 $\Delta t$，要借助 $v\approx d/\Delta t$ 得到瞬时速度；油膜法直接测油膜面积 $S$，要借助 $d\approx V/S$ 估测分子直径；测电源电动势和内阻时，图像纵截距和斜率分别对应 $E$ 和 $-r$。

\begin{center}
\input{figures/tikz/experiment-model-review}

\figcaption{实验模型复盘：把直接读数转化为目标物理量，并检查误差来源}\label{fig:experiment-model-review}
\end{center}

\textbf{方法提醒：} 实验综合题一定要写清“测量量是什么、公式从哪里来、斜率或面积单位是什么、主要误差会让结果偏大还是偏小”。这比背实验步骤更能迁移到新情境。

\section*{六、例题精讲}

\begin{examplebox}{同一道题的模型选择}
\textbf{题意分析：} 一个小物块从光滑斜面高处由静止下滑，到达水平粗糙面后继续滑行，最终停下。问物块在水平面上滑行距离。

\textbf{物理模型：} 斜面段机械能守恒，水平段动能定理。

\begin{center}
\input{figures/tikz/model-review-incline-rough}
\end{center}

\textbf{解题过程：}
斜面光滑，重力势能转化为动能：
\[
mgh=\frac12mv^2.
\]
进入水平粗糙面后，摩擦力做负功使动能减少：
\[
-\mu mg s=0-\frac12mv^2.
\]
联立得
\[
\mu mg s=mgh,\qquad s=\frac{h}{\mu}.
\]

\textbf{方法总结：} 这不是单纯“斜面题”，而是两个阶段：光滑段用机械能守恒，粗糙段用动能定理。
\end{examplebox}

\begin{examplebox}{碰撞后上升高度}
\textbf{题意分析：} 质量为 $m$ 的小球以速度 $v_0$ 撞入质量为 $M$ 的木块并嵌在其中，随后整体沿光滑圆弧上升。求能上升的最大高度。

\textbf{物理模型：} 碰撞时间很短，若水平方向外力冲量可忽略，完全非弹性碰撞可用动量守恒；碰后沿光滑圆弧上升用机械能守恒。

\begin{center}
\input{figures/tikz/model-review-collision-rise}
\end{center}

\textbf{解题过程：}
碰撞极短时间内水平方向动量守恒：
\[
mv_0=(m+M)v.
\]
碰后整体上升：
\[
\frac12(m+M)v^2=(m+M)gh.
\]
所以
\[
h=\frac{v^2}{2g}
=\frac{1}{2g}\left(\frac{m}{m+M}v_0\right)^2.
\]

\textbf{方法总结：} 碰撞过程机械能一般不守恒，但碰撞后的光滑上升过程机械能守恒。
\end{examplebox}

\begin{examplebox}{一题多解：粗糙水平面上的刹停}
\textbf{题意分析：} 质量为 $m$ 的物块以初速度 $v_0$ 在粗糙水平面上滑行，动摩擦因数为 $\mu$。求停止距离。

\textbf{方法一：动能定理。}
摩擦力做功使动能减少：
\[
-\mu mg s=0-\frac12mv_0^2,
\]
所以
\[
s=\frac{v_0^2}{2\mu g}.
\]

\textbf{方法二：牛顿定律加运动学。}
水平方向加速度大小
\[
a=\mu g,
\]
方向与运动相反。取运动方向为正，则
\[
0-v_0^2=2(-\mu g)s,
\]
得到同样结果：
\[
s=\frac{v_0^2}{2\mu g}.
\]

\textbf{方法总结：} 两种方法都对，但视角不同。若题目只问距离且力做功容易表达，能量法更简洁；若还要求时间、加速度或中间速度，牛顿定律和运动学更直接。
\end{examplebox}

\begin{examplebox}{模型切换训练：电场加速后进入磁场}
\textbf{题意分析：} 带电粒子质量为 $m$、电荷量大小为 $q$，从静止经电压 $U$ 加速后垂直进入磁感应强度为 $B$ 的匀强磁场。求磁场中圆周运动半径。

\textbf{模型拆解：} 加速区用电场力做功，磁场区用洛伦兹力提供向心力。

\begin{center}
\input{figures/tikz/model-review-electric-magnetic}
\end{center}

\textbf{解题过程：}
加速区：
\[
|q|U=\frac12mv^2.
\]
磁场区：
\[
|q|vB=\frac{mv^2}{r},\qquad r=\frac{mv}{|q|B}.
\]
由第一式得
\[
v=\sqrt{\frac{2|q|U}{m}},
\]
代入半径式：
\[
r=\frac1B\sqrt{\frac{2mU}{|q|}}.
\]

\textbf{方法总结：} 这里用 $|q|$ 表示电荷量大小，且 $U$ 表示加速电场对粒子做正功对应的电压大小。图中轨迹以正电荷为例；若粒子带负电，偏转方向相反，但半径大小仍由同一公式给出。磁场中的洛伦兹力始终垂直速度，只改变速度方向不改变速率。两个场区的作用不同，必须分阶段处理。
\end{examplebox}

\subsection*{训练提示}
\begin{enumerate}
  \item 当题目涉及两车速度变化、位移差、最大距离时，$v$-$t$ 图像很直观。
  \item 有滑动摩擦并产生耗散时，机械能通常不守恒；但动能定理仍成立，因为它统计所有力做功。
  \item 若要求系统加速度，优先整体法；若要求绳力或相互作用力，需要隔离法。
  \item 加速区用动能定理，偏转区用类平抛分解。
  \item 匀速时合力为 0；能量上外力做功转化为电能和焦耳热。
\end{enumerate}

\section*{八、易错点}
\begin{mistakebox}
\begin{enumerate}
  \item \textbf{公式先行：} 未选对象、未分过程就套公式，容易把不同阶段混在一起。
  \item \textbf{守恒条件不检查：} 机械能守恒、动量守恒都需要满足适用条件。
  \item \textbf{方向正负混乱：} 矢量公式必须先规定正方向。
  \item \textbf{把图像当装饰：} 图像的斜率、面积、交点、截距都有物理意义。
  \item \textbf{综合题不分段：} 条件一变，模型往往也要变。
  \item \textbf{忽略后段章节的模型语言：} 光学不是只画图，热学不是只代公式，近代物理不是只背结论，都要先判断模型和适用条件。
  \item \textbf{把实验当记忆题：} 实验题也要先找直接测量量和间接量，再判断图像斜率、面积或比例关系。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}
\begin{competitionbox}
\textbf{量纲检查}

竞赛和高水平综合题中，量纲检查是非常有用的自检工具。一个表达式若表示速度，量纲必须是
\[
[v]=\mathrm{L}\mathrm{T}^{-1}.
\]
例如 $\sqrt{gh}$ 的量纲为
\[
\sqrt{(\mathrm{L}\mathrm{T}^{-2})\mathrm{L}}=\mathrm{L}\mathrm{T}^{-1},
\]
可以作为速度量出现。

\textbf{极限检查}

得到结果后，令某个参数取极限，看结论是否合理。例如 $s=\dfrac{h}{\mu}$ 中，若 $\mu$ 越大，滑行距离越短；若 $\mu\rightarrow0$，水平面无摩擦，距离趋于无穷大，符合物理直觉。

\textbf{模型意识：} 量纲检查和极限检查不能替代推导，但能快速发现许多不合理答案。
\end{competitionbox}

\subsection*{2.\quad 三类常见“不能直接守恒”}

\begin{enumerate}
  \item \textbf{机械能不守恒：} 滑动摩擦耗散、空气阻力、外力做非保守功或非弹性碰撞。
  \item \textbf{动量不守恒：} 系统外力冲量不可忽略，或研究方向上外力明显。
  \item \textbf{电荷运动不能用匀速：} 存在电场力、磁场力或碰撞阻力时，速度方向或大小可能变化。
\end{enumerate}

\subsection*{3.\quad 多模型题的标注方法}

建议在草稿纸上把题目过程标成
\[
\text{阶段 A}\rightarrow\text{阶段 B}\rightarrow\text{阶段 C}.
\]
每个阶段下面写一句话：
\[
\text{对象是什么？}\quad \text{用什么规律？}\quad \text{连接量是什么？}
\]
所谓连接量，就是上一阶段结果进入下一阶段的物理量，如速度、压缩量、电流、半径等。

\begin{examplebox}{模型判断训练}
\textbf{题意分析：} 小球从高处滑下，与静止木块碰撞后一起压缩弹簧。判断各阶段应使用什么规律。

\textbf{模型拆解：}
\begin{enumerate}
  \item 小球滑下：若轨道光滑，用机械能守恒求碰前速度。
  \item 碰撞瞬间：若碰撞时间很短，水平方向动量守恒。
  \item 共同压缩弹簧：若水平面光滑，用机械能守恒；若粗糙，用功能关系。
\end{enumerate}

\textbf{方法总结：} 一个综合题中，机械能可能在某一段守恒，在另一段不守恒；不要用一个判断覆盖全过程。
\end{examplebox}

\section*{十、今日小结}
\begin{enumerate}[nosep]
  \item 物理建模先选对象、分过程、找约束、选规律。
  \item 运动学、牛顿定律、能量、动量和场模型是高中物理主干。
  \item 光学、热学和近代物理也要按模型处理：光路或波动、状态或过程、光子或能级或核反应。
  \item 实验题要按“直接测量量、模型关系、间接量、误差来源”复盘。
  \item 综合题常需要多个模型按阶段接力。
  \item 守恒规律一定要检查适用条件。
  \item 量纲检查和极限检查是非常重要的答案自检方法。
  \item \textbf{一分钟复盘：} 任选一道综合题，只做模型判断：分几段、每段用什么规律、守恒条件是否满足、最后用什么量纲或极限检查答案。
\end{enumerate}
