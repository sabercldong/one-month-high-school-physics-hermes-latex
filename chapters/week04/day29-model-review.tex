\section*{一、学习目标}
\begin{enumerate}
  \item 能用“对象、过程、约束、目标量”四项整理一道综合题。
  \item 能把复杂题按条件变化拆成多个阶段，并为每阶段选择合适模型。
  \item 能列出高中物理常见模型的适用条件、典型图像、常用关系和失效情形。
  \item 能从对象、过程和约束判断候选物理方法，并说明筛选理由。
  \item 能把一串公式改写成“阶段、规律、连接量”清楚的解题过程。
\end{enumerate}
\section*{二、为什么要做模型复盘}

初学物理时，知识按章节出现：运动学、力学、电学、磁学。实际解题时，题目往往不会标明“这是第几章”。例如带电粒子在电场中运动，既有电场力，又有运动学；导体棒切割磁感线，既有电磁感应，又有安培力和能量转化。按模型复盘，就是把分散知识重新组织成方法系统。

\textbf{科学发展视角：} 真实科技问题通常不是单一章节题。新能源汽车涉及力学、电路、热学和电磁学；医学影像涉及电磁场、粒子运动和数据处理；航天任务同时需要轨道、能量、动量和控制模型。模型复盘的目的，是训练学生从复杂情境中主动选择工具。

\section*{三、模型识别与切换}

\begin{conceptbox}{物理建模的四步}

\begin{enumerate}
  \item \textbf{选对象：} 研究单个物体、系统，还是某个电路回路？
  \item \textbf{分过程：} 运动是否分阶段？条件是否发生变化？
  \item \textbf{找约束：} 绳长不变、轨道约束、闭合回路、电荷守恒等。
  \item \textbf{选规律：} 牛顿定律、能量守恒、动量守恒、场力公式、电路定律等。
\end{enumerate}

\textbf{核心提醒：} 速度、高度、弹簧、碰撞等关键词只能提示候选模型；决定模型选择的是过程中的力、能量、动量和约束条件。
\end{conceptbox}

\begin{conceptbox}{方法选择树}

\begin{center}
\input{figures/tikz/method-decision-tree}

\figcaption{方法选择树：目标量和过程提示候选模型，适用条件决定能否使用}\label{fig:method-decision-tree}
\end{center}

\begin{itemize}
  \item 问位移、时间、速度，且加速度已知：优先运动学。
  \item 问加速度、拉力、支持力：优先受力分析和牛顿第二定律。
  \item 问高度、速度、压缩量、最远距离，且只需联系始末状态：优先考虑能量。
  \item 碰撞、爆炸、反冲、人船模型：优先考虑动量关系。
  \item 圆周运动、轨道、最高点最低点：优先径向受力。
  \item 电路稳定量：优先欧姆定律、闭合电路定律和等效电路。
  \item 电磁感应：优先磁通量变化、楞次定律和能量转化。
\end{itemize}

\textbf{关键词不能代替条件：} 关键词只能提示可能使用的模型，不能直接证明该模型一定适用。决定能否使用某个规律的是条件：
\begin{itemize}
  \item 看到“高度”可以想到能量，但还要检查是否有摩擦、外力或非弹性碰撞。
  \item 看到“碰撞”可以想到动量，但还要检查所选系统在碰撞方向上的外力冲量是否可忽略。
  \item 看到“圆周”可以想到向心力，但还要先判断径向合力由哪些真实力提供。
\end{itemize}

\textbf{认知提醒：} 先用关键词找到候选模型，再用适用条件筛选模型。能说出“为什么能用”和“为什么不能用”，才算完成建模。
\end{conceptbox}

\begin{learningbox}{从题干到模型的四步筛选}
综合题需要先把关键词翻译成对象、过程和条件，再选择公式。可以按下面四步把题干翻译成模型：
\begin{enumerate}
  \item \textbf{先定对象：} 是一个物体、一个系统、一团气体、一个电路，还是一个带电粒子？
  \item \textbf{再看过程：} 是连续运动、碰撞瞬间、进入场区、接通电路，还是状态缓慢变化？
  \item \textbf{检查条件：} 是否光滑、是否匀强、外力冲量是否可忽略、机械能或动量是否守恒？
  \item \textbf{锁定目标量：} 题目要速度、位移、力、电流、能量、时间还是误差方向；目标量会反过来提示最省力的模型。
\end{enumerate}
若四步中有一项发生改变，就在那一点分段，重新选择规律。
\end{learningbox}

\section*{五、一题多解与模型迁移}

\subsection*{模型 1：运动学与图像}

若加速度恒定，优先用匀变速公式；若题目给图像，先看斜率和面积：
\[
x\text{-}t\text{ 图像斜率}=v,\qquad
v\text{-}t\text{ 图像斜率}=a,\qquad
v\text{-}t\text{ 有向面积}=\Delta x.
\]

\subsection*{模型 2：受力分析}

受力题先画受力图，再选坐标轴。斜面、圆周、带电粒子题都可以归结为“沿关键方向列牛顿第二定律”。

\subsection*{模型 3：能量和动量}

能量适合处理距离、速度、压缩量；动量适合处理相互作用时间很短或内力远大于外力的过程。两者常组合使用：碰撞前后用动量，碰撞后的运动用能量。

\subsection*{模型 4：场与电路}

静电场和重力场相似：静电力做功与路径无关，因此可以引入电势能。电路题则要先化简连接关系，再分析电源内阻和外电路变化。

\subsection*{模型 5：电磁感应综合}

导体棒题常把三件事连在一起：
\[
\mathcal E=BLv,\qquad I=\frac{\mathcal E}{R},\qquad F_A=BIL.
\]
这里默认导体棒、速度和磁场方向两两垂直，$R$ 为闭合回路总电阻。若导体棒速度变化，还要结合牛顿第二定律或能量关系。

\subsection*{模型 6：跨章节模型切换}

综合题的难点常常不是某个公式，而是“何时换模型”。例如小球先下滑、再碰撞、再压缩弹簧，三个阶段的适用规律完全不同。判断切换点时看条件是否改变：是否发生碰撞、是否进入粗糙面、是否进入场区、是否接入电路、是否达到临界状态。

\begin{center}
\input{figures/tikz/model-switching-map}

\figcaption{模型切换：条件改变处就是重新选择规律的地方}\label{fig:model-switching-map}
\end{center}

\textbf{连接量意识：} 上一阶段的结果通常不是最终答案，而是下一阶段的已知量。例如碰前速度、碰后共同速度、最大压缩量、进入磁场速度、回路电流，都可能成为连接两个过程的中间量。

\subsection*{模型 7：光学、热学和近代物理也要建模}

前面几节的光学、热学和近代物理与传统力学题的外在形式不同，但同样要先建模型。光学题先决定用“光线模型”还是“波动模型”；热学题先区分状态量和过程量；近代物理题先看是光子能量分析、能级跃迁、半衰期统计，还是核反应守恒。

\begin{center}
\input{figures/tikz/model-review-late-topics}

\figcaption{光学、热学和近代物理的模型语言：非力学问题同样需要先建模}\label{fig:model-review-late-topics}
\end{center}

\begin{itemize}
  \item \textbf{光学：} 几何光学先画法线和光路，再判断反射、折射、全反射或色散；波动光学先判断相干条件、光程差、波长和条纹间距。
  \item \textbf{热学：} 先问“研究对象是哪团气体？”“物质的量是否改变？”“过程是等温、等容、等压还是绝热？”再使用状态方程和第一定律。
  \item \textbf{近代物理：} 光电效应看单个光子能量，能级跃迁看能级差，核反应看质量数、电荷数和能量守恒。
\end{itemize}

\subsection*{模型 8：实验题的测量链条}

实验题表面上是操作步骤，解题时仍然要建模。核心不是记住仪器名称，而是先分清：
\[
\text{直接测量量}\rightarrow\text{物理关系或图像关系}\rightarrow\text{目标物理量}.
\]
例如光电门直接测遮光时间 $\Delta t$，$\ell/\Delta t$ 是宽度为 $\ell$ 的遮光片通过光束期间的平均速度；遮光片足够窄时，才用 $v\approx \ell/\Delta t$ 近似相应位置的瞬时速度。油膜法直接测油膜面积 $S$，要借助 $d\approx V/S$ 估测分子直径；测电源电动势和内阻时，若作 $U$-$I$ 图像，纵截距和斜率分别对应 $E$ 和 $-r$。

\figcaption{实验模型复盘：把直接读数转化为目标物理量，并检查误差来源}\label{fig:experiment-model-review}

\section*{六、例题精讲}

\begin{examplebox}{同一道题的模型选择}
\textbf{题意分析：} 一个小物块从光滑斜面高处由静止下滑，到达固定的水平粗糙面后继续滑行，最终停下。已知物块与水平面间的动摩擦因数为 $\mu$，问物块在水平面上滑行的距离。

\textbf{物理模型：} 斜面段机械能守恒，水平段动能定理。

\begin{center}
\input{figures/tikz/model-review-incline-rough}
\end{center}

\textbf{解题过程：}
斜面光滑，重力势能转化为动能：
\[
mgh=\frac12mv^2.
\]
进入水平粗糙面后，摩擦力做负功使动能减少：
\[
-\mu mg s=0-\frac12mv^2.
\]
联立得
\[
\mu mg s=mgh,\qquad s=\frac{h}{\mu}.
\]

\textbf{方法总结：} 这不是单纯“斜面题”，而是两个阶段：光滑段用机械能守恒，粗糙段用动能定理。
\end{examplebox}

\begin{examplebox}{碰撞后上升高度}
\textbf{题意分析：} 质量为 $m$ 的小球沿水平方向以速度 $v_0$ 撞入静止的、质量为 $M$ 的木块并嵌在其中，随后整体沿光滑圆弧轨道上升。求能上升的最大高度。

\textbf{物理模型：} 碰撞时间很短，若水平方向外力冲量可忽略，完全非弹性碰撞可用动量守恒；碰后沿光滑圆弧上升用机械能守恒。

\begin{center}
\input{figures/tikz/model-review-collision-rise}
\end{center}

\textbf{解题过程：}
碰撞极短时间内水平方向动量守恒：
\[
mv_0=(m+M)v.
\]
碰后整体上升：
\[
\frac12(m+M)v^2=(m+M)gh.
\]
所以
\[
h=\frac{v^2}{2g}
=\frac{1}{2g}\left(\frac{m}{m+M}v_0\right)^2.
\]

\textbf{方法总结：} 碰撞过程机械能一般不守恒，但碰撞后的光滑上升过程机械能守恒。
\end{examplebox}

\begin{examplebox}{一题多解：粗糙水平面上的刹停}
\textbf{题意分析：} 质量为 $m$ 的物块以初速度 $v_0$ 在粗糙水平面上滑行，动摩擦因数为 $\mu$。求停止距离。

\textbf{方法一：动能定理。}
摩擦力做功使动能减少：
\[
-\mu mg s=0-\frac12mv_0^2,
\]
所以
\[
s=\frac{v_0^2}{2\mu g}.
\]

\textbf{方法二：牛顿定律加运动学。}
水平方向加速度大小
\[
a=\mu g,
\]
方向与运动相反。取运动方向为正，则
\[
0-v_0^2=2(-\mu g)s,
\]
得到同样结果：
\[
s=\frac{v_0^2}{2\mu g}.
\]

\textbf{方法总结：} 选方法前先看目标量。若题目只问距离且力做功容易表达，能量法更简洁；若还要求时间、加速度或中间速度，牛顿定律和运动学更直接。
\end{examplebox}

\begin{examplebox}{模型切换训练：电场加速后进入磁场}
\textbf{题意分析：} 带电粒子质量为 $m$、电荷量为 $q$，从静止经电压 $U$ 加速后，以垂直于磁场的速度进入磁感应强度为 $B$ 的匀强磁场。求磁场中圆周运动半径。

\textbf{模型拆解：} 加速区用电场力做功，磁场区用洛伦兹力提供向心力。

\begin{center}
\input{figures/tikz/model-review-electric-magnetic}
\end{center}

\textbf{解题过程：}
加速区：
\[
|q|U=\frac12mv^2.
\]
磁场区：
\[
|q|vB=\frac{mv^2}{r},\qquad r=\frac{mv}{|q|B}.
\]
由第一式得
\[
v=\sqrt{\frac{2|q|U}{m}},
\]
代入半径式：
\[
r=\frac1B\sqrt{\frac{2mU}{|q|}}.
\]

\textbf{方法总结：} 这里用 $|q|$ 表示电荷量大小，且 $U$ 表示加速电场对粒子做正功对应的电压大小。图中轨迹以正电荷为例；若粒子带负电，偏转方向相反，但半径大小仍由同一公式给出。磁场中的洛伦兹力始终垂直速度，只改变速度方向不改变速率。两个场区的作用不同，必须分阶段处理。
\end{examplebox}

\begin{learningbox}{变式训练参考结果}
\begin{enumerate}[itemsep=0.45em,topsep=0.3em,parsep=0pt]
  \item 当题目涉及两物体速度随时间变化、位移差、最近或最远距离时，优先考虑 $v$-$t$ 图像；图线纵坐标之差给出相对速度，图线间的有向面积给出相对位移。
  \item 滑动摩擦把部分机械能转化为内能，因此所选系统的机械能通常不守恒；动能定理是合力总功与动能变化的关系，仍然成立。
  \item 求系统共同加速度时优先用整体法，以消去内力；求绳力或物体间相互作用力时，再隔离相应物体列方程。
  \item 先按场区分过程：若用 $U$ 表示使粒子加速的电压大小，加速区用动能定理 $|q|U=\Delta E_k$；偏转区用类平抛模型分解运动。
  \item 终端匀速时合力为零，外力与安培力平衡；此时动能不再变化，外力的输入功率等于回路的焦耳热功率。
\end{enumerate}
\end{learningbox}

\section*{八、模型边界与极限检验}
\begin{competitionbox}
\textbf{量纲检查}

竞赛和高水平综合题中，量纲检查是重要的结果复核工具。一个表达式若表示速度，量纲必须是
\[
[v]=\mathrm{L}\mathrm{T}^{-1}.
\]
例如 $\sqrt{gh}$ 的量纲为
\[
\sqrt{(\mathrm{L}\mathrm{T}^{-2})\mathrm{L}}=\mathrm{L}\mathrm{T}^{-1},
\]
可以作为速度量出现。

\textbf{极限检查}

得到结果后，令某个参数趋近某个极限，看结论是否合理。例如 $s=\dfrac{h}{\mu}$ 中，若 $\mu$ 越大，滑行距离越短；当 $\mu\rightarrow0^+$ 时，停止距离趋于无穷大。若直接取 $\mu=0$，物块将不再停下，原题“停止距离”也就失去意义。

\textbf{模型意识：} 量纲检查和极限检查不能替代推导，但能快速发现许多不合理答案。
\end{competitionbox}

\subsection*{2.\quad 三类常见“不能直接套用”}

\begin{enumerate}
  \item \textbf{机械能守恒不能直接套用：} 先选定系统；若除重力、弹簧弹力外的力对系统总功不为零，或过程含非弹性碰撞，通常要改用功能关系。
  \item \textbf{动量守恒不能直接套用：} 若所选系统在研究时间内受到的合外力冲量不可忽略，就应使用动量定理，而不能直接令始末总动量相等。
  \item \textbf{匀速直线运动不能直接套用：} 存在电场力、磁场力或碰撞阻力时，速度大小或方向可能变化；仅有磁场洛伦兹力时，速率虽不变，速度方向仍会改变。
\end{enumerate}

\subsection*{3.\quad 多模型题的标注方法}

建议在草稿纸上把题目过程标成
\[
\text{阶段 A}\rightarrow\text{阶段 B}\rightarrow\text{阶段 C}.
\]
每个阶段下面写一行说明：
\[
\text{对象是什么？}\quad \text{用什么规律？}\quad \text{连接量是什么？}
\]
所谓连接量，就是上一阶段结果进入下一阶段的物理量，如速度、压缩量、电流、半径等。

\begin{examplebox}{模型判断训练}
\textbf{题意分析：} 小球从高处滑下，与静止木块碰撞后一起压缩弹簧。判断各阶段应使用什么规律。

\textbf{模型拆解：}
\begin{enumerate}
  \item 小球滑下：若轨道光滑，用机械能守恒求碰前速度。
  \item 碰撞瞬间：若碰撞时间很短且水平方向合外力冲量可忽略，水平方向动量守恒。
  \item 共同压缩弹簧：若水平面光滑，用机械能守恒；若粗糙，用功能关系。
\end{enumerate}

\textbf{方法总结：} 综合题要逐段判断守恒条件。机械能可能在某一段守恒，在另一段不守恒；每换一段过程，都要重新检查摩擦、外力做功和系统边界。
\end{examplebox}

\subsection*{5.\quad 分层训练}

\begin{enumerate}
  \item \textbf{基础：} 固定粗糙面上的滑动摩擦做负功时，物体机械能怎样变化？若是静摩擦或把多个物体选成系统，又为什么必须重新检查研究对象和总功？
  \item \textbf{提高：} 两物体碰撞过程中，为什么常常能用动量守恒，却不能用机械能守恒？
  \item \textbf{综合：} 导体棒在磁场中由静止开始运动，外力恒定，说明速度、电动势、电流、安培力怎样相互影响。

\begin{learningbox}{竞赛补充分层训练参考结果}
\begin{enumerate}[itemsep=0.45em,topsep=0.3em,parsep=0pt]
  \item 若研究对象是物体本身，固定粗糙面对它的滑动摩擦做负功会使其机械能减小；静摩擦可能做正功、负功或不做功，扩大研究系统后摩擦还可能成为内力并使机械能转化为内能，因此必须重新说明系统边界和能量种类。
  \item 碰撞时间很短时外力冲量常可忽略，所以系统动量近似守恒；碰撞中可能发生形变、发热和发声，机械能一般不守恒，只有弹性碰撞才额外满足动能守恒。
  \item 速度增大使 $\mathcal E=BLv$ 增大，继而使 $I=\mathcal E/R$ 和反向安培力增大；加速度逐渐减小，直至安培力与外力平衡并趋于终端速度。
  \item 忽略次要因素可先暴露主导机制、建立可解模型；再按精度需要加入阻力、非匀强、仪表内阻等修正，并用实验检验模型边界。
\end{enumerate}
\end{learningbox}

\section*{九、易错点}
\begin{mistakebox}
\begin{enumerate}
  \item \textbf{公式先行：} 未选对象、未分过程就列式；每个方程前先写对象和阶段。
  \item \textbf{守恒条件不检查：} 机械能、动量守恒都有条件；先选系统，再检查除重力、弹力外的力做功和合外力冲量。
  \item \textbf{方向正负混乱：} 矢量公式必须先规定正方向；先画箭头，再给代数量正负号。
  \item \textbf{忽视图像信息：} 斜率、面积、交点、截距都有物理意义；先标注图像，再列方程。
  \item \textbf{综合题不分段：} 条件一变，模型往往也要变；在条件改变处画分界线。
  \item \textbf{忽略非力学章节的模型语言：} 光学题先画法线、界面或双缝并标传播方向；热学题先写研究对象、过程和符号约定；近代物理题先圈出光子、电子、原子或原子核。完成这些第一步后，再调用公式或结论。
  \item \textbf{把实验当记忆题：} 实验题也要先找直接测量量和间接量，再判断图像斜率、面积或比例关系。
\end{enumerate}
\end{mistakebox}

\section*{十、今日小结}
\begin{enumerate}[nosep]
  \item 物理建模先选对象、分过程、找约束、选规律；每一步都要能在题图或文字中找到依据。
  \item 运动学、牛顿定律、能量、动量和场模型是高中物理主干。
  \item 光学、热学和近代物理也要按模型处理：光路或波动、状态或过程、光子或能级或核反应。
  \item 实验题要按“直接测量量、模型关系、间接量、误差来源”复盘。
  \item 综合题常需要多个模型按阶段连续配合；相邻阶段之间要写清连接量，如速度、位移、电荷量或磁通量变化量。
  \item 使用守恒规律前，先选定系统，再检查除重力、弹力外的力做功或合外力冲量是否可忽略。
  \item 量纲检查和极限检查用于收尾复核：单位不对、极端情况不合理，都说明模型或代数需要回查。
\end{enumerate}

\textbf{一分钟复盘：} 任选一道综合题，画一条阶段线，只做模型判断：每段写对象、规律、连接量、适用条件，最后写一个量纲或极限检查。若某段只能写出公式、说不出适用条件，就回到该模型的基础章节重读。
