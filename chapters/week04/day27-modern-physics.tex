\daytitle{27}{近代物理与原子物理入门}

\begin{learningbox}{本节导读}
近代物理从经典物理解释不了的现象出发：光电效应说明光具有粒子性；原子能级说明原子内部能量不是连续变化；原子核反应说明质量和能量可以相互联系。本节目标不是展开大学量子力学，而是建立“微观世界常常是不连续的、概率性的、守恒约束非常强”的基本认识。
\end{learningbox}

\textbf{本节读题路线：} 光电效应题先区分频率和光强，再用能量守恒写光电方程；能级跃迁题先看能级差，再判断吸收还是辐射；核反应题先守恒质量数和电荷数，再检查能量变化和半衰期信息。

\section*{一、学习目标}
\begin{enumerate}
  \item 能从光电效应实验事实出发说明经典波动观点的困难，并使用爱因斯坦光电方程。
  \item 能说明光子能量 $E=h\nu$、逸出功和截止频率在光电效应中的角色。
  \item 能由卢瑟福 $\alpha$ 粒子散射实验说明原子核式结构模型的证据。
  \item 能由能级差计算光子能量，并用能级跃迁解释原子光谱的离散谱线。
  \item 能读懂玻尔氢原子模型的能级公式，并说明电离能含义。
  \item 会配平核反应方程，并说明质量数和电荷数守恒的检查方法。
  \item 能按比例衰减处理半衰期问题，并说明放射性衰变类型和质能方程的基本意义。
  \item 能说出相对论给出经典物理的适用边界，并说明质能关系的科学意义。
\end{enumerate}
\section*{二、初高中衔接}

前面的光学主要把光看成光线或波。近代物理进一步说明，光在某些现象中必须看成一份一份的光子。前面的能量守恒仍然成立，但微观系统的能量变化常常不是连续的，而是按确定能级差吸收或放出。

\textbf{科学发展视角：} 近代物理的共同特点，是从实验事实反推微观结构和能量规则。光电效应用频率阈值说明光子能量，能级跃迁用谱线反推原子能级，核反应用守恒量和质量亏损判断释放能量。太阳能电池、光谱分析、医学影像和核能技术，都建立在这些“实验事实 + 守恒约束 + 能量量子化”的模型上。

\section*{三、核心概念}

\begin{conceptbox}{卢瑟福 $\alpha$ 粒子散射实验}

在卢瑟福 $\alpha$ 粒子散射实验中，高速 $\alpha$ 粒子射向很薄的金箔。实验现象是：绝大多数 $\alpha$ 粒子几乎沿原方向穿过金箔，少数发生明显偏转，极少数甚至被大角度弹回。

\begin{center}
\input{figures/tikz/rutherford-scattering}

\figcaption{卢瑟福 $\alpha$ 粒子散射：大角度偏转说明原子内部有很小而带正电的原子核}\label{fig:rutherford-scattering}
\end{center}

\textbf{物理结论：} 原子大部分空间是空旷的；原子的正电荷和几乎全部质量集中在很小的原子核内，核外是电子。这就是原子的\textbf{核式结构模型}。

\textbf{认知提醒：} 这个实验不是直接“看见”原子核，而是由散射现象反推内部结构。高中物理经常用这种方式建立微观模型：看不见对象本身，就看它对可测粒子的影响。
\end{conceptbox}

\begin{conceptbox}{能量量子化与光子}

经典图像中，能量常被想象成可以连续取任意数值；近代物理发现，微观系统吸收或放出能量时，常常表现出“一份一份”的特征。对光来说，每一份能量叫一个\textbf{光子}，其能量为
\[
\boxed{E=h\nu}.
\]
频率 $\nu$ 越高，单个光子的能量越大；在频率相同的比较中，光强越大，通常表示单位时间到达的光子数越多。这个区分是理解光电效应的关键。

\begin{center}
\input{figures/tikz/quantum-energy-packets}

\figcaption{能量量子化与光子：频率决定单个光子能量；同频率下，光强主要影响光子数}\label{fig:quantum-energy-packets}
\end{center}
\end{conceptbox}

\textbf{科学史补充：黑体辐射与量子化思想}

能量量子化思想最早不是从光电效应开始的，而是来自黑体辐射问题。加热物体会发光，温度越高，辐射越强，辐射峰值还会向短波方向移动。经典物理若把能量交换看成完全连续，无法正确解释短波端的实验规律。普朗克提出：物质与电磁辐射交换能量时，只能按
\[
E=h\nu
\]
这样的“一份一份”进行。后来爱因斯坦把这种思想用于光电效应，进一步提出光本身也可以看作一份一份的光子。

\begin{center}
\input{figures/tikz/blackbody-quantum-origin}

\figcaption{黑体辐射与量子化思想：温度升高时峰值向短波移动，经典连续图像在短波端失效}\label{fig:blackbody-quantum-origin}
\end{center}

\textbf{学习边界：} 本讲义先让学生知道黑体辐射是量子化思想的重要来源，暂不计算普朗克辐射公式。现阶段重点看实验事实：温度升高时峰值向短波移动，经典连续能量图像在短波端失效。

\begin{conceptbox}{光电效应}

用一定频率的光照射金属表面，金属中电子吸收光子能量后可能逸出，形成光电子。对同一种金属而言，能否发生光电效应主要由入射光频率是否达到截止频率决定，而不是由光强单独决定。

\textbf{从实验事实到模型：}
\begin{enumerate}
  \item 存在\textbf{截止频率}：频率低于某一数值时，光再强也不能打出光电子。
  \item 光电子几乎\textbf{立即逸出}：当频率达到或超过截止频率并能发生光电效应时，弱光也不需要长时间“积累能量”。
  \item 光电子最大初动能随\textbf{频率}增大而增大。
  \item 在频率不变且已能发生光电效应时，增大光强主要增大光电流，说明逸出的电子数增多。
\end{enumerate}
这些事实说明：光的能量不是连续平均分给许多电子，而是以光子为单位被电子吸收。高中普通光电效应模型中，可把一个电子主要看作吸收一个光子的能量。

\[
\boxed{h\nu=W_0+E_{k\max}}
\]

这条式子可以看成微观世界的能量核算：一个光子的能量先用于把电子从金属中“拉出来”，这部分能量叫逸出功；如果还有剩余，才表现为光电子的最大初动能。因此频率不够时，即使光很强，也只能增加照来的光子数，不能让单个光子具有更大的能量。

\begin{center}
\input{figures/tikz/photoelectric-effect}

\figcaption{光电效应：一个光子的能量被一个电子吸收}\label{fig:photoelectric-effect}
\end{center}

\begin{itemize}
  \item $h\nu$：光子能量。
  \item $W_0$：金属逸出功。
  \item $E_{k\max}$：逸出光电子的最大初动能。
  \item 截止频率满足 $h\nu_0=W_0$。
\end{itemize}
\end{conceptbox}

\begin{conceptbox}{原子能级}

原子只能处在一系列特定能量状态中，这些能量状态叫能级。原子吸收或放出光子时，能量变化满足
\[
\boxed{h\nu=|E_m-E_n|}.
\]

\begin{center}
\input{figures/tikz/energy-level-transition}

\figcaption{原子能级跃迁：能级差决定吸收或放出光子的频率}\label{fig:energy-level-transition}
\end{center}

\textbf{理解：} 能级不是电子绕核运动的普通轨道线，而是原子允许具有的能量状态。能级差不同，发出的光频率不同，于是形成特征光谱。
\end{conceptbox}

\begin{conceptbox}{原子核与核反应}

原子核由质子和中子组成。核反应方程必须满足两个守恒：
\[
\boxed{\text{质量数守恒}},\qquad
\boxed{\text{电荷数守恒}}.
\]

\begin{center}
\input{figures/tikz/nuclear-reaction-balance}

\figcaption{核反应方程：配平的核心是质量数和电荷数守恒}\label{fig:nuclear-reaction-balance}
\end{center}

常见符号：
\[
{}^4_2\mathrm{He}\quad(\alpha\text{ 粒子}),\qquad
{}^0_{-1}e\quad(\beta^-\text{ 粒子}),\qquad
{}^1_0n\quad(\text{中子}).
\]
\end{conceptbox}

\begin{conceptbox}{半衰期}

大量同种放射性原子核中，未衰变原子核数减少到原来一半所需的时间叫半衰期。半衰期是统计规律，不是说某一个原子核到时间一定衰变。

\textbf{公式使用前检查：}
\nopagebreak[4]
\begin{enumerate}
  \item 先判断研究对象是光子、电子、原子还是原子核，能量公式各不相同。

\section*{五、典型模型}

\textbf{三类能量核算：} 近代物理题涉及公式较多，但核心仍是能量守恒。先判断是哪一类过程，再写对应的能量关系：
\begin{itemize}
  \item \textbf{光电效应：} 一个光子的能量先支付逸出功，剩余部分成为光电子最大初动能。
  \[
  h\nu=W_0+E_{k\max}.
  \]
  \item \textbf{能级跃迁：} 原子能级差全部对应一个光子的能量，向下跃迁放光，向上跃迁吸光。
  \[
  h\nu=|E_m-E_n|.
  \]
  \item \textbf{核反应：} 先用质量数、电荷数守恒配平方程，再用质量亏损判断释放或吸收的能量。
  \[
  E_{\text{释放}}=\Delta m c^2.
  \]
\end{itemize}

\textbf{认知提醒：} 三类题都不是“套一个新公式”而已。先说清输入能量在哪里、输出能量在哪里、哪些量必须守恒，再进入计算，错误会少很多。

\subsection*{模型 1：光电效应判断}

先比较频率：
\[
\nu<\nu_0\Rightarrow\text{在高中普通光电效应模型中不能逸出光电子},
\]
\[
\nu\ge\nu_0\Rightarrow\text{能发生光电效应；等号时光电子刚好逸出}.
\]
在频率不变且已能发生光电效应时，光强增大主要增加单位时间逸出电子数，不会改变单个光子的能量。

\begin{center}
\input{figures/tikz/photoelectric-frequency-intensity}

\figcaption{光电效应判断：是否逸出先看频率，光强主要影响光电子数}\label{fig:photoelectric-frequency-intensity}
\end{center}

\subsection*{模型 2：能级跃迁}

向高能级跃迁需要吸收光子；向低能级跃迁会放出光子。光子频率由能级差决定：
\[
\nu=\frac{|E_m-E_n|}{h}.
\]

\begin{center}
\input{figures/tikz/spectral-lines-from-levels}

\figcaption{能级跃迁与光谱：不同能级差对应不同频率的谱线}\label{fig:spectral-lines-from-levels}
\end{center}

\subsection*{模型 3：由散射现象反推原子结构}

卢瑟福散射实验体现了一种重要建模方法：先看实验事实，再反推结构。
\begin{itemize}
  \item 绝大多数粒子直穿：说明原子内部大部分空间空旷。
  \item 少数粒子明显偏转：说明原子内部存在强电场区域。
  \item 极少数粒子大角度反弹：说明正电荷和质量集中在很小的区域内。
\end{itemize}

\textbf{模型边界：} 核式结构模型解释了原子核的存在，但不能单独解释原子稳定性和光谱线。玻尔模型进一步引入能级量子化，才解释了氢原子光谱。

\subsection*{模型 4：玻尔氢原子模型}

氢原子只有一个电子，是高中阶段理解原子能级最常用的模型。玻尔模型的核心不是“电子真的像行星一样沿确定轨道转”，而是给出一个可计算的能级结构：
\[
E_n=-\frac{13.6}{n^2}\ \mathrm{eV},\qquad n=1,2,3,\cdots
\]

\begin{center}
\input{figures/tikz/bohr-hydrogen-levels}

\figcaption{玻尔氢原子模型：能级越高越接近 $0$，跃迁能级差决定谱线}\label{fig:bohr-hydrogen-levels}
\end{center}

\begin{itemize}
  \item $n=1$ 是基态，能量最低，$E_1=-13.6\ \mathrm{eV}$。
  \item $n$ 越大，能级越高，能量越接近 $0$。
  \item 从 $n=1$ 电离到自由电子，需要吸收 $13.6\ \mathrm{eV}$ 能量。
  \item 从高能级向低能级跃迁时，放出光子；光子能量为两个能级之差。
\end{itemize}

\textbf{模型边界：} 玻尔模型能很好解释氢原子光谱，但它不是完整的量子力学图像。高中阶段把它作为“能级量子化”的入门模型，不把图中的圆轨道理解成电子的真实路径。

\subsection*{模型 5：核反应配平}

未知粒子可通过质量数、电荷数分别列方程判断。例如
\[
{}^{14}_{7}\mathrm{N}+{}^4_2\mathrm{He}\rightarrow{}^{17}_{8}\mathrm{O}+X.
\]
质量数：$14+4=17+A_X$，得 $A_X=1$；电荷数：$7+2=8+Z_X$，得 $Z_X=1$，所以
\[
X={}^1_1\mathrm{H}.
\]

\subsection*{模型 6：放射性衰变与射线防护}

放射性衰变是原子核自发发生的变化，常见射线可先按“带不带电、穿透强弱、核反应方程怎样变”来识别：
\begin{itemize}
  \item \textbf{$\alpha$ 衰变：} 放出 ${}^4_2\mathrm{He}$ 原子核，母核质量数减 4，电荷数减 2。
  \item \textbf{$\beta^-$ 衰变：} 放出电子 ${}^0_{-1}e$，母核质量数不变，电荷数加 1。更完整地说，核内一个中子转化为质子，同时放出电子和反中微子 $\bar{\nu}_e$；反中微子的质量数和电荷数都为 0，高中配平方程时常不显式写出。
  \item \textbf{$\gamma$ 射线：} 本质是高能光子，常伴随核反应或衰变释放，通常不改变质量数和电荷数。
\end{itemize}

\begin{center}
\input{figures/tikz/radioactive-decay-shielding}

\figcaption{三种常见射线：穿透能力不同，防护材料也不同}\label{fig:radioactive-decay-shielding}
\end{center}

\textbf{科学素养提醒：} 放射性不是“只要有辐射就一定危险”。风险取决于射线类型、活度、距离、屏蔽和照射时间。医学影像、放射治疗、工业探伤和考古测年都利用了核辐射，但必须在剂量控制和防护条件下使用。

\section*{六、例题精讲}

\begin{examplebox}{光电效应最大初动能}
\textbf{题意分析：} 某金属逸出功 $W_0=2.0\ \mathrm{eV}$，用光子能量为 $3.5\ \mathrm{eV}$ 的光照射，求光电子最大初动能。

\textbf{物理模型：} 爱因斯坦光电方程。

\begin{center}
\input{figures/tikz/photoelectric-energy-account}
\end{center}

\textbf{解题过程：}
\[
E_{k\max}=h\nu-W_0=3.5-2.0=1.5\ \mathrm{eV}.
\]

\textbf{方法总结：} 光电效应题先看光子能量是否达到逸出功，再算最大初动能。
\end{examplebox}

\begin{examplebox}{能级跃迁发光频率}
\textbf{题意分析：} 原子从 $E_3=-1.5\ \mathrm{eV}$ 跃迁到 $E_1=-13.6\ \mathrm{eV}$，求放出光子的能量。

\textbf{物理模型：} 能级差等于光子能量。

\begin{center}
\input{figures/tikz/energy-level-example}
\end{center}

\textbf{解题过程：}
\[
E_{\gamma}=E_3-E_1=(-1.5)-(-13.6)=12.1\ \mathrm{eV}.
\]

\textbf{方法总结：} 能级题先判断吸收还是辐射，再用高能级减低能级；光子能量取正值。
\end{examplebox}

\begin{examplebox}{氢原子能级跃迁}
\textbf{题意分析：} 氢原子从 $n=3$ 能级跃迁到 $n=2$ 能级，求放出光子的能量。

\textbf{物理模型：} 玻尔氢原子能级公式。

\textbf{解题过程：}
\[
E_3=-\frac{13.6}{3^2}\ \mathrm{eV}\approx-1.51\ \mathrm{eV},
\qquad
E_2=-\frac{13.6}{2^2}\ \mathrm{eV}=-3.40\ \mathrm{eV}.
\]
从高能级降到低能级，光子能量为
\[
E_{\gamma}=E_3-E_2=(-1.51)-(-3.40)=1.89\ \mathrm{eV}.
\]

\textbf{方法总结：} 氢原子能级是负值，越接近 $0$ 能级越高。放光时用“初能级减末能级”，结果取正。
\end{examplebox}

\begin{examplebox}{半衰期计算}
\textbf{题意分析：} 某放射性样品初始有 $N_0$ 个未衰变原子核，半衰期为 5 天。经过 15 天后剩余多少？

\textbf{物理模型：} 每过一个半衰期剩余一半。

\begin{center}

\textbf{解题过程：}
15 天包含 $\dfrac{15}{5}=3$ 个半衰期，所以

\subsection*{训练提示}
\begin{enumerate}
  \item 先比较入射光频率和截止频率。若频率低于截止频率，单个光子能量不足，不能发生光电效应。
  \item 先固定频率再看光强。在频率不变且已能发生光电效应时，最大初动能不变；光强增大主要使光电子数增多。
  \item 先用反证想象均匀原子模型。若原子内部到处都是均匀物质和正电荷，高速 $\alpha$ 粒子应普遍受阻或偏转；大量直穿说明原子内大部分区域几乎不阻挡它。
  \item 先判断跃迁方向。从高能级到低能级放出光子，从低能级到高能级吸收光子。
  \item 先取能级差的绝对值：$E_2=-3.40\ \mathrm{eV}$，$E_1=-13.6\ \mathrm{eV}$，放出光子能量 $10.2\ \mathrm{eV}$。
  \item 先分别配平质量数和电荷数；质量数差为 4，电荷数差为 2，所以 $X={}^{4}_{2}\mathrm{He}$。
  \item 先看守恒量。$\beta^-$ 衰变中质量数不变，电荷数增加 1。
\end{enumerate}

\section*{八、易错点}
\begin{mistakebox}
\begin{enumerate}
  \item \textbf{认为光强越大一定能打出电子：} 先看频率是否达到截止频率，再讨论光强影响电子数。
  \item \textbf{混淆光强和光子能量：} 先用 $E=h\nu$ 判断单个光子能量；频率不变时，光强增大主要表示光子数增多。
  \item \textbf{把卢瑟福实验当成直接拍到原子核：} 先看实验事实：少数 $\alpha$ 粒子发生大角度偏转；原子核式结构是由散射规律反推出来的模型。
  \item \textbf{能级差符号处理错误：} 先判断吸收还是辐射，再取两个能级差的绝对值作为光子能量。
  \item \textbf{把氢原子能级负号看成“能量大小为负”：} 负号表示电子被原子核束缚，能量零点取在电离后的自由电子状态；比较光子能量时看能级差。
  \item \textbf{核反应只配质量数：} 先配质量数，再配电荷数，两条守恒都满足后再判断粒子种类。
  \item \textbf{把 $\alpha$、$\beta$、$\gamma$ 射线混为一谈：} 先分别检查组成、带电情况和穿透能力；$\alpha$、$\beta$、$\gamma$ 不是同一种粒子或射线。
  \item \textbf{把半衰期用于单个原子核：} 半衰期是大量原子核的统计规律。
  \item \textbf{把 $E=mc^2$ 当成普通机械能公式：} 质能关系来自相对论，常用于静能量、质量亏损和核能释放，不是低速物体动能的替代公式。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}
\begin{competitionbox}
\textbf{德布罗意物质波}

近代物理的一个重要思想是波粒二象性：光有粒子性，微观粒子也有波动性。德布罗意提出，动量为 $p$ 的粒子对应波长
\[
\lambda=\frac{h}{p}.
\]

\textbf{为什么宏观物体看不出波动性？}
宏观物体动量很大，所以对应波长极小，远小于可观察尺度。电子等微观粒子动量小，波长可与原子尺度相当，因此会表现出衍射和干涉。

\begin{center}
\input{figures/tikz/debroglie-diffraction}
\end{center}

\textbf{连接前后知识：} 这一公式把动量 $p$、普朗克常量 $h$ 和波长 $\lambda$ 联系起来，是从经典物理走向量子物理的桥梁。
\end{competitionbox}

\subsection*{1.\quad 光电效应实验装置}

光电效应不能只理解为“电子飞出金属表面”，还要通过光电流、电压和光照条件的关系来判断微观过程。实验中用光照射阴极，若有光电子逸出并到达阳极，外电路中就出现光电流。

\begin{center}
\input{figures/tikz/photoelectric-experiment}

\figcaption{光电效应实验装置：用光电流和外加电压研究光电子能量}\label{fig:photoelectric-experiment}
\end{center}

\textbf{实验事实到方程：} 截止电压说明最快光电子的初动能可被反向电场刚好“耗尽”。若 $U_c$ 表示截止电压的大小，则
\[
eU_c=E_{k\max}.
\]
改变入射光频率，发现 $E_{k\max}$ 随频率线性增大，由此得到
\[
h\nu=W_0+E_{k\max}.
\]

\subsection*{2.\quad 光电效应伏安曲线}

光电效应实验不仅能说明“有无光电子”，还可以通过伏安曲线研究光电子最大初动能和单位时间逸出电子数。

\begin{center}
\input{figures/tikz/photoelectric-ui-graph}

\figcaption{光电效应伏安曲线：截止电压和饱和电流对应不同物理意义}\label{fig:photoelectric-ui-graph}
\end{center}

\begin{itemize}
  \item \textbf{截止电压：} 使光电流刚好为 0 的反向电压；若 $U_c$ 取其大小，则满足 $eU_c=E_{k\max}$。
  \item \textbf{饱和电流：} 在理想收集条件下，逸出的光电子几乎都被收集时的电流，反映单位时间逸出电子数。
  \item \textbf{光强影响：} 同频率下，光强越大，饱和电流越大；但截止电压不因光强增大而增大。
\end{itemize}

\subsection*{3.\quad 相对论初步：经典物理的适用边界}

牛顿力学在日常低速世界非常准确，但当速度接近光速 $c$，或者讨论核反应中的质量亏损时，经典图像就不够用了。相对论给出两个重要提醒：
\begin{itemize}
  \item 真空中的光速 $c$ 是自然界的重要上限，静止质量不为零的物体不能被加速到光速或超过光速。
  \item 质量和能量不是彼此孤立的量，静止物体也具有静能量 $E=mc^2$。
\end{itemize}

\subsection*{4.\quad 核能释放的数量级}

核反应中的质量亏损通常很小，但由于
\[
c^2\approx9.0\times10^{16}\ \mathrm{m^2/s^2},
\]
即使很小的质量亏损也可能对应巨大的能量。这解释了为什么核裂变和核聚变能释放远高于普通化学反应的能量。

\textbf{严谨提醒：} 质量亏损不是“质量消失了所以不守恒”的简单说法。更准确地说，在相对论中质量和能量共同参与守恒，核反应前后的总能量守恒。

\subsection*{5.\quad 核裂变与核聚变：两种释放核能的路径}

质能方程说明“为什么核反应可能释放巨大能量”，但高中还需要区分两类典型核反应。

\begin{center}
\input{figures/tikz/fission-fusion-model}

\figcaption{核裂变与核聚变：前者是重核分裂，后者是轻核结合}\label{fig:fission-fusion-model}
\end{center}

\begin{itemize}
  \item \textbf{核裂变：} 重核吸收中子后分裂成较轻的原子核，同时放出若干中子和能量。若新放出的中子继续引发其他裂变，就可能形成链式反应。核电站利用可控裂变释放能量。
  \item \textbf{核聚变：} 轻核在极高温、高压条件下结合成较重的原子核，并释放能量。太阳和恒星的能量主要来自聚变。受控核聚变的难点在于如何长时间稳定约束高温等离子体。
\end{itemize}

\textbf{统一视角：} 不论裂变还是聚变，计算释放能量时都回到质量亏损：
\[
E_{\text{释放}}=\Delta m\,c^2.
\]
核反应方程仍必须满足质量数守恒、电荷数守恒；能量释放不表示守恒失效，而是质量和能量共同参与守恒。

\begin{examplebox}{截止电压与最大初动能}
\textbf{题意分析：} 某光电管实验中，截止电压大小为 $1.2\ \mathrm{V}$。求光电子最大初动能（用 eV 表示）。

\textbf{物理模型：} 反向电场做功恰好阻止最快光电子到达阳极。

\textbf{解题过程：}
\[
E_{k\max}=eU_c.
\]
若用电子伏特作单位，电荷量大小为 $e$ 的电子通过 $1\ \mathrm{V}$ 电势差对应 $1\ \mathrm{eV}$，所以
\[
E_{k\max}=1.2\ \mathrm{eV}.
\]

\textbf{方法总结：} 光电效应计算先选单位体系；用 eV 时逸出功、光子能量和最大初动能都要统一用 eV。
\end{examplebox}

\begin{examplebox}{核反应方程补全}
\textbf{题意分析：} 补全核反应：
\[
{}^{27}_{13}\mathrm{Al}+{}^4_2\mathrm{He}\rightarrow{}^{30}_{15}\mathrm{P}+X.
\]

\textbf{物理模型：} 质量数守恒、电荷数守恒。

\textbf{解题过程：}
质量数：
\[
27+4=30+A_X,\qquad A_X=1.
\]
电荷数：
\[
13+2=15+Z_X,\qquad Z_X=0.
\]
所以
\[
X={}^1_0n.
\]

\textbf{方法总结：} 未知粒子先用质量数 $A$ 和电荷数 $Z$ 守恒求出自己的 $A,Z$，再对照常见粒子（中子、质子、$\alpha$ 粒子、电子）识别名称；不要先凭符号猜。
\end{examplebox}

\section*{十、今日小结}
\enlargethispage{3\baselineskip}
\begin{enumerate}
  \item 能量量子化说明：微观能量交换常以一份一份的形式发生。
  \item 光电效应说明光具有粒子性，光子能量由频率决定，$E=h\nu$。
  \item 光电方程为 $h\nu=W_0+E_{k\max}$，截止频率满足 $h\nu_0=W_0$。
  \item 卢瑟福 $\alpha$ 粒子散射实验说明原子具有核式结构：正电荷和几乎全部质量集中在很小的原子核内。
  \item 原子能级跃迁满足 $h\nu=|E_m-E_n|$。
  \item 氢原子玻尔模型中 $E_n=-13.6/n^2\ \mathrm{eV}$，基态电离能为 $13.6\ \mathrm{eV}$。
  \item 核反应方程必须满足质量数守恒和电荷数守恒。
  \item $\alpha$、$\beta$、$\gamma$ 射线的组成和穿透能力不同，防护方式也不同。
  \item 半衰期是大量原子核衰变的统计规律。
  \item 相对论说明：牛顿力学有适用范围，质能关系 $E=mc^2$ 解释了核能数量级。
  \item 核裂变是重核分裂，核聚变是轻核结合，二者释放能量都可用质量亏损理解。
\end{enumerate}

\textbf{一分钟复盘：} 把光电效应、能级跃迁和核反应各写成一条“输入能量 $\to$ 输出形式”的关系，并在每条后面补一句守恒条件或边界条件。
