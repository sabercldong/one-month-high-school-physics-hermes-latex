\daytitle{25}{光学基础}

\begin{learningbox}{本节导读}
本节先建立“光线模型”：反射、折射、折射率、全反射和凸透镜成像；再用双缝干涉把光从“几何光学”推进到“波动光学”。学习顺序是：先会画光路图，再由几何关系写公式，最后理解光既可像直线传播，也可表现出波动性。
\end{learningbox}

\textbf{本节读题路线：} 几何光学题先画界面和法线，再标角度；折射题先判断光速变快还是变慢，再用折射定律计算；透镜题先用特殊光线判断像的性质，再考虑公式；干涉题先看条纹间距受 $L$、$\lambda$、$d$ 哪个量影响。

\section*{一、学习目标}
\begin{enumerate}
  \item 能画出反射、折射光路，并使用折射定律和折射率判断光线偏折。
  \item 会先判断光从光疏到光密还是从光密到光疏，再预判光线靠近或远离法线。
  \item 能判断全反射条件，并使用临界角公式。
  \item 会用凸透镜光路图分析成像性质，并能联系照相机、人眼、放大镜等光学仪器。
  \item 能说明光的频率、波长、波速和颜色之间的基本关系。
  \item 能用双缝干涉公式判断条纹间距与波长、缝距、屏距的关系，并能先统一单位再计算。
  \item 能用典型现象说明薄膜干涉、衍射和偏振体现的光的波动性。
\end{enumerate}
\section*{二、初高中衔接}

初中学习光学时，重点是反射、折射、凸透镜成像现象。高中要更精确地处理三个问题：角度必须相对于法线来量；折射率反映光速在介质中的变化；光路图不仅是画图题，也是建立几何关系的工具。

\textbf{科学发展视角：} 光学不只服务于眼镜和照相机。光纤通信依赖全反射，显微镜和望远镜依赖透镜成像，芯片光刻和干涉测量要考虑波长、干涉和衍射。学习本节时，先用光线模型解决成像和折射，再用波动模型解释干涉、衍射和分辨率。

\section*{三、核心概念}

\begin{conceptbox}{反射与折射}

光遇到两种介质的分界面时，一部分返回原介质形成反射光，一部分进入另一介质形成折射光。

\[
\boxed{i=i'},\qquad
\boxed{n_1\sin i=n_2\sin r}.
\]

\begin{center}
\input{figures/tikz/reflection-refraction}

\figcaption{反射和折射：入射角、反射角、折射角都相对于法线测量}\label{fig:reflection-refraction}
\end{center}

\begin{itemize}
  \item $i$：入射角；$i'$：反射角；$r$：折射角。
  \item 光从光疏介质进入光密介质，折射光线靠近法线。
  \item 光从光密介质进入光疏介质，折射光线远离法线。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{光路可逆性}

在同一组静止介质和光学元件中，如果光可以沿某条路径从 $A$ 到 $B$，那么从 $B$ 沿相反方向入射，也会沿原路径返回 $A$。这叫\textbf{光路可逆性}。

\begin{center}
\input{figures/tikz/optical-reversibility}

\figcaption{光路可逆性：同一条折射光路反向传播时仍满足相同的折射定律}\label{fig:optical-reversibility}
\end{center}

\textbf{学习意义：} 画反射、折射和透镜成像图时，可以用光路可逆性检查图像是否合理。例如从物点到像点的光线若画对了，反向从像点出发也应沿同一路径回到物点。

\textbf{模型边界：} 光路可逆性讨论的是理想几何光学中的传播路径；遇到吸收、散射或特殊单向光学器件时，实际强度和路径可能不再简单可逆。高中阶段通常只在反射、折射、透镜和光纤等理想模型中使用。

\end{conceptbox}

\begin{conceptbox}{折射率}

介质的绝对折射率定义为
\[
\boxed{n=\frac{c}{v}},
\]
其中 $c$ 是真空中光速，$v$ 是光在介质中的传播速度。

\begin{itemize}
  \item $n$ 越大，光在该介质中传播越慢。
  \item 真空折射率为 1，空气折射率通常近似取 1。
  \item 折射率不是“光线弯曲程度”的直接定义；折射角由两种介质的折射率和入射角共同决定。
\end{itemize}

\begin{center}
\input{figures/tikz/refraction-speed-wavefront}

\figcaption{折射率与光速：进入折射率更大的介质时，光速变小，光线靠近法线}\label{fig:refraction-speed-wavefront}
\end{center}

\textbf{频率、波长与颜色：}
光也是波，满足
\[
v=\lambda f.
\]
同一束光从一种介质进入另一种介质时，频率 $f$ 由光源决定，通常不变；传播速度 $v$ 改变，所以波长 $\lambda$ 随之改变。进入折射率更大的介质时，$v$ 变小，$\lambda$ 也变短。可见光的颜色主要由频率决定，所以红光、蓝光在同一介质中速度和波长可以不同，但“颜色身份”对应的是频率。

\textbf{认知提醒：} 不要把“波长变短”误解为“频率变高”。跨介质传播时，频率通常不变；在同一种介质中，才常用 $v=\lambda f$ 比较不同频率光的波长。
\end{conceptbox}

\begin{conceptbox}{全反射}

当光从光密介质射向光疏介质，且入射角大于临界角时，在理想无吸收界面的高中几何光学模型中不再画折射光，反射光全部返回原介质，这就是全反射。

\[
\boxed{\sin C=\frac{n_2}{n_1}}\qquad(n_1>n_2)
\]

\begin{center}
\input{figures/tikz/total-internal-reflection}

\figcaption{全反射：只有从光密介质射向光疏介质才可能发生}\label{fig:total-internal-reflection}
\end{center}

光纤通信正是利用全反射，让光在细长光纤中多次反射而不轻易漏出。
\end{conceptbox}

\begin{conceptbox}{凸透镜成像}

凸透镜会聚光线。常用三条特殊光线画图：
\begin{enumerate}
  \item 平行主光轴的光线，折射后过焦点；
  \item 过光心的光线，传播方向不变；
  \item 过焦点的光线，折射后平行主光轴。
\end{enumerate}

\begin{center}
\input{figures/tikz/convex-lens-imaging}

\figcaption{凸透镜成像：用两条特殊光线即可确定像的位置}\label{fig:convex-lens-imaging}
\end{center}
\end{conceptbox}

  \item 透镜题先判断物距与焦距的关系，再判断像的正倒、大小和虚实。

\begin{learningbox}{光学题的三类模型分析清单}
光学题先判断模型类型，再选择公式和作图方式：
\begin{enumerate}
  \item \textbf{界面光路：} 先画界面和法线，角度一律相对于法线量；反射用 $i=i'$，折射用 $n_1\sin i=n_2\sin r$，全反射还要先确认“光密到光疏”。
  \item \textbf{透镜成像：} 先画主光轴、焦点和两条特殊光线，判断实像还是虚像、正立还是倒立，再用 $\dfrac1f=\dfrac1u+\dfrac1v$ 计算。
  \item \textbf{波动光学：} 先看是干涉、衍射还是偏振；双缝条纹间距用 $\Delta x=\dfrac{L\lambda}{d}$，计算前先统一纳米、毫米、米等单位。
\end{enumerate}
\textbf{简要归纳：} 几何光学先画光路，透镜题先判像，波动光学先找控制条纹或图样的量。
\end{learningbox}

\section*{五、典型模型}

\subsection*{模型 1：折射方向判断}

判断折射方向时，关键参照线是法线，而不是纸面上“向上弯、向下弯”的直观印象：
\[
n_2>n_1\Rightarrow r<i,\qquad n_2<n_1\Rightarrow r>i.
\]

\subsection*{模型 2：平面镜成像与视深}

平面镜成像和水中物体“看起来变浅”都不是新的力学过程，而是光路反向延长后形成的几何结果：
\begin{itemize}
  \item \textbf{平面镜：} 像与物关于镜面对称，像距等于物距，成正立等大的虚像。
  \item \textbf{视深：} 从水中射向空气的光线折射后远离法线，人眼沿空气中光线反向延长，会把水中物体看成位于较浅处的虚像。
\end{itemize}

\begin{center}
\input{figures/tikz/plane-mirror-apparent-depth}

\figcaption{平面镜成像与视深：虚像来自反射光线或折射光线的反向延长}\label{fig:plane-mirror-apparent-depth}
\end{center}

\textbf{学习边界：} 高中阶段遇到平面镜和视深题，先画实际光线，再画反向延长线。不要把虚像当作真实光线会聚的位置。

\subsection*{模型 3：全反射与光纤}

全反射必须同时满足两个条件：
\[
\text{光密介质}\rightarrow\text{光疏介质},\qquad i>C.
\]
若只满足入射角大，但方向是从光疏到光密，不会发生全反射。

\subsection*{模型 4：凸透镜成像}

物距大于 $2f$ 时，成倒立缩小实像；物距等于 $2f$ 时，成倒立等大实像；物距在 $f$ 与 $2f$ 之间时，成倒立放大实像；物距等于 $f$ 时，折射光近似平行，屏上不能得到有限距离处的清晰实像；物距小于 $f$ 时，成正立放大虚像。

\begin{center}
\input{figures/tikz/lens-object-zones}

\figcaption{凸透镜成像分区：物距所在区间决定像的性质}\label{fig:lens-object-zones}
\end{center}

\textbf{透镜题三步分析清单：}
\begin{enumerate}
  \item 先比较物距 $u$ 与 $f$、$2f$ 的关系，判断大致成像区间。
  \item 再用两条特殊光线确定像的位置和性质：能在屏上承接的是实像，只能由反向延长线得到的是虚像。
  \item 最后再用 $\dfrac1f=\dfrac1u+\dfrac1v$ 计算数值；若涉及虚像或符号，必须先统一正负号约定。
\end{enumerate}

\textbf{认知提醒：} 透镜公式用于算得更准，光路图用于判断方向和性质。先画图再代数，能防止把实像、虚像和放大率记混。

若要用实验测凸透镜焦距，常让物体、凸透镜和光屏共轴，移动光屏直到得到清晰实像。测出物距 $u$ 和像距 $v$ 后，由薄透镜公式
\[
\frac1f=\frac1u+\frac1v
\]
求焦距 $f$。这里的 $u,v$ 都应从透镜光心附近量起，不能从支架边缘量起。

\begin{center}
\input{figures/tikz/lens-focal-length-experiment}

\figcaption{凸透镜焦距测量：调出清晰实像后，用物距和像距求焦距}\label{fig:lens-focal-length-experiment}
\end{center}

\subsection*{模型 5：光学仪器中的凸透镜}

照相机、人眼、放大镜、显微镜和望远镜，都在使用凸透镜成像规律。学生容易把“透镜成像表”当成孤立结论记忆，但光学仪器恰好能把这些结论连起来：
\begin{itemize}
  \item \textbf{照相机和人眼：} 远处物体经凸透镜成倒立、缩小的实像，像必须落在胶片或视网膜上才清晰。
  \item \textbf{放大镜：} 物体放在焦点以内，人眼看到正立、放大的虚像。
  \item \textbf{显微镜和望远镜：} 常用两组透镜，先由物镜形成中间像，再由目镜把中间像放大供眼睛观察。
\end{itemize}

\begin{center}
\input{figures/tikz/optical-instruments-lens}

\figcaption{光学仪器中的凸透镜：先判断成实像还是虚像，再判断像是否落在接收屏上}\label{fig:optical-instruments-lens}
\end{center}

\textbf{认知提醒：} 实像可以成在屏上；虚像不是实际光线会聚点，不能直接投到光屏上，需要眼睛或后续透镜系统沿反向延长线接收。这个区别比机械背“正倒、大小”更重要。

\subsection*{模型 6：人眼屈光不正与矫正}

人眼要看清物体，关键是晶状体把来自物体的光会聚到视网膜上。若像没有落在视网膜上，就会看不清。

\begin{center}
\input{figures/tikz/eye-defects-correction}

\figcaption{近视与远视的透镜矫正：矫正镜先改变入眼光束的会聚程度}\label{fig:eye-defects-correction}
\end{center}

\begin{itemize}
  \item \textbf{近视眼：} 远处物体的像成在视网膜前，说明眼睛会聚能力偏强，需用\textbf{凹透镜}先把光发散，使像后移到视网膜上。
  \item \textbf{远视眼：} 近处物体的像成在视网膜后，说明眼睛会聚能力偏弱，需用\textbf{凸透镜}先把光会聚，使像前移到视网膜上。
\end{itemize}

\textbf{判断要点：} 近视“前像后移”用凹透镜；远视“后像前移”用凸透镜。不能只记镜片名称，要先判断像相对视网膜的位置。

\subsection*{模型 7：双缝干涉}

光具有波动性，相干光叠加会形成明暗条纹。相邻亮纹间距为
\[
\Delta x=\frac{L\lambda}{d}.
\]

\begin{center}
\input{figures/tikz/double-slit-interference}

\figcaption{双缝干涉：条纹间距随波长和屏距增大，随缝距增大而减小}\label{fig:double-slit-interference}
\end{center}

这个公式可以用“光程差”直观理解。相邻亮纹对应的光程差相差一个波长 $\lambda$。当屏到双缝距离 $L$ 远大于缝距 $d$ 时，小角度近似下
\[
\Delta \ell \approx d\frac{x}{L}.
\]
令相邻亮纹的光程差变化为 $\lambda$，可推出
\[
\Delta x=\frac{L\lambda}{d}.
\]
因此，屏越远或波长越长，条纹越疏；双缝间距越大，条纹越密。

\begin{center}
\input{figures/tikz/double-slit-path-difference}

\figcaption{双缝光程差：用几何关系把光程差转化为屏上距离}\label{fig:double-slit-path-difference}
\end{center}

\section*{六、例题精讲}

\begin{examplebox}{折射角计算}
\textbf{题意分析：} 光从空气射入某玻璃，入射角 $i=30^\circ$，玻璃折射率 $n=1.5$，空气折射率取 1。求折射角。

\textbf{物理模型：} 折射定律。

\begin{center}
\input{figures/tikz/refraction-example-angle}
\end{center}

\textbf{解题过程：}
\[
n_1\sin i=n_2\sin r
\]
\[
1\times\sin30^\circ=1.5\sin r
\]
\[
\sin r=\frac{1}{3},\qquad r\approx19.5^\circ.
\]

\textbf{方法总结：} 折射题先判断光从光疏到光密还是光密到光疏，再预判靠近或远离法线；计算结果要和预判一致。
\end{examplebox}

\begin{examplebox}{全反射临界角}
\textbf{题意分析：} 光从折射率为 $1.50$ 的玻璃射向空气，求临界角。

\textbf{物理模型：} 光密介质到光疏介质的全反射。

\begin{center}
\input{figures/tikz/tir-critical-example}
\end{center}

\textbf{解题过程：}
\[
\sin C=\frac{n_2}{n_1}=\frac{1}{1.50}=\frac23.
\]
因此
\[
C\approx41.8^\circ.
\]

\textbf{方法总结：} 临界角题先确认光从光密介质射向光疏介质；公式中分子是光疏介质折射率，分母是光密介质折射率。
\end{examplebox}

\begin{examplebox}{双缝干涉条纹间距}
\textbf{题意分析：} 双缝间距 $d=0.50\ \mathrm{mm}$，屏到双缝距离 $L=1.0\ \mathrm{m}$，用波长 $\lambda=600\ \mathrm{nm}$ 的光照射，求相邻亮纹间距。

\textbf{物理模型：} 双缝干涉。

\begin{center}
\input{figures/tikz/double-slit-example}
\end{center}

\textbf{解题过程：}
\[
\Delta x=\frac{L\lambda}{d}
=\frac{1.0\times600\times10^{-9}}{0.50\times10^{-3}}
=1.2\times10^{-3}\ \mathrm{m}.
\]
即
\[
\Delta x=1.2\ \mathrm{mm}.
\]

\textbf{方法总结：} 干涉题先统一到国际单位制，尤其纳米、毫米，再代入 $\Delta x=\dfrac{L\lambda}{d}$。
\end{examplebox}

\section*{七、变式训练}

\begin{enumerate}
  \item 光从水射入空气时，折射光线相对法线是靠近还是远离？

\subsection*{训练提示}
\begin{enumerate}
  \item 先判断光从哪种介质进入哪种介质。水到空气是光密到光疏，折射光线远离法线；入射角足够大时再考虑全反射。
  \item 先写 $n=c/v$，再代真空光速 $c=3.0\times10^8\ \mathrm{m/s}$，注意求的是介质中光速。
  \item 先确认是光密到光疏，再写临界角公式；本题 $\sin C=\dfrac{1}{1.33}$，不要把分子分母写反。
  \item 先用特殊光线判断像的性质。放大镜成正立、放大的虚像，物体应放在焦点以内。
  \item 先从透镜光心附近量 $u,v$，再由 $\dfrac1f=\dfrac1u+\dfrac1v$ 得 $f=\dfrac{uv}{u+v}$。
  \item 先看 $\Delta x=\dfrac{L\lambda}{d}$ 中哪个量改变；条纹间距与缝距成反比，$d$ 增大为 2 倍时，条纹间距减半。
\end{enumerate}

\section*{八、易错点}
\begin{mistakebox}
\begin{enumerate}
  \item \textbf{角度量错：} 先画法线，再量入射角、反射角和折射角；这些角都不是相对于界面。
  \item \textbf{把虚像当成真实光线交点：} 先区分实线光路和虚线延长线。平面镜像和视深中的像都来自光线反向延长，真实光线并没有在虚像处会聚。
  \item \textbf{全反射条件不完整：} 先判断是否光密到光疏，再看入射角是否满足 $i>C$。
  \item \textbf{把折射率理解成光速变快：} 先用 $n=c/v$ 判断；折射率越大，介质中光速越小。
  \item \textbf{误以为光进入介质后频率改变：} 跨介质题先固定频率。对同一束光，频率通常不变，改变的是速度和波长。
  \item \textbf{凸透镜成像只记表格：} 先画过光心和过焦点的特殊光线，再判断像的大小、正倒和虚实。
  \item \textbf{测焦距时距离量错：} 物距、像距应从透镜光心附近到物或光屏的位置量起，不要把支架边缘当成透镜位置。
  \item \textbf{混淆实像和虚像：} 照相机、人眼需要实像落在接收屏上；放大镜看到的是虚像，不能直接成在光屏上。
  \item \textbf{近视远视矫正镜片记反：} 先看像在视网膜前还是后。像在前用凹透镜使像后移；像在后用凸透镜使像前移。
  \item \textbf{波动光学单位混乱：} 计算前先把 $\lambda$、$d$、$L$ 统一到米；$\lambda$ 常用纳米，$d$ 常用毫米，是最容易漏换的两个量。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}
\begin{competitionbox}
\textbf{费马原理的思想}

几何光学中有一个更深的统一观点：光在两点之间传播时，实际光路使传播时间取极值。反射定律和折射定律都可以从这个思想推出。

\textbf{为什么折射会偏折？}
光在不同介质中速度不同。若一束斜入射光进入较慢介质，波前的一侧先进入介质而速度先变慢，另一侧仍在原介质中较快传播，波前发生旋转，于是光线方向改变。

\textbf{竞赛入门模型：} 多介质光路问题通常先把光路分成几段，分别写出每段时间
\[
t=\frac{s_1}{v_1}+\frac{s_2}{v_2}+\cdots,
\]
再利用几何关系寻找传播时间取驻值的路径。高中阶段先把法线、角度和折射率用清楚，竞赛阶段再把它们统一到费马原理的思想中。
\end{competitionbox}

\subsection*{1.\quad 棱镜色散：折射率与波长有关}

白光通过棱镜后会分解成不同颜色的光，这是因为同一介质对不同颜色光的折射率不同。通常玻璃对紫光的折射率略大，对红光的折射率略小，所以紫光偏折更明显。

\subsection*{2.\quad 透镜公式的使用边界}

薄透镜公式
\[
\frac1f=\frac1u+\frac1v
\]
是高中光学中的常用关系，但它有适用边界：
\begin{itemize}
  \item 透镜要足够薄；
  \item 光线要近轴；
  \item 物、像距离的正负号要按统一规则处理；
  \item 真实光学仪器还会有像差，不能把理想透镜公式无限推广。
\end{itemize}

\textbf{学习建议：} 初学阶段先用光路图判断像的性质，再用公式计算数值。图像判断能防止公式符号用错。

\textbf{符号提醒：} 若采用高中常用的实物实像正取法，计算前必须先约定物距、像距、焦距的正负；若只做初步判断，可以先用光路图判断成实像还是虚像，再代入统一规则。不要在同一题中混用两套符号约定。

\subsection*{3.\quad 波动光学的三个关键词}

\begin{enumerate}
  \item \textbf{相干：} 两束光频率相同、相位差稳定，才容易形成稳定干涉条纹。
  \item \textbf{光程差：} 决定某处是加强还是减弱。
  \item \textbf{波长：} 条纹间距、衍射明显程度都与波长有关。
\end{enumerate}

双缝干涉中，相邻亮纹间距
\[
\Delta x=\frac{L\lambda}{d}
\]
说明：波长越长、屏越远，条纹越疏；双缝间距越大，条纹越密。

\textbf{公式来源直觉：} 屏越远，同样的角度差在屏上拉开的距离越大；双缝间距越大，同一位置产生的光程差变化更快，条纹就更密。这比只记公式更能防止把 $L$ 和 $d$ 的影响记反。

\subsection*{4.\quad 薄膜干涉：从光程差到彩色条纹}

肥皂泡、油膜和镜头镀膜常出现彩色条纹，原因是\textbf{薄膜干涉}。入射光到达薄膜上表面时，一部分直接反射；另一部分进入薄膜，在下表面反射后再射出。两束反射光到达人眼时发生叠加。

\begin{center}
\input{figures/tikz/thin-film-interference}

\figcaption{薄膜干涉：上下表面的两束反射光叠加，光程差决定加强或减弱}\label{fig:thin-film-interference}
\end{center}

\textbf{核心判断：} 薄膜厚度 $d$ 改变时，两束反射光的光程差随之改变。不同波长的光满足加强或减弱条件的位置不同，所以白光照射下会看到彩色条纹。

\textbf{模型边界：} 薄膜干涉的严格明暗条件还要考虑反射时是否发生半波损失。高中入门阶段先抓住“同一束光分成两束，再因光程差发生干涉”的模型；遇到定量题时再按题目给出的相位条件处理。

\textbf{科学应用：} 镜头增透膜会设计合适厚度，使某些反射光相互削弱，从而减少反光、提高透光率。这里用到的仍然是干涉思想，而不是简单“涂一层透明材料”。

\subsection*{5.\quad 衍射与偏振：光的波动性补充}

高中光学题最常考几何光学和双缝干涉，但从科学发展角度看，衍射和偏振同样重要。
\begin{itemize}
  \item \textbf{衍射：} 光遇到小孔、窄缝或障碍物边缘时会发生绕射。孔径越接近光的波长，衍射越明显；显微镜和望远镜的分辨率最终会受到衍射限制。
  \item \textbf{偏振：} 光是横波，振动方向可以被选择。偏振片、液晶显示和许多光学传感器都利用了偏振。
\end{itemize}

\begin{center}
\input{figures/tikz/optical-diffraction-polarization}

\figcaption{光的衍射与偏振：衍射限制分辨率，偏振体现光的横波性质}\label{fig:optical-diffraction-polarization}
\end{center}

\textbf{学习边界：} 高中阶段不要求用复杂公式计算衍射图样，但要知道衍射说明光具有波动性，偏振进一步说明光是横波。遇到“为什么光学仪器不能无限放大”的问题，要想到衍射极限。

\begin{examplebox}{光纤临界角与数值判断}
\textbf{题意分析：} 某光纤芯层折射率 $n_1=1.48$，包层折射率 $n_2=1.46$。光从芯层射向包层，求临界角满足的关系，并判断临界角接近 $80^\circ$ 还是 $40^\circ$。

\textbf{物理模型：} 光密介质到光疏介质，全反射临界角。

\textbf{解题过程：}
\[
\sin C=\frac{n_2}{n_1}=\frac{1.46}{1.48}\approx0.986.
\]
由于 $\sin C$ 接近 1，所以 $C$ 接近 $90^\circ$，更接近 $80^\circ$。

\textbf{方法总结：} 折射率差很小时，临界角很大，光必须以较“贴近界面”的方向入射才会全反射。
\end{examplebox}

\subsection*{6.\quad 分层训练}

\begin{enumerate}
  \item \textbf{基础：} 光从空气进入水中，入射角为 $45^\circ$，折射角比入射角大还是小？
  \item \textbf{提高：} 某透明介质折射率为 $1.60$，光从该介质射向空气，写出临界角方程。
  \item \textbf{综合：} 双缝实验中换用波长更短的蓝光，其他条件不变，条纹间距如何变化？说明理由。
  \item \textbf{拓展：} 肥皂泡为什么会呈现彩色条纹？从薄膜干涉角度说明。
  \item \textbf{开放思考：} 为什么显微镜和望远镜不仅要考虑几何成像，还要考虑衍射极限？
\end{enumerate}

\section*{十、今日小结}
\begin{enumerate}
  \item 反射角等于入射角，折射遵循 $n_1\sin i=n_2\sin r$。
  \item 平面镜成像满足像距等于物距；视深变浅来自折射光线的反向延长。
  \item 折射率 $n=c/v$，折射率越大，介质中光速越小。
  \item 光满足 $v=\lambda f$；跨介质传播时频率通常不变，速度和波长改变。
  \item 全反射必须从光密介质射向光疏介质，且入射角大于临界角。
  \item 凸透镜成像要会画特殊光线，并能解释照相机、人眼和放大镜的成像差异；测焦距时可由清晰实像的 $u,v$ 求 $f$。
  \item 近视像在视网膜前，用凹透镜矫正；远视像在视网膜后，用凸透镜矫正。
  \item 双缝干涉说明光具有波动性，条纹间距 $\Delta x=L\lambda/d$。
  \item 薄膜干涉来自上下表面反射光的叠加，可解释肥皂泡彩纹和增透膜。
  \item 衍射限制光学仪器分辨率，偏振体现光的横波性质。
\end{enumerate}

\textbf{一分钟复盘：} 任选一道光学题，先画法线或主光轴，再标角度、介质和光路方向；如果是透镜题，至少画两条特殊光线后再写公式。
