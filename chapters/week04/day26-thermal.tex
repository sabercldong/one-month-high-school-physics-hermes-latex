\daytitle{26}{热学基础}

\begin{learningbox}{本节导读}
热学研究大量分子的集体行为。本节先从分子动理论理解温度、内能和压强，再学习理想气体实验定律，最后用热力学第一定律分析吸热、做功和内能变化。重点不是机械记忆热学公式，而是建立“宏观现象由微观运动解释”的视角。
\end{learningbox}

\textbf{本节读题路线：} 先判断研究对象是哪一团气体或哪个热机；再区分状态量（$p,V,T,U$）和过程量（$Q,W$）：状态量写在初末状态旁，过程量写在箭头上。气体题先看过程类型和温度单位，热力学第一定律题先定 $Q$、$W$ 正负号，图像题先看 $p$-$V$ 面积和体积变化方向。

\section*{一、学习目标}
\begin{enumerate}
  \item 能说出分子动理论的三条基本观点，并用它们解释宏观热现象。
  \item 能用扩散现象和布朗运动说明分子热运动的证据。
  \item 能说出油膜法怎样由体积和面积估测分子大小。
  \item 能说明热平衡和温度计读数的物理前提。
  \item 能区分温度、热量、内能和做功，并能判断题目问的是状态量还是过程量。
  \item 能结合图像判断玻意耳定律、查理定律和盖-吕萨克定律的条件与变量关系。
  \item 会先确认气体质量或物质的量是否不变、温度是否用热力学温度，再用理想气体状态方程分析常见变化过程。
  \item 会先规定热量和做功的正负，再用热力学第一定律判断内能变化。
  \item 能用能量流向图说明热机效率和热力学第二定律的定性含义。
  \item 能用图像或现象说明晶体、非晶体、液晶、相对湿度、表面张力和毛细现象的基本物理图像。
\end{enumerate}
\section*{二、初高中衔接}

初中热学常把“热”与“温度升高”联系起来，但高中必须更精确：温度是状态量，热量是过程量；内能属于系统，热量和功是改变内能的两种方式。说“物体含有热量”是不严谨的，应说“物体具有内能”，或“在某过程中吸收、放出热量”。

\textbf{科学发展视角：} 热学是能源技术的基础。热机效率、空调制冷、发动机、相变储能、温室效应和芯片散热，都要同时回答两类问题：系统处于什么状态（$p,V,T,U$ 怎样变），过程里能量怎样交换（吸热、放热、对外做功还是外界做功）。把状态量和过程量分开，是理解现代能源设备的第一步。

\begin{learningbox}{本节概念地图}
热学要把三层语言对应起来：微观层面看分子运动和相互作用，宏观层面看 $p,V,T,U$ 等状态量，过程层面看热传递 $Q$ 和做功 $W$。读题时先判断题目问的是“此刻状态”，还是“变化过程”。
\[
\text{分子运动}\rightarrow \text{宏观状态量}\rightarrow \text{热量、做功与能量转化}.
\]
\end{learningbox}

\section*{三、核心概念}

\begin{conceptbox}{分子动理论}

分子动理论用微观运动解释宏观热现象，包含三个基本观点：
\begin{enumerate}
  \item 物体由大量分子组成；
  \item 分子永不停息地做无规则热运动；
  \item 分子间存在相互作用力。
\end{enumerate}

\begin{center}
\input{figures/tikz/molecular-motion}

\figcaption{分子热运动：宏观温度反映大量分子运动的统计特征}\label{fig:molecular-motion}
\end{center}

\textbf{关键理解：} 温度反映大量分子无规则热运动的统计平均；对理想气体来说，温度越高，分子的平均平动动能越大。但不能说某一个分子的动能一定变大，因为分子运动是统计性的。

\textbf{两个重要证据：} 
\begin{itemize}
  \item \textbf{扩散现象：} 不同物质能够自发地彼此进入对方，例如香味在空气中扩散、墨水在水中散开。扩散说明分子在不停运动。
  \item \textbf{布朗运动：} 悬浮在液体或气体中的微小颗粒做无规则运动。颗粒本身不是分子，它的运动来自周围大量分子从各个方向不断撞击且瞬时不平衡。
\end{itemize}

\begin{center}
\input{figures/tikz/diffusion-brownian-motion}

\figcaption{扩散与布朗运动：宏观可见现象背后是分子的无规则热运动}\label{fig:diffusion-brownian-motion}
\end{center}
\end{conceptbox}

\begin{conceptbox}{油膜法估测分子大小}

分子很小，不能用普通刻度尺直接测量。高中常用一个理想化实验建立数量级认识：把已知体积 $V$ 的油酸滴在水面上，使它尽量摊成一层很薄的\textbf{单分子油膜}。若测得油膜面积为 $S$，则油膜厚度可估作油酸分子的直径：
\[
\boxed{d\approx\frac{V}{S}}.
\]

\begin{center}
\input{figures/tikz/oil-film-molecule-size}

\figcaption{油膜法：把微小体积转化为可测面积，用 $d\approx V/S$ 估测分子直径}\label{fig:oil-film-molecule-size}
\end{center}

\textbf{关键假设：} 油酸在水面上近似形成单分子层，且分子可粗略看作直立排列。真实实验中常把油酸配成稀溶液，计算 $V$ 时必须取\textbf{纯油酸体积}，不能把整滴溶液体积直接代入。
\end{conceptbox}

\begin{conceptbox}{温度、内能、热量}

两个温度不同的物体接触后，若没有其他外界影响，热量会从高温物体传向低温物体，直到二者达到\textbf{热平衡}。热平衡时没有净热传递，二者温度相同。温度计测温并不是“碰一下就立刻知道真值”，而是要等温度计与被测物体达到热平衡后再读数。

\begin{center}
\input{figures/tikz/thermal-equilibrium-thermometer}

\figcaption{热平衡与温度计：温度计读数依赖它与被测物体达到热平衡}\label{fig:thermal-equilibrium-thermometer}
\end{center}

\begin{itemize}
  \item \textbf{温度：} 描述大量分子热运动剧烈程度的宏观量；在理想气体模型中，它直接反映分子平均动能。
  \item \textbf{内能：} 物体内大量分子热运动动能和分子间相互作用势能的总和，不包括物体整体的机械能。
  \item \textbf{热量：} 热传递过程中转移的能量，是过程量。
  \item \textbf{做功：} 通过宏观力和位移改变系统能量的方式。
\end{itemize}

\textbf{严谨表述：} 不能说“物体含有热量”，只能说“物体吸收热量”或“放出热量”。

\begin{center}
\input{figures/tikz/thermal-state-process-map}

\figcaption{状态量与过程量：内能属于系统，热量和功只描述能量转移过程}\label{fig:thermal-state-process-map}
\end{center}

\textbf{四词辨析清单：}
\begin{itemize}
  \item 问“此刻有多热”：看温度，它描述大量分子热运动的统计强弱。
  \item 问“系统此刻储存多少微观能量”：看内能，它是状态量，属于系统本身。
  \item 问“因为温差转移了多少能量”：看热量，它只在热传递过程中有意义。
  \item 问“外力或气体通过体积变化转移了多少能量”：看功，它也是过程量。
\end{itemize}

\textbf{认知提醒：} 热量和功不是物体“拥有”的状态量，而是能量进出系统的两条通道。解题时先判断题目问的是状态还是过程：问初末状态用温度、体积、压强、内能；问能量怎样进出系统，再写热量 $Q$ 和功 $W$。
\end{conceptbox}

\begin{conceptbox}{气体实验定律}

一定质量理想气体在某个状态下可用 $p,V,T$ 描述。温度必须使用热力学温度：
\[
T=t+273.15.
\]

\begin{center}
\input{figures/tikz/gas-laws-graphs}

\figcaption{气体实验定律图像：温度必须用热力学温度 $T$}\label{fig:gas-laws-graphs}
\end{center}

\[
\boxed{pV=C\quad(\text{等温})}
\]
\[
\boxed{\frac{V}{T}=C\quad(\text{等压})}
\]
\[
\boxed{\frac{p}{T}=C\quad(\text{等容})}
\]

综合起来，一定质量理想气体满足
\[
\boxed{\frac{pV}{T}=C}.
\]

\textbf{物质的量版本：} 这里的常量 $C$ 对同一团气体不变，但不是所有气体共用的普适常量。若气体的物质的量为 $n$，理想气体状态方程可写为
\[
\boxed{pV=nRT}.
\]
其中 $R$ 是气体常量。若从微观分子数看，也可写成
\[
\boxed{pV=NkT},\qquad N=nN_A.
\]
这里 $N_A$ 是阿伏伽德罗常量，$k$ 是玻尔兹曼常量。高中常用 $\dfrac{pV}{T}=C$ 处理“同一团气体”的状态变化；若题目比较不同物质的量的气体，要想到 $pV$ 与 $nT$ 成正比。

\begin{center}
\input{figures/tikz/ideal-gas-mole-bridge}

\figcaption{理想气体状态方程：物质的量把宏观状态量和分子数连接起来}\label{fig:ideal-gas-mole-bridge}
\end{center}
\end{conceptbox}

\begin{conceptbox}{热力学第一定律}

取“系统吸热为正，系统对外做功为正”的约定：
\[
\boxed{\Delta U=Q-W}.
\]

\begin{center}
\input{figures/tikz/first-law-piston}

\figcaption{热力学第一定律：吸热和做功共同决定内能变化}\label{fig:first-law-piston}
\end{center}

\begin{itemize}
  \item $Q>0$：系统吸热；$Q<0$：系统放热。
  \item $W>0$：系统对外做功；$W<0$：外界对系统做功。
  \item $\Delta U>0$：内能增加；$\Delta U<0$：内能减少。
\end{itemize}
\end{conceptbox}

\begin{learningbox}{热学题的状态-过程分析清单}
热学题先把“此刻状态”和“变化过程”分开：
\begin{enumerate}
  \item \textbf{状态层：} 确定研究对象，写清 $p,V,T,U$；温度进入气体定律前先换成 K。
  \item \textbf{过程层：} 判断等温、等压、等容、绝热或一般过程；热量 $Q$ 和功 $W$ 只在过程中有意义。
  \item \textbf{图像层：} $p$-$V$ 图中面积给出气体对外做功大小；体积增大时 $W>0$，体积减小时 $W<0$。
  \item \textbf{能量层：} 按本讲义约定用 $\Delta U=Q-W$；吸热取 $Q>0$，放热取 $Q<0$，气体对外做功取 $W>0$。
\end{enumerate}
\textbf{来源理解：} $p$-$V$ 图面积来自小段体积功 $W=p\Delta V$ 的累加；热力学第一定律则是能量守恒在热现象中的表达。气体定律先看状态，第一定律先看过程，符号约定先写清再代数。
\end{learningbox}

\section*{五、典型模型}

\subsection*{模型 1：等温压缩或膨胀}

温度不变，理想气体内能不变。若气体被压缩，体积减小，压强增大：
\[
p_1V_1=p_2V_2.
\]

\subsection*{模型 2：等压升温}

压强不变时，温度升高，体积增大：
\[
\frac{V_1}{T_1}=\frac{V_2}{T_2}.
\]
使用比例式前先把摄氏温度换成热力学温度 $T$，不能直接把摄氏温度代入。

\subsection*{模型 3：$p$-$V$ 图像中的功}

在准静态膨胀或压缩过程中，气体对外做的体积功可由 $p$-$V$ 图像下方面积表示：
\[
W=\int p\,dV.
\]
若体积增大，$dV>0$，气体对外做功为正；若体积减小，$dV<0$，外界对气体做功，气体对外做功为负。面积给出大小，方向由体积变化判断。

\begin{center}
\input{figures/tikz/pv-work-area}

\figcaption{$p$-$V$ 图像：图线下方面积表示气体对外做功}\label{fig:pv-work-area}
\end{center}

\subsection*{模型 4：绝热近似}

若过程很快或保温良好，可近似认为 $Q=0$。此时
\[
\Delta U=-W.
\]
气体快速膨胀对外做功，内能减少，温度降低；气体被快速压缩，外界对它做功，内能增加，温度升高。

\begin{center}
\input{figures/tikz/thermal-process-pv-summary}

\figcaption{常见热过程的 $p$-$V$ 图像：图像形状和面积帮助判断做功}\label{fig:thermal-process-pv-summary}
\end{center}

\subsection*{模型 5：扩散与布朗运动的判断}

遇到微观热运动的定性题，先分清“谁在动”：
\begin{itemize}
  \item 若是两种物质彼此混合、浓度逐渐均匀，通常是\textbf{扩散现象}；
  \item 若是在显微镜下看到小颗粒不停做无规则运动，通常是\textbf{布朗运动}；
  \item 布朗运动越明显，说明颗粒越小、温度越高，周围分子撞击造成的瞬时不平衡越明显。
\end{itemize}

\textbf{严谨提醒：} 布朗运动不是“分子本身的运动被看见了”，而是可见微粒受到大量分子撞击后的运动。它间接证明分子在做无规则热运动。

\section*{六、例题精讲}

\begin{examplebox}{等温变化}
\textbf{题意分析：} 一定质量理想气体温度不变，初态压强 $p_1=1.0\times10^5\ \mathrm{Pa}$，体积 $V_1=2.0\ \mathrm{L}$。若体积压缩到 $V_2=0.50\ \mathrm{L}$，求末态压强。

\textbf{物理模型：} 等温变化，$pV=C$。

\begin{center}
\input{figures/tikz/isothermal-compression-example}
\end{center}

\textbf{解题过程：}
\[
p_1V_1=p_2V_2,
\qquad
p_2=\frac{p_1V_1}{V_2}
=\frac{1.0\times10^5\times2.0}{0.50}
=4.0\times10^5\ \mathrm{Pa}.
\]

\textbf{方法总结：} 气体定律题先判断过程类型。等温压缩用 $pV=C$，体积变为原来的 $\dfrac14$ 时压强变为 4 倍。
\end{examplebox}

\begin{examplebox}{等压升温}
\textbf{题意分析：} 一定质量理想气体在压强不变时，温度从 $27^\circ\mathrm{C}$ 升高到 $127^\circ\mathrm{C}$。初体积 $V_1=3.0\ \mathrm{L}$，求末体积。

\textbf{物理模型：} 等压变化，$\dfrac{V}{T}=C$。

\begin{center}
\input{figures/tikz/isobaric-heating-example}
\end{center}

\textbf{解题过程：}
\[
T_1=27+273=300\ \mathrm{K},\qquad T_2=127+273=400\ \mathrm{K}.
\]
\[
\frac{V_1}{T_1}=\frac{V_2}{T_2},
\qquad
V_2=V_1\frac{T_2}{T_1}=3.0\times\frac{400}{300}=4.0\ \mathrm{L}.
\]

\textbf{方法总结：} 气体定律中的温度必须用热力学温度，不能用摄氏温度直接比。
\end{examplebox}

\begin{examplebox}{热力学第一定律}
\textbf{题意分析：} 某气体吸收热量 $Q=500\ \mathrm{J}$，同时对外做功 $W=200\ \mathrm{J}$。求内能变化。

\textbf{物理模型：} 热力学第一定律。

\begin{center}
\input{figures/tikz/first-law-example-flow}
\end{center}

\textbf{解题过程：}
\[
\Delta U=Q-W=500-200=300\ \mathrm{J}.
\]

\textbf{方法总结：} 第一定律题先定 $Q$、$W$ 正负；吸热若同时对外做功，内能增加量会小于吸收热量。
\end{examplebox}

\subsection*{训练提示}
\begin{enumerate}
  \item 先判断过程是否等温；等温时 $pV=C$，体积变为 3 倍，压强变为原来的 $\dfrac13$。
  \item 先把摄氏温度换成热力学温度；近似计算时常取 $T=t+273$。
  \item 先按本讲义约定定正负号：放热写 $Q=-100\ \mathrm{J}$；外界压缩气体时，系统对外做功为负，写 $W=-300\ \mathrm{J}$。
  \item 先看 $p$-$V$ 图像中体积是增大还是减小；面积表示气体对外做功，体积减小时做功为负。
  \item 先分清观察对象。香水味传播是扩散现象；花粉微粒无规则运动是布朗运动，布朗运动的对象是微粒而不是单个分子。
\end{enumerate}

\section*{八、易错点}
\begin{mistakebox}
\begin{enumerate}
  \item \textbf{说“物体含有热量”：} 先看题目描述的是状态还是过程。温度、内能是状态量；热量只在传热过程中讨论，应说“吸收或放出热量”，不要说“含有热量”。
  \item \textbf{温度计刚接触就读数：} 先等待温度计与被测物体达到热平衡，读数才代表被测物体温度。
  \item \textbf{气体定律用摄氏温度：} 列比例关系前先把摄氏温度换成热力学温度 $T$。
  \item \textbf{把 $pV/T=C$ 中的 $C$ 当成普适常量：} 对同一团气体 $C$ 不变；不同物质的量的气体要用 $pV=nRT$ 比较。
  \item \textbf{混淆做功正负：} 先写清正负号约定；本讲义约定系统对外做功为正，所以 $\Delta U=Q-W$。
  \item \textbf{把温度看成单个分子动能：} 先强调统计平均；温度对应大量分子的平均动能。
  \item \textbf{油膜法把溶液体积当油酸体积：} 计算 $d=V/S$ 时，$V$ 应是形成油膜的纯油酸体积。
  \item \textbf{忽略内能还含分子势能：} 对实际物体和相变过程，分子势能变化也很重要。
  \item \textbf{把布朗运动说成分子运动：} 布朗运动是微小颗粒的无规则运动，间接反映分子热运动。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}
\begin{competitionbox}
\textbf{从微观角度看压强}

气体压强来自大量分子不断碰撞器壁。单个分子的碰撞很复杂，但大量分子的平均效果很稳定，这就是统计物理的基本思想。

在理想气体模型中，分子本身大小可忽略，分子间除碰撞外不考虑相互作用。由此可以推出
\[
pV=\frac23N\overline{E_k},
\]
其中 $N$ 是分子数，$\overline{E_k}$ 是单个分子的平均平动动能。又因为理想气体状态方程为
\[
pV=NkT,
\]
可得
\[
\overline{E_k}=\frac32kT.
\]

\textbf{意义：} 这说明温度不是模糊的冷热感觉，而是微观平均动能的量度。高中阶段不要求完整推导，但这个结果能帮助理解为什么绝对零度可看作热运动强弱的最低极限。

\subsection*{1.\quad 相变与潜热：温度不变也能吸热}

许多学生会误以为“吸热一定升温”。相变过程说明：吸收的热量不一定都转化为分子平均动能，也可能主要改变分子间的相互作用势能。

\begin{center}
\input{figures/tikz/phase-change-heating-curve}

\figcaption{相变加热曲线：熔化和汽化过程中温度可保持不变，但仍在吸收热量}\label{fig:phase-change-heating-curve}
\end{center}

\textbf{典型判断：} 冰熔化成水时，温度可以保持在 $0^\circ\mathrm{C}$；水沸腾时，温度可以保持在沸点。平台段吸收的热量叫\textbf{潜热}，主要用于改变物质的微观结构或分子势能，而不是提高温度。

\textbf{与内能的关系：} 内能包括分子动能和分子势能。温度主要反映分子平均动能；相变时温度不变，但分子势能改变，所以内能仍可改变。

\subsection*{2.\quad 固体、液晶与湿度：从模型走向材料}

热学不只研究气体。实际材料的性质也来自微观结构：
\begin{itemize}
  \item \textbf{晶体：} 微粒排列有规则，常有确定熔点，许多金属、食盐、石英属于晶体。
  \item \textbf{非晶体：} 微粒排列没有长程规则，通常没有严格固定熔点，玻璃、松香等可看作典型例子。
  \item \textbf{液晶：} 既能像液体那样流动，又有一定取向有序性，液晶显示器正是利用外电场改变分子取向来控制透光。
\end{itemize}

空气中的水蒸气也要用热学语言描述。同一温度下，空气中水蒸气压有一个最大值，叫\textbf{饱和汽压} $p_s$。实际水蒸气压为 $p$ 时，相对湿度为
\[
\varphi=\frac{p}{p_s}\times100\%.
\]
温度升高时，饱和汽压通常增大，所以同样多的水蒸气在较高温度下可能显得“不那么潮湿”。这也是为什么降温容易结露：空气容纳水蒸气的能力下降，多余水蒸气凝结成小水滴。

\begin{center}
\input{figures/tikz/materials-humidity}

\figcaption{材料结构与湿度：微观排列决定材料性质，饱和汽压决定相对湿度}\label{fig:materials-humidity}
\end{center}

\textbf{学习边界：} 高中阶段通常先定性区分晶体、非晶体和液晶，理解相对湿度的含义；暂不深入晶格结构或复杂相图。读材料类题时，先抓“微观排列是否有序”和“水蒸气是否接近饱和”这两个判断。

\subsection*{3.\quad 液体表面张力与毛细现象}

液体表面附近的分子受力情况不同于液体内部。液体内部某个分子受到周围分子的吸引大致平衡；而液体表面分子上方分子较少，受力不完全对称，于是液面有收缩趋势，好像一张被拉紧的薄膜。这种使液面趋向收缩的作用叫\textbf{表面张力}。

\begin{center}
\input{figures/tikz/surface-tension-capillary}

\figcaption{表面张力与毛细现象：液面趋向收缩，细管中液面可上升或下降}\label{fig:surface-tension-capillary}
\end{center}

\textbf{两个常见现象：}
\begin{itemize}
  \item 小水滴常接近球形，是因为在体积一定时球形表面积最小，表面张力使液面趋向收缩。
  \item 细玻璃管插入水中，水可沿管壁上升；若液体不浸润管壁，也可能出现液面下降。这类现象叫\textbf{毛细现象}。
\end{itemize}

\textbf{学习边界：} 高中阶段一般定性理解表面张力和毛细现象即可，暂不计算表面张力系数。遇到现象题，先判断液面是否趋向收缩、液体是否浸润管壁，再解释上升或下降。

\subsection*{4.\quad 热机效率}

热机从高温热源吸收热量 $Q_1$，把其中一部分转化为对外做功 $W$，其余热量 $Q_2$ 放给低温热源：
\[
Q_1=W+Q_2.
\]
这里的 $Q_1$、$Q_2$ 都按热量大小取正值，$Q_2$ 不是代入第一定律时的负号放热量。
热机效率定义为
\[
\eta=\frac{W}{Q_1}=1-\frac{Q_2}{Q_1}.
\]

\begin{center}
\input{figures/tikz/heat-engine-cycle}

\figcaption{热机循环：循环过程中系统回到初态，净功等于吸热与放热之差}\label{fig:heat-engine-cycle}
\end{center}

\textbf{重要理解：} 对循环工作的热机，不能从单一热源吸热并把它全部转化为功而不产生其他影响；因此实际热机都需要向低温热源放出一部分热量。真实装置还会因摩擦、散热和不可逆过程产生额外损耗。

\textbf{热力学第二定律的定性理解：} 热量可以自发地从高温物体传到低温物体，但不能自发地从低温物体传到高温物体。若要把热量从低温处搬到高温处，例如冰箱和空调，就必须消耗外界做功。这说明能量不仅要守恒，还要考虑过程方向。

\begin{center}
\input{figures/tikz/second-law-heat-flow}

\figcaption{热力学第二定律的方向性：逆向搬运热量必须消耗外界做功}\label{fig:second-law-heat-flow}
\end{center}

\textbf{现代应用：制冷机与热泵。} 冰箱、空调和热泵并不是“违反第二定律”，而是消耗外界做功，把热量从低温处搬到高温处。若关注冷端降温，就是制冷机；若关注热端供热，就是热泵。

\begin{center}
\input{figures/tikz/refrigerator-heat-pump}

\figcaption{制冷机与热泵：外界做功使热量逆向转移}\label{fig:refrigerator-heat-pump}
\end{center}

\textbf{认知提醒：} 制冷机和热泵不是“凭空制造冷或热”。它们都遵守能量守恒：电功输入后，热量被重新分配。冰箱背面发热，是因为它把箱内热量连同压缩机消耗的电功一起排到室内。

\begin{examplebox}{热机每循环输出功和效率}
\textbf{题意分析：} 某热机每循环从高温热源吸收 $Q_1=1000\ \mathrm{J}$，向低温热源放出 $Q_2=650\ \mathrm{J}$。求每循环输出功和效率。

\textbf{物理模型：} 热机循环，系统回到初态，$\Delta U=0$。

\begin{center}
\input{figures/tikz/heat-engine-efficiency-example}
\end{center}

\textbf{解题过程：}
\[
W=Q_1-Q_2=1000-650=350\ \mathrm{J}.
\]
\[
\eta=\frac{W}{Q_1}=\frac{350}{1000}=35\%.
\]

\textbf{方法总结：} 循环过程先看初末状态是否相同；回到初态则 $\Delta U=0$，吸热与放热之差就是对外输出功。
\end{examplebox}

\subsection*{5.\quad 四种常见过程的能量判断}

\begin{center}
\begin{tabular}{lll}
\toprule
过程 & 特征 & 第一定律分析 \\
\midrule
等温过程 & 理想气体温度不变 & $\Delta U=0$，故 $Q=W$；膨胀吸热，压缩放热 \\
等容过程 & 体积不变 & $W=0$，$\Delta U=Q$ \\
等压过程 & 压强不变 & $W=p\Delta V$ \\
绝热过程 & $Q=0$ & $\Delta U=-W$ \\
\bottomrule
\end{tabular}
\end{center}

\textbf{认知顺序：} 先判断过程类型，再判断 $Q$、$W$ 的正负，最后用 $\Delta U=Q-W$。不要一开始就做代数运算。

\textbf{正负号约定：} 本讲义采用“系统对外做功为正”的约定，因此气体膨胀时 $W>0$，压缩时 $W<0$；吸热时 $Q>0$，放热时 $Q<0$。若别的资料采用“外界对系统做功为正”，第一定律形式会不同，但物理结论一致。解题时先看清约定，再列式。

\textbf{过程判断要点：} 等温看温度，等容看体积，等压看压强，绝热看是否与外界交换热量。若题目没有明确过程类型，不能随意套某个特殊公式，只能从第一定律和状态方程出发分析。

\begin{examplebox}{等容加热}
\textbf{题意分析：} 一定质量理想气体被封闭在刚性容器中，吸收热量 $300\ \mathrm{J}$。求气体对外做功和内能变化。

\textbf{物理模型：} 等容过程，体积不变。

\textbf{解题过程：}
容器刚性，体积不变，所以
\[
W=0.
\]
由热力学第一定律：
\[
\Delta U=Q-W=300-0=300\ \mathrm{J}.
\]

\textbf{方法总结：} 等容过程没有体积变化，气体不对外做体积功。
\end{examplebox}

\begin{examplebox}{绝热压缩}
\textbf{题意分析：} 外界对气体做功 $200\ \mathrm{J}$，过程很快，可视为绝热。求内能变化，并判断温度如何变化。

\textbf{物理模型：} 绝热过程，$Q=0$。本讲义约定系统对外做功为正。

\textbf{解题过程：}
外界对气体做功 $200\ \mathrm{J}$，即气体对外做功
\[
W=-200\ \mathrm{J}.
\]
所以
\[
\Delta U=Q-W=0-(-200)=200\ \mathrm{J}.
\]
内能增加，理想气体温度升高。

\textbf{方法总结：} 绝热压缩会使气体升温，这也是打气筒快速打气时筒壁发热的原因之一。
\end{examplebox}

\subsection*{6.\quad 分层训练}

\begin{enumerate}
  \item \textbf{基础：} 一定质量理想气体等容放热，内能怎样变化？
  \item \textbf{提高：} 气体等压膨胀，吸热 $500\ \mathrm{J}$，对外做功 $180\ \mathrm{J}$，求内能变化。
  \item \textbf{综合：} 某热机每循环吸热 $1000\ \mathrm{J}$，放热 $650\ \mathrm{J}$，求输出功和效率。
  \item \textbf{应用：} 同一房间温度降低时，为什么窗玻璃上更容易出现水珠？
  \item \textbf{开放思考：} 为什么冰箱能把热量从低温处搬到高温处，但必须消耗电能？
  \item \textbf{拓展观察：} 小水滴为什么常接近球形？细玻璃管插入水中时，液面为什么可能高于管外水面？
\end{enumerate}

\section*{十、今日小结}
\begin{enumerate}
  \item 分子动理论把宏观热现象解释为大量分子的统计运动。
  \item 扩散现象和布朗运动都是分子热运动的重要证据。
  \item 油膜法用 $d\approx V/S$ 估测分子大小，前提是形成近似单分子层。
  \item 热平衡时没有净热传递，温度计读数的前提是温度计与被测物体达到热平衡。
  \item 温度反映分子平均动能，内能是分子动能和分子势能总和。
  \item 热量和功都是过程量，都是改变内能的方式。
  \item 一定质量理想气体满足 $pV/T=C$；若显式给出物质的量，则用 $pV=nRT$。
  \item 热力学第一定律在本讲义约定下写作 $\Delta U=Q-W$。
  \item 相变时温度可能不变，但吸收或放出的潜热会改变分子势能和内能。
  \item 晶体、非晶体和液晶的差别来自微观排列；相对湿度描述空气中水蒸气接近饱和的程度。
  \item 表面张力来自液体表面分子受力不对称，毛细现象与浸润、管径和表面张力有关。
  \item 热力学第二定律强调过程方向：热量不会自发地从低温物体传到高温物体。
  \item 制冷机和热泵靠外界做功把热量从低温处搬到高温处，不违背能量守恒和第二定律。
\end{enumerate}

\textbf{一分钟复盘：} 看到热学题，先在题旁写三列：研究对象、状态变化、能量交换；若用热力学第一定律，再单独写清 $Q$、$W$、$\Delta U$ 的正负约定。
