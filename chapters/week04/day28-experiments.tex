\daytitle{28}{高中物理实验专题}

\begin{learningbox}{本节导读}
实验题不是“背步骤”，而是考查物理量怎样被测出来。本节按通用能力组织：纸带与运动学、电学测量、验证规律、数据处理和误差分析。学习目标是看到实验题能迅速判断：测什么、怎么测、怎样处理数据、误差从哪里来。
\end{learningbox}

\textbf{本节读题路线：} 先问实验要测什么量，再找哪些量能直接测、哪些量要间接算；作图题先确定横纵轴和斜率单位，电学实验先判断电表内阻带来的系统误差。写结论时要把物理关系、单位和有效数字一起交代清楚。

\section*{一、学习目标}
\begin{enumerate}
  \item 能先数清纸带时间间隔，再用相邻点间距求速度、加速度。
  \item 会识别常见力学、电学实验的测量对象、直接测量量和核心公式。
  \item 会用坐标描点和图像法处理平抛运动实验。
  \item 能在实验图像中先写出横纵轴单位，再判断斜率、截距和面积的物理意义。
  \item 会区分系统误差和偶然误差，知道常见减小误差的方法。
  \item 形成规范实验表达：单位、有效数字、坐标轴和结论都要清楚。
  \item 会读游标卡尺、螺旋测微器，能处理零点误差和有效数字。
  \item 能说出电阻率、小灯泡伏安特性、玻璃折射率、凸透镜焦距和双缝测波长等高频实验的核心关系。
  \item 会解释多用电表欧姆挡的基本原理和读数特点。
  \item 能用电桥示意图说明微小电阻变化怎样转化为可测电压。
\end{enumerate}
\section*{二、初高中衔接}

初中实验多强调操作现象，高中实验更强调定量关系。例如同样是测速度，高中要知道为什么在匀变速直线运动中，中间时刻速度等于该小段位移除以对应时间；同样是测电阻，高中要知道电表内阻会带来系统误差。

\textbf{科学发展视角：} 现代科学和工程高度依赖测量。传感器、数据采集、图像识别和自动控制都在做同一件事：把物理量转化为可记录的数据，再用模型解释数据。高中实验训练的是这种科学思维的最小闭环。

\section*{三、核心概念}

\begin{conceptbox}{实验题的四个问题}

做实验题时先问四个问题：
\begin{enumerate}
  \item \textbf{测量对象：} 最终要测什么物理量？
  \item \textbf{直接测量量：} 哪些量可由仪器直接读出？
  \item \textbf{间接关系：} 用什么公式把直接测量量转化为目标量？
  \item \textbf{误差来源：} 哪些假设不完全成立？
\end{enumerate}

\begin{center}
\input{figures/tikz/experiment-error-flow}

\figcaption{实验处理流程：测量、记录、作图、误差分析缺一不可}\label{fig:experiment-error-flow}
\end{center}
\end{conceptbox}

\begin{conceptbox}{读数仪器与有效数字}

很多实验题的第一步，是能不能把仪器读数读对。读数时要先分清\textbf{仪器精度}，再决定结果保留到哪一位。

\begin{center}
\input{figures/tikz/vernier-micrometer-reading}

\figcaption{常见长度测量仪器：先读固定部分，再读对齐或旋转部分}\label{fig:vernier-micrometer-reading}
\end{center}

\begin{itemize}
  \item \textbf{游标卡尺：} 先读游标零刻度左侧的主尺读数，再加上游标与主尺对齐的格数乘以精度。
  \item \textbf{螺旋测微器：} 先读固定刻度，再加上可动刻度读数；常见精度为 $0.01\ \mathrm{mm}$。
  \item \textbf{零点误差：} 若仪器闭合时不读零，最后应作修正：真实读数 $=$ 仪器读数 $-$ 零点误差。
  \item \textbf{有效数字：} 测量结果不能写得比仪器精度更“精细”。例如精度为 $0.1\ \mathrm{mm}$ 的仪器，结果不应随意写到 $0.001\ \mathrm{mm}$。
\end{itemize}
\end{conceptbox}

\begin{conceptbox}{估读与不确定度}

测量值不是“绝对真值”，而是带有一定可信范围的结果。高中阶段不要求系统学习大学实验中的不确定度理论，但要形成三个基本习惯：

\begin{center}
\input{figures/tikz/measurement-uncertainty}

\figcaption{估读与不确定度：测量结果的位数应与仪器分辨能力相匹配}\label{fig:measurement-uncertainty}
\end{center}

\begin{itemize}
  \item \textbf{模拟刻度要估读：} 直尺、电流表、电压表等有连续刻度的仪器，通常估读到最小分度值的下一位。
  \item \textbf{数字仪表看分辨率：} 数字表显示到哪一位，通常说明它能分辨到哪一位；不要人为添加没有意义的零。
  \item \textbf{多次测量看离散程度：} 多次测量结果越集中，偶然误差通常越小；若数据明显偏离，要先判断是否有操作或读数问题。
\end{itemize}

\textbf{表达原则：} 最终结果的有效数字应与主要测量量的精度相匹配。若仪器只能读到毫米级，却写成 $x=2.000000\ \mathrm{m}$，就等于声称测到了微米级精度，这是不严谨的。

\end{conceptbox}

\begin{conceptbox}{纸带法}

打点计时器每隔相同时间打一个点。若电源频率为 $50\ \mathrm{Hz}$，相邻点时间间隔为
\[
\Delta t=0.02\ \mathrm{s}.
\]
若每 5 个间隔取一个计数点，则相邻计数点时间为
\[
T=5\Delta t=0.10\ \mathrm{s}.
\]

\begin{center}
\input{figures/tikz/ticker-tape-analysis}

\figcaption{纸带法：用相等时间内位移变化研究匀变速运动}\label{fig:ticker-tape-analysis}
\end{center}

匀变速直线运动中，某段时间中间时刻的速度等于这一小段的平均速度：
\[
v_{\text{中}}=\frac{\Delta x}{\Delta t}.
\]
若连续相等时间内位移差恒定，则
\[
\Delta x=aT^2.
\]

\textbf{光电门测速：} 现代实验常用光电门替代人工计时。让宽度为 $d$ 的遮光片通过光电门，计时器记录遮光时间 $\Delta t$。若遮光片足够窄，遮光过程中的平均速度可近似看作通过光电门时的瞬时速度：
\[
v\approx\frac{d}{\Delta t}.
\]

\begin{center}
\input{figures/tikz/photogate-speed}

\figcaption{光电门测速：用遮光片宽度和遮光时间估测瞬时速度}\label{fig:photogate-speed}
\end{center}

\textbf{方法提醒：} 遮光片越窄，运动状态在遮光时间内变化越小，瞬时速度近似越好；若遮光片很宽或物体加速度很大，就不能把整个遮光过程简单看成同一瞬时速度。
\end{conceptbox}

\begin{conceptbox}{电学测量}

电学实验常见目标是测电阻、电源电动势和内阻。关键不是把电路画出来就结束，而是要判断电表内阻对测量结果的影响。

\begin{center}
\input{figures/tikz/electric-meter-circuits}

\figcaption{伏安法测电阻：内接法和外接法适用于不同电阻范围}\label{fig:electric-meter-circuits}
\end{center}

\begin{itemize}
  \item 大电阻常用电流表内接法，减小电压表分流影响。
  \item 小电阻常用电流表外接法，减小电流表分压影响。
  \item 电源实验常用 $U=E-Ir$，作 $U$-$I$ 图像求截距和斜率。
\end{itemize}
\end{conceptbox}

\begin{conceptbox}{电学实验中的电路选择}

电学实验不仅要选内接、外接，还要会判断滑动变阻器怎样接。常见有两种：

\begin{center}
\input{figures/tikz/rheostat-limit-divider}

\figcaption{滑动变阻器接法：限流接法调电流，分压接法可让电压从近似零调起}\label{fig:rheostat-limit-divider}
\end{center}

\begin{itemize}
  \item \textbf{限流接法：} 滑动变阻器与待测电阻串联，电路简单、耗能较少，适合一般调节电流。
  \item \textbf{分压接法：} 待测电阻接在滑片与一端之间，电压调节范围更宽，尤其适合要求电压从 $0$ 开始变化、待测电阻较大或需要多组连续数据的实验。
  \item \textbf{判断顺序：} 先看题目是否要求“从零调起”；再看待测电阻与滑动变阻器阻值是否匹配；最后考虑安全电流和仪表量程。
\end{itemize}

表头本身能通过的最大电流很小。若要把它改装成大量程电表，需要用电阻重新分配电流或电压：

\begin{center}
\input{figures/tikz/meter-range-extension}

\figcaption{电表量程扩展：并联分流改电流表，串联分压改电压表}\label{fig:meter-range-extension}
\end{center}

\begin{itemize}
  \item 改装电流表：表头 $G$ 与小电阻 $R_s$ 并联，让大部分电流从分流电阻通过。
  \item 改装电压表：表头 $G$ 与大电阻 $R$ 串联，让大部分电压分在串联电阻上。
\end{itemize}

若题目进一步要求测表头内阻，常见方法是\textbf{半偏法}。先用较大的保护电阻 $R_0$ 调出某一稳定偏转，再给表头并联一个可调电阻 $R_s$，调到表头偏转变为原来的一半。若 $R_0$ 足够大，使总电流近似不变，则并联电阻与表头中电流近似相等，故
\[
R_s \approx R_g.
\]

\begin{center}
\begin{minipage}{0.96\linewidth}
\centering
\input{figures/tikz/half-deflection-galvanometer}

\figcaption{半偏法测表头内阻：在总电流近似不变时，半偏电阻近似等于表头内阻}\label{fig:half-deflection-galvanometer}
\end{minipage}
\end{center}

\textbf{误差意识：} 半偏法的结论不是无条件精确等式。并联 $R_s$ 后外电路总电阻会改变，电源电流会略变；保护电阻越大，这种变化越小，近似越好。
\end{conceptbox}

\section*{四、公式与适用条件}

\textbf{实验前检查：}
\nopagebreak[4]
\begin{enumerate}
  \item 先说清要测什么物理量，哪些量直接测，哪些量由公式间接算出。
  \item 画电路或装置图时，先保证测量对象、仪表位置和量程选择正确。
  \item 图像法先写纵轴、横轴和单位，再说明斜率或截距代表什么。
  \item 误差分析要区分系统误差、偶然误差和读数误差，不要只写“有误差”。
\end{enumerate}

\begin{learningbox}{实验题的证据链}
实验题的答案要像一条证据链，而不是操作步骤的堆叠：
\begin{enumerate}
  \item \textbf{目标量：} 题目要测或验证什么，例如 $g$、$R$、$E,r$、$v_0$、$\lambda$。
  \item \textbf{直接测量量：} 仪器实际读到什么，例如长度、时间、电压、电流、角度或条纹间距。
  \item \textbf{物理关系：} 用哪条公式把直接测量量转化为目标量，图像法还要说明斜率或截距的意义。
  \item \textbf{结果检查：} 单位、有效数字、量程和误差方向是否合理。
\end{enumerate}
写实验设计题时，按这四步组织语言，答案会更清楚，也更容易体现科学性。
\end{learningbox}

\section*{五、典型模型}

\subsection*{模型总览：实验基本方法}

高中实验题不只是考“某个装置怎么接”，更常考实验方法。遇到陌生实验，先判断它用了哪一种基本方法，再把方法翻译成具体器材和数据处理。

\begin{center}
\input{figures/tikz/experiment-methods-map}

\figcaption{高中实验常用方法：控制变量、转换放大、等效替代和比较法}\label{fig:experiment-methods-map}
\end{center}

\begin{itemize}
  \item \textbf{控制变量法：} 研究多因素关系时，一次只改变一个量。例如验证牛顿第二定律时，先保持 $m$ 不变研究 $a$ 与 $F$，再保持 $F$ 不变研究 $a$ 与 $m$。
  \item \textbf{转换放大法：} 把难以直接测量的物理量转化为易读数据。例如用纸带点距求速度和加速度，用传感器把温度、压力、光强转化为电信号。
  \item \textbf{等效替代法：} 用一个等效量代替复杂对象。例如把复杂电路化为等效电阻，把电源看成理想电源与内阻串联。
  \item \textbf{比较法：} 把实验测得的量与标准值、理论关系或平衡条件比较。例如验证机械能守恒、电桥平衡测未知电阻。
\end{itemize}

\textbf{实验设计提醒：} 设计实验时先写清“采用什么方法”，再写“测哪些量、如何处理数据、误差从哪里来”。这样答案更像科学实验，而不是器材清单。

\subsection*{模型 1：验证牛顿第二定律}

常见方法是控制变量：
\begin{itemize}
  \item 保持质量 $m$ 不变，研究 $a$ 与 $F$ 的关系；
  \item 保持合力 $F$ 不变，研究 $a$ 与 $m$ 的关系。
\end{itemize}
若作 $a$-$F$ 图像，斜率应为 $\dfrac1m$。

\subsection*{模型 2：验证机械能守恒}

自由落体或摆球下落实验中，比较重力势能减少量和动能增加量：
\[
mgh\quad\text{与}\quad \frac12mv^2.
\]
若空气阻力、摩擦和测量误差较小，两者应近似相等。

\subsection*{模型 3：探究平抛运动}

平抛实验的核心，是把一个二维运动拆成两个一维关系：水平方向近似匀速，竖直方向近似自由落体。实验中通常让小球从斜槽末端水平抛出，在坐标纸上记录多个轨迹点。

\begin{center}
\input{figures/tikz/projectile-experiment}

\figcaption{探究平抛运动：用描点轨迹和 $y-x^2$ 图像检验抛物线关系}\label{fig:projectile-experiment}
\end{center}

取抛出点为原点，$x$ 轴水平向右，$y$ 轴竖直向下，则
\[
x=v_0t,\qquad y=\frac12gt^2.
\]
消去时间 $t$ 得
\[
y=\frac{g}{2v_0^2}x^2.
\]
因此若作 $y-x^2$ 图像，应近似为过原点的直线；斜率
\[
k=\frac{g}{2v_0^2},
\]
可反推出
\[
v_0=\sqrt{\frac{g}{2k}}.
\]

\textbf{关键条件：} 斜槽末端必须水平，坐标原点应取在小球离开轨道的位置，$y$ 方向通常取向下为正。若原点选错或把竖直位移从桌面算起，$y$ 与 $x^2$ 的线性关系会被破坏。

\subsection*{模型 4：验证动量守恒}

碰撞实验的核心不是“看到碰撞就结束”，而是比较碰撞前后系统总动量是否近似相等。常用低摩擦轨道或气垫导轨减小外力影响，用光电门或纸带测速度：
\[
m_1v_1+m_2v_2\approx m_1v_1'+m_2v_2'.
\]

\begin{center}
\input{figures/tikz/momentum-conservation-experiment}

\figcaption{验证动量守恒：测出碰前、碰后速度，比较系统总动量}\label{fig:momentum-conservation-experiment}
\end{center}

\textbf{关键条件：} 研究对象要选两个碰撞物体组成的系统；轨道尽量水平、摩擦尽量小，使碰撞过程中的外力冲量可以忽略。若碰撞后粘在一起，应把共同速度作为末速度；若碰后分开，则分别测 $v_1'$ 和 $v_2'$。

\subsection*{模型 5：测电源电动势和内阻}

由闭合电路欧姆定律
\[
U=E-Ir.
\]
作 $U$-$I$ 图像时，纵截距为 $E$，斜率绝对值为 $r$。

\subsection*{模型 6：图像法}

图像法不是为了追求图形美观，而是把数据关系线性化。常见思路：
\[
y=kx+b.
\]
斜率 $k$、截距 $b$ 都必须有物理意义和单位。

\textbf{斜率检查分析清单：}
\begin{enumerate}
  \item 先写清横轴、纵轴各是什么物理量，单位分别是什么。
  \item 再由理论式改写成 $y=kx+b$ 的形式，判断斜率 $k$ 和截距 $b$ 对应什么。
  \item 最后用“纵轴单位除以横轴单位”检查斜率单位是否合理。
\end{enumerate}

\textbf{认知提醒：} 斜率不是一个纯数字。若 $T^2-l$ 图像的斜率单位是 $\mathrm{s^2/m}$，才可能对应单摆公式中的斜率项；若单位不对，说明横纵轴或公式变形已经出了问题。

\subsection*{模型 7：电学实验电路选择}

电学实验设计常按下面顺序判断：
\begin{enumerate}
  \item 先判断测量目标：测电阻、测电源、测电流还是测电压；
  \item 再判断电表接法：大电阻优先考虑内接，小电阻优先考虑外接；
  \item 再判断滑动变阻器接法：若要求从零开始调节或需要宽范围数据，优先考虑分压接法；
  \item 最后检查量程：任何时候都不能让电流、电压超过仪表量程。
\end{enumerate}

\subsection*{模型 8：多用电表欧姆挡}

多用电表的欧姆挡不是“直接量电阻”，而是表内电源让电流通过待测电阻，再由指针偏转反推出电阻大小。因此测电阻时，待测电阻必须与原电路断开，不能带电测量。

\begin{center}
\input{figures/tikz/multimeter-ohm-range}

\figcaption{多用电表欧姆挡：内部有电源，电阻越小电流越大，指针越向右偏}\label{fig:multimeter-ohm-range}
\end{center}

\textbf{欧姆挡操作检查：}
\begin{enumerate}
  \item 选择合适倍率后，先把两表笔短接，调到 $0\ \Omega$，这叫欧姆调零。
  \item 欧姆刻度左大右小，左端是 $\infty$，右端是 $0$，且刻度不均匀。
  \item 换倍率后必须重新欧姆调零；测量时手不要同时接触两表笔金属部分。
\end{enumerate}

\subsection*{模型 9：电桥测量与传感器}

电桥的思想是比较两条分压支路。当中间检流计没有电流时，左右两个中点电势相等，称为\textbf{电桥平衡}。

\begin{center}
\input{figures/tikz/wheatstone-bridge}

\figcaption{惠斯通电桥：平衡时检流计无电流，可由已知电阻求未知电阻}\label{fig:wheatstone-bridge}
\end{center}

平衡条件为
\[
\boxed{\frac{R_1}{R_2}=\frac{R_3}{R_x}}.
\]
若 $R_x$ 是热敏电阻、光敏电阻或应变片，外界温度、光照或形变会使 $R_x$ 改变，电桥就从平衡变为不平衡，中间支路出现电压或电流信号。现代传感器常用这种方式把“微小变化”转化为“可测电信号”。

\section*{六、例题精讲}

\begin{examplebox}{纸带求加速度}
\textbf{题意分析：} 某纸带上相邻计数点时间间隔 $T=0.10\ \mathrm{s}$。连续三段位移分别为 $x_1=2.10\ \mathrm{cm}$、$x_2=3.05\ \mathrm{cm}$、$x_3=4.00\ \mathrm{cm}$。求加速度。

\textbf{物理模型：} 匀变速直线运动，逐差法。

\begin{center}
\input{figures/tikz/ticker-tape-example}
\end{center}

\textbf{解题过程：}
\[
a=\frac{x_3-x_1}{2T^2}.
\]
统一单位：
\[
x_3-x_1=(4.00-2.10)\ \mathrm{cm}=0.0190\ \mathrm{m}.
\]
\[
a=\frac{0.0190}{2\times0.10^2}=0.95\ \mathrm{m/s^2}.
\]

\textbf{方法总结：} 纸带题先数时间间隔，再统一单位；很多错误来自 $\Delta t$ 和 $\mathrm{cm}/\mathrm{m}$ 换算。
\end{examplebox}

\begin{examplebox}{测电源电动势和内阻}
\textbf{题意分析：} 某电源的 $U$-$I$ 图像近似为直线，纵截距 $1.50\ \mathrm{V}$，当电流从 $0$ 增大到 $0.50\ \mathrm{A}$ 时，路端电压降到 $1.25\ \mathrm{V}$。求电动势和内阻。

\textbf{物理模型：} $U=E-Ir$。

\begin{center}
\input{figures/tikz/source-ui-slope-example}
\end{center}

\textbf{解题过程：}
纵截距即
\[
E=1.50\ \mathrm{V}.
\]
斜率为
\[
k=\frac{\Delta U}{\Delta I}=\frac{1.25-1.50}{0.50-0}=-0.50\ \Omega.
\]
所以
\[
r=0.50\ \Omega.
\]

\textbf{方法总结：} $U$-$I$ 图像题先读截距再读斜率；斜率为负，内阻取绝对值。
\end{examplebox}

\begin{examplebox}{表头改装成电压表}
\textbf{题意分析：} 一只表头满偏电流 $I_g=1.0\ \mathrm{mA}$，内阻 $R_g=100\ \Omega$。若要改装成量程为 $3.0\ \mathrm{V}$ 的电压表，应串联多大的电阻？

\textbf{物理模型：} 表头改电压表，串联大电阻分压。

\begin{center}
\input{figures/tikz/meter-range-extension}
\end{center}

\textbf{解题过程：}
满偏时通过表头的电流为 $I_g$，整个电压表两端电压应为 $U=3.0\ \mathrm{V}$：
\[
U=I_g(R_g+R).
\]
所以
\[
R=\frac{U}{I_g}-R_g
=\frac{3.0}{1.0\times10^{-3}}-100
=2900\ \Omega.
\]

\textbf{方法总结：} 电压表内阻越大，对被测电路影响越小；改装电压表要串联大电阻。
\end{examplebox}

\subsection*{训练提示}
\begin{enumerate}
  \item 先数时间间隔。相邻打点时间为 $0.02\ \mathrm{s}$；“每隔 4 个点取一个计数点”通常意味着相邻计数点间有 5 个时间间隔。
  \item 先读主尺，再读游标或螺旋刻度；本题读数为 $12.0+7\times0.1=12.7\ \mathrm{mm}$。
  \item 先问实验要让哪个力近似等于合力。平衡摩擦力是为了让小车受到的合力更接近细线拉力。
  \item 先确认摆长定义。摆长应从悬点量到摆球球心，不能只量细线长度。
  \item 先比较待测电阻大小和电表内阻影响。小电阻更适合外接法，避免把电流表电阻算进待测电阻。
  \item 先看电压是否需要从近似 $0$ 连续调起；若需要，应选分压接法。
  \item 先判断表头允许电流。改装大量程电流表时，应并联小电阻分流，保护表头。
  \item 先确认外电路是否带电。欧姆挡内部已有电源，外部带电会干扰读数甚至损坏表；换倍率后要重新调零。
  \item 先把平抛轨迹写成 $y=kx^2$ 的形式；由 $y=\dfrac{g}{2v_0^2}x^2$ 得 $v_0=\sqrt{\dfrac{g}{2k}}$。
  \item 先写电桥平衡条件 $\dfrac{R_1}{R_2}=\dfrac{R_3}{R_x}$，再代入求 $R_x$。
  \item 先看误差会怎样传递。直径要平方进入截面积，直径误差会被放大，所以要多点测量取平均。
  \item 先判断元件是否线性。小灯泡灯丝温度随电流增大而升高，电阻会变化，伏安特性曲线通常不是过原点的直线。
\end{enumerate}

\section*{八、易错点}

实验题的错误通常不是计算困难，而是漏掉了测量链条中的一个环节。阅读下面清单时，可以先按三类做标记：
\begin{itemize}
  \item \textbf{读数错误：} 先查时间间隔、仪器精度、有效数字和零点误差。
  \item \textbf{模型错误：} 再查图像斜率、实验原理、待测量和控制量是否一一对应。
  \item \textbf{电路错误：} 最后查电表实际测的是谁的电压或电流，再判断内外接、分压限流和改装方向。
\end{itemize}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{把相邻点时间和计数点时间混淆：} 打点间隔常为 $0.02\ \mathrm{s}$，计数点间隔可能是它的多倍。
  \item \textbf{图像斜率没有单位：} 斜率是物理量，必须带单位。
  \item \textbf{只报结论不分析误差：} 实验题常要求解释偏大、偏小的原因。
  \item \textbf{只记实验名称不识别方法：} 陌生实验往往只是换了装置，背后仍可能使用控制变量、转换放大、等效替代或比较法。
  \item \textbf{有效数字随意写：} 结果精度不能明显超过测量仪器精度。
  \item \textbf{写出“假精度”：} 数字写得越长不代表越准确。最终结果的小数位数要和仪器分辨率、数据离散程度相匹配。
  \item \textbf{读数精度和小数位混淆：} 游标卡尺、螺旋测微器要按仪器精度读数；若有零点误差，还要先判断零点误差的正负。
  \item \textbf{把小灯泡当定值电阻：} 小灯泡工作时温度变化明显，伏安特性曲线弯曲，不能用一个恒定电阻概括全过程。
  \item \textbf{验证动量守恒时系统选错：} 应把碰撞的两个物体作为系统，并检查水平方向外力冲量是否可忽略。
  \item \textbf{光学实验角度量错基准：} 折射定律中的角度都相对法线，不是相对界面。
  \item \textbf{电表内阻被忽略：} 内外接法选择是在控制电表内阻带来的系统误差。
  \item \textbf{把限流接法和分压接法混用：} 需要电压从零开始连续调节时，通常不能只用限流接法。
  \item \textbf{电表改装方向记反：} 改电流表并联小电阻，改电压表串联大电阻。
  \item \textbf{把半偏法结论当成精确等式：} $R_s\approx R_g$ 依赖总电流近似不变，保护电阻太小会带来明显系统误差。
  \item \textbf{欧姆挡读数方向看反：} 欧姆挡右端是 $0$，左端是 $\infty$，且刻度不均匀；换倍率后要重新调零。
  \item \textbf{电桥平衡条件写反：} 先看清哪两个电阻在同一分压支路，再写比例关系，不要按固定字母顺序硬套。
  \item \textbf{平抛实验原点选错：} 平抛公式中的 $x,y$ 都应从抛出点开始量；若把桌面边缘或落地点当原点，图像斜率会失去正确物理意义。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}
\begin{competitionbox}
\textbf{线性化思想}

许多实验公式不是天然的一次函数，但可以通过变换变量变成直线。例如单摆：
\[
T=2\pi\sqrt{\frac{l}{g}}
\]
平方后得
\[
T^2=\frac{4\pi^2}{g}l.
\]
于是作 $T^2-l$ 图像，斜率就是 $\dfrac{4\pi^2}{g}$。

\textbf{竞赛与科研中的习惯：} 不只是“代入平均值”，而是尽量利用全部数据。作图、拟合、看残差，都是为了判断模型是否适合数据。高中阶段先理解“直线斜率有物理意义”这一点，就已经接近实验数据处理的核心。
\end{competitionbox}

\subsection*{1.\quad 最佳直线不是简单连点}

实验数据有偶然误差，所以图像上的点通常不会完全落在一条直线上。画最佳直线时，应让点大致均匀分布在直线两侧，而不是机械地连接第一个点和最后一个点。

\begin{center}
\input{figures/tikz/experiment-linear-fit}

\figcaption{实验图像处理：用最佳直线求斜率，减少偶然误差影响}\label{fig:experiment-linear-fit}
\end{center}

\textbf{斜率取点原则：} 计算斜率时，应在最佳直线上取相距较远的两个点，这两个点不一定是原始实验点。这样能减小读数误差对斜率的影响。

\subsection*{2.\quad 常见实验的误差方向}

\begin{center}
\begin{tabular}{lll}
\toprule
实验 & 常见误差来源 & 可能影响 \\
\midrule
单摆测 $g$ & 摆长量短、周期测量偏大 & $g$ 可能偏小 \\
机械能守恒 & 空气阻力、纸带摩擦 & 动能增加量小于势能减少量 \\
牛顿第二定律 & 摩擦未平衡完全 & 测得加速度偏小 \\

测电源内阻 & 电压表分流 & 内阻测量可能偏小 \\
\bottomrule
\end{tabular}
\end{center}

\textbf{误差判断提醒：} 误差方向不能机械记忆，要回到实验原理判断。例如伏安法内接、外接的偏差方向，取决于电压表或电流表实际测到的是谁的电压、电流。

\subsection*{3.\quad 伏安法内接、外接的误差来源}

内接法和外接法的选择，本质是尽量让电表内阻造成的系统误差更小。

\begin{center}
\input{figures/tikz/voltmeter-ammeter-error}

\figcaption{伏安法误差来源：关键是判断电压表和电流表实际测量范围}\label{fig:voltmeter-ammeter-error}
\end{center}

\begin{itemize}
  \item \textbf{内接法：} 电压表测到的是待测电阻和电流表的总电压，适合待测电阻较大时使用。
  \item \textbf{外接法：} 电流表测到的是待测电阻和电压表支路的总电流，适合待测电阻较小时使用。
  \item \textbf{判断原则：} 大电阻怕电压表分流，小电阻怕电流表分压。不能只记“内大外小”，要能说出为什么。
\end{itemize}

\subsection*{4.\quad 实验设计题的答题框架}

遇到“设计实验测某物理量”的题，可按以下顺序作答：
\begin{enumerate}
  \item 写出实验原理公式；
  \item 说明需要测量哪些物理量；
  \item 给出器材和电路/装置图；
  \item 写出主要操作步骤；
  \item 说明数据处理方法；
  \item 简要分析误差来源和减小误差的方法。
\end{enumerate}

\textbf{使用提醒：} 答题框架要按题目取舍。核心不是把步骤写多，而是说清“测什么、怎么由测量量得到目标量、误差从哪里来”。

\begin{examplebox}{由图像求重力加速度}
\textbf{题意分析：} 单摆实验得到多组摆长 $l$ 和周期 $T$，作出 $T^2-l$ 图像，斜率为 $s=4.05\ \mathrm{s^2/m}$。求当地重力加速度。

\textbf{物理模型：} 单摆周期公式平方：
\[
T^2=\frac{4\pi^2}{g}l.
\]

\textbf{解题过程：}
斜率
\[
s=\frac{4\pi^2}{g}.
\]
所以
\[
g=\frac{4\pi^2}{s}
=\frac{4\times3.14^2}{4.05}
\approx9.75\ \mathrm{m/s^2}.
\]

\textbf{方法总结：} 图像法先写斜率单位，再反推物理量单位；本题斜率单位是 $\mathrm{s^2/m}$，结果应为 $\mathrm{m/s^2}$。
\end{examplebox}

\subsection*{5.\quad 分层训练}

  \item \textbf{基础：} 为什么用多次测量求平均值可以减小偶然误差？

\section*{十、今日小结}
\begin{enumerate}
  \item 实验题先明确测量对象、直接测量量、间接公式和误差来源。
  \item 实验设计常用控制变量、转换放大、等效替代和比较法；先识别方法，再选择器材。
  \item 纸带法通过相等时间内位移变化研究匀变速运动。
  \item 光电门用遮光片宽度和遮光时间估测瞬时速度，对应近似关系 $v\approx d/\Delta t$。
  \item 平抛实验要先定原点和坐标轴，再用 $y$ 与 $x^2$ 的线性关系检验模型或求水平初速度。
  \item 长度读数要看仪器精度：游标卡尺看对齐格，螺旋测微器看固定刻度和可动刻度，并注意零点误差。
  \item 估读和不确定度说明：测量结果的有效数字必须和仪器分辨能力相匹配。
  \item 典型实验要能迁移：测电阻率、小灯泡伏安特性、玻璃折射率、凸透镜焦距和双缝测波长，都可按“直接测量量 + 物理关系 + 误差判断”整理。
  \item 验证动量守恒要选对系统，并尽量减小水平方向外力冲量。
  \item 电学实验先判断电压表分流还是电流表分压，再确定系统误差方向。
  \item 滑动变阻器有限流和分压两类接法；是否需要从零调起是重要判断依据。
  \item 表头改装遵循分流、分压思想：电流表并联小电阻，电压表串联大电阻。
  \item 半偏法可近似测表头内阻，但成立前提是调节过程中总电流近似不变。
  \item 多用电表欧姆挡内部有电源，测前要欧姆调零，刻度左大右小且不均匀。
  \item 电桥测量利用平衡条件比较电阻，传感器可把电阻微小变化转化为电信号。
  \item 图像法的关键是斜率、截距和面积的物理意义。
  \item 规范表达包括单位、有效数字、坐标轴、结论和误差分析。
\end{enumerate}

\textbf{一分钟复盘：} 拿一道实验题，按“测什么、直接测哪些量、用什么公式转化、主要误差从哪里来”四句话复述；能复述清楚再写步骤。
