\daytitle{17}{带电粒子在电场中的运动}

\begin{learningbox}{本讲义大致内容}
把前两天的电场知识和运动学知识结合起来——带电粒子在电场中会怎样运动？
加速电场中粒子的速度变化，偏转电场中的类平抛运动。示波管的原理也基于此。
\end{learningbox}

\section*{一、学习目标}

\begin{enumerate}
  \item 掌握带电粒子在加速电场中的运动：从静止出发且电场力做正功时，$\lvert q\rvert U = \dfrac12 mv^2$。
  \item 掌握带电粒子在偏转电场中的类平抛运动分析。
  \item 会计算粒子的偏转位移和偏转角。
  \item 理解示波管的基本原理。
  \item 能区分带电粒子的“先加速后偏转”综合问题。
\end{enumerate}

\section*{二、初高中衔接}

初中没有涉及带电粒子运动的内容。本节是电场和运动学的第一次综合——把 Day 02-04 的运动学公式和 Day 15-16 的电场知识结合起来。

\textbf{核心思路：}
\[
\text{电场力 } F = |q|E \;\to\; \text{加速度大小 } a = \frac{F}{m} = \frac{|q|E}{m} \;\to\; \text{方向另判}
\]

\textbf{科学发展视角：} 带电粒子在电场中的加速和偏转，是电子束、离子注入、粒子探测器和质谱分析的基础。高中阶段先把它看成“电场力 + 运动学”的组合模型，后面进入磁场后，就能理解科学仪器如何用电场和磁场一起控制粒子轨迹。

\section*{三、核心概念}

\begin{conceptbox}{加速电场}

带电粒子在匀强电场中加速，电场力做正功，动能增加。计算速度大小时，通常把 $q$ 理解为电荷量大小；运动方向由电荷正负和电场方向判断。

\begin{center}
\input{figures/tikz/accelerating-field}

\figcaption{加速电场：电场力做功转化为粒子动能}\label{fig:accelerating-field}
\end{center}

\textbf{核心公式（初速为零，电场力做正功）：}
\[
\boxed{\lvert q\rvert U = \frac12 mv^2}
\]

\begin{itemize}
  \item $U$：加速电压。
  \item $\lvert q\rvert$：粒子电荷量大小。若使用带符号电荷量，应先判断电场力做功正负。
  \item 在只看电场力做功、忽略碰撞和相对论效应的模型中，粒子的末速度 $v = \sqrt{\dfrac{2\lvert q\rvert U}{m}}$ 与加速距离无关。
\end{itemize}

如果粒子有初速度 $v_0$：
\[
\lvert q\rvert U = \frac12 mv^2 - \frac12 mv_0^2
\]
这里的 $\lvert q\rvert U$ 表示电场力做的正功；若电场力做负功，粒子动能减少，应改用带符号的 $W_{\text{电}}=\Delta E_k$。

\end{conceptbox}

\begin{conceptbox}{偏转电场（类平抛）}

带电粒子以初速度 $v_0$ 垂直射入匀强电场，做类平抛运动。

\begin{center}
\input{figures/tikz/deflection-field}

\figcaption{偏转电场：粒子轨迹为抛物线}\label{fig:deflection-field}
\end{center}

\textbf{分析方法：} 正交分解
\begin{itemize}
  \item $x$ 方向（匀速）：$x = v_0 t$。
  \item $y$ 方向（匀加速）：若 $q$ 带符号，$a_y = \dfrac{qE}{m} = \dfrac{qU}{md}$，$y = \dfrac12 a_y t^2$ 可直接表示偏转方向；若只求大小，则用 $\lvert a_y\rvert=\dfrac{|q|E}{m}$。
\end{itemize}

\textbf{偏转位移（极板长 $L$，粒子从极板中心射入，忽略重力和边缘场）：}
\[
y = \frac12 \cdot \frac{qU}{md} \cdot \left(\frac{L}{v_0}\right)^2
\]

\textbf{偏转角 $\theta$（出射方向与水平方向的夹角）：}
\[
\tan\theta = \frac{v_y}{v_0} = \frac{qUL}{md v_0^2}
\]

\end{conceptbox}

\section*{五、典型模型}

\subsection*{模型 1：先加速后偏转}

粒子先经过加速电压 $U_1$ 加速，再进入偏转电压 $U_2$ 的偏转电场。

\begin{center}
\input{figures/tikz/accelerate-deflect-model}

\figcaption{先加速后偏转模型：$U_1$ 决定入射速度，$U_2$ 决定偏转大小}\label{fig:accelerate-deflect-model}
\end{center}

加速：$\lvert q\rvert U_1 = \frac12 mv_0^2 \;\Rightarrow\; v_0^2 = \frac{2\lvert q\rvert U_1}{m}$

偏转位移：
\[
y = \frac{U_2 L^2}{4U_1 d}
\]
在粒子从静止经同一加速电压加速、进入同一理想偏转电场并忽略重力和相对论效应时，偏转位移与 $q$、$m$ 无关，这是示波管能工作的核心原因。

\subsection*{模型 2：示波管}

示波管可以看成“先加速后两次偏转”的装置。电子枪发射电子，电子先经加速电场获得较大的水平速度，再依次经过两对偏转板，最后打在荧光屏上形成亮点。

\begin{center}
\input{figures/tikz/oscilloscope-model}

\figcaption{示波管模型：加速、偏转、屏幕成像}\label{fig:oscilloscope-model}
\end{center}

\begin{itemize}
  \item \textbf{加速电场：} 决定电子进入偏转系统前的速度 $v_0$。电子带负电，受力方向与电场方向相反。
  \item \textbf{$Y$ 偏转板：} 控制亮点的上下位置，通常接入待观测的信号电压。
  \item \textbf{$X$ 偏转板：} 控制亮点的左右位置，常接扫描电压。
  \item \textbf{荧光屏：} 电子打到屏上形成亮点，亮点随时间移动就形成图像。
\end{itemize}

\subsection*{模型 3：离开偏转电场后的无场区运动}

粒子在偏转电场内做类平抛运动；离开极板后若进入无场区，就沿出射速度方向做匀速直线运动。因此屏幕上的总偏移通常由两部分组成：
\[
Y = y_1 + y_2
\]
其中 $y_1$ 是极板内偏转，$y_2$ 是离开极板后在无场区继续“斜着飞”产生的偏移。

\begin{center}
\input{figures/tikz/post-deflection-drift}

\figcaption{离开偏转电场后的无场区：沿出射速度方向匀速直线运动}\label{fig:post-deflection-drift}
\end{center}

匀强电场中的电场力方向恒定，一般不会像圆周运动的向心力那样始终指向圆心，所以本节不把“圆周运动”作为主模型。

\section*{六、例题精讲}

\begin{examplebox}{加速电场}

\textbf{题意分析：} 一个电子从静止开始被 $U = 500\ \mathrm{V}$ 的电压加速。已知 $e = 1.6 \times 10^{-19}\ \mathrm{C}$，$m_e = 9.1 \times 10^{-31}\ \mathrm{kg}$。求电子加速后的速度。

\textbf{物理模型：} 加速电场，$\lvert q\rvert U = \frac12 mv^2$。

\textbf{解题过程：}

\[
\begin{aligned}
v &= \sqrt{\frac{2eU}{m}}
= \sqrt{\frac{2 \times 1.6 \times 10^{-19} \times 500}{9.1 \times 10^{-31}}} \\
&= \sqrt{1.76 \times 10^{14}}
\approx 1.33 \times 10^7\ \mathrm{m/s}
\end{aligned}
\]

\textbf{方法总结：} 电子的质量很小，$500\ \mathrm{V}$ 的电压就能让它加速到 $10^7\ \mathrm{m/s}$ 量级。但即使如此，远小于光速 $3 \times 10^8\ \mathrm{m/s}$，不需用相对论修正。

\end{examplebox}

\begin{examplebox}{偏转电场}

\textbf{题意分析：} 电子以 $v_0 = 3 \times 10^7\ \mathrm{m/s}$ 水平射入两平行板间。极板长 $L = 0.06\ \mathrm{m}$，间距 $d = 0.02\ \mathrm{m}$，电压 $U = 200\ \mathrm{V}$。求：
\begin{enumerate}
  \item 电子在电场中的运动时间。
  \item 电子的偏转位移。
  \item 出射时的偏转角。
\end{enumerate}

\textbf{物理模型：} 类平抛运动。

\textbf{解题过程：}

\begin{enumerate}
  \item $t = \frac{L}{v_0} = \frac{0.06}{3 \times 10^7} = 2 \times 10^{-9}\ \mathrm{s}$
  
  \item $a = \frac{eU}{md} = \frac{1.6 \times 10^{-19} \times 200}{9.1 \times 10^{-31} \times 0.02} \approx 1.76 \times 10^{15}\ \mathrm{m/s^2}$
  
  $y = \frac12 a t^2 = \frac12 \times 1.76 \times 10^{15} \times (2 \times 10^{-9})^2 = 3.52 \times 10^{-3}\ \mathrm{m} = 3.52\ \mathrm{mm}$
  
  \item $\tan\theta = \frac{v_y}{v_0} = \frac{at}{v_0} = \frac{1.76 \times 10^{15} \times 2 \times 10^{-9}}{3 \times 10^7} \approx 0.117$
  
  $\theta \approx \arctan 0.117 \approx 6.7^\circ$
\end{enumerate}

\textbf{方法总结：} 偏转电场的关键是把运动分解为匀速和匀加速两个方向分别处理，数学处理与平抛运动相同，但加速度方向要由电荷正负和电场方向判断。

\end{examplebox}

\begin{examplebox}{先加速后偏转}

\textbf{题意分析：} 电子从静止经 $U_1 = 1000\ \mathrm{V}$ 加速，然后垂直进入 $U_2 = 100\ \mathrm{V}$ 的偏转电场。极板长 $L = 0.05\ \mathrm{m}$，间距 $d = 0.01\ \mathrm{m}$。求电子的偏转位移。

\textbf{物理模型：} 先加速后偏转。

\begin{center}
\input{figures/tikz/accelerate-deflect-example}

\figcaption{例题示意：先由 $U_1$ 加速，再由 $U_2$ 偏转}\label{fig:accelerate-deflect-example}
\end{center}

\textbf{解题过程：}

加速后速度 $v_0^2 = \dfrac{2eU_1}{m}$

偏转位移：
\[
y = \frac12 \frac{eU_2}{md} \left(\frac{L}{v_0}\right)^2
= \frac12 \frac{eU_2}{md} \cdot \frac{L^2 m}{2eU_1}
= \frac{U_2 L^2}{4U_1 d}
\]

代入：
\[
y = \frac{100 \times (0.05)^2}{4 \times 1000 \times 0.01} = \frac{100 \times 0.0025}{40} = \frac{0.25}{40} = 0.00625\ \mathrm{m} = 6.25\ \mathrm{mm}
\]

\textbf{方法总结：} 先加速后偏转问题中，在粒子从静止经同一加速电压加速、进入同一偏转电场且忽略重力和相对论效应时，偏转位移 $y = \dfrac{U_2 L^2}{4U_1 d}$ 与粒子的 $q$、$m$ 无关。若粒子电性相反，偏转方向相反。

\end{examplebox}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{把电场力加速度和重力加速度混淆：} 带电粒子在电场中的加速度大小 $a = \dfrac{|q|E}{m}$，不是 $g$。$g$ 只在重力作用下才有，方向要由电荷正负和电场方向判断。
  
  \item \textbf{偏转电场中忘记 $x$ 方向是匀速运动：} $x$ 方向不受力（重力一般忽略），是匀速直线运动，不能写成匀加速。
  
  \item \textbf{混淆加速电压和偏转电压：} 加速 $U_1$ 决定 $v_0$ 的大小，偏转 $U_2$ 决定偏转位移。两者互不干扰。

  \item \textbf{有初速度时仍套 $\lvert q\rvert U=\frac12mv^2$：} 这个式子只适用于从静止开始、且电场力做正功的情形。若粒子已有初速度，应写成 $W_{\text{电}}=\Delta E_k=\frac12mv^2-\frac12mv_0^2$，并先判断电场力做功正负。
  
  \item \textbf{忽略重力的条件：} 微观粒子（电子、质子、离子）在电场中通常忽略重力。但带电液滴、带电小球不能忽略。
  
  \item \textbf{偏转公式中的 $L$ 是极板长度：} 偏转位移公式中的 $L$ 是极板长度，不是极板到屏的距离。屏幕上总的偏移需要另外计算。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{带电粒子在交变电场中的运动}

如果偏转电场是交变的（如示波器中的锯齿波或正弦波电压），粒子的偏转位移随时间变化，在荧光屏上形成图像。

\begin{center}
\input{figures/tikz/alternating-field-trace}

\figcaption{交变偏转电场：扫描电压把时间展开，信号电压决定上下偏转}\label{fig:alternating-field-trace}
\end{center}

\textbf{关键思路：} 粒子穿过偏转电场的时间 $t = L/v_0$ 非常短（通常 $< 10^{-8}\ \mathrm{s}$），而交变电压的周期 $T$ 往往长得多，所以单个粒子通过极板时，可以近似认为电压不变。不同时间发出的电子对应不同瞬时电压，打在屏幕上的位置不同，连续起来就形成图像。

\textbf{例题：} 示波器中 $x$ 偏转板加锯齿波电压（扫描电压），$y$ 偏转板加正弦信号电压。电子打在屏上的轨迹是什么？

\textbf{解：} $y$ 方向偏转与正弦电压成正比，亮点随信号电压上下运动；$x$ 方向偏转与锯齿波扫描电压成正比，亮点随时间近似匀速向右运动。因此屏上把“随时间变化的正弦电压”展开成一条正弦曲线。

\textbf{进一步理解：} 如果扫描电压周期与信号周期匹配，每次扫描画出的曲线重合，屏幕上看到稳定波形；如果二者不同步，波形会左右移动或变得不稳定。

\textbf{竞赛小贴士：} 处理交变电场问题时，先判断粒子经过电场的时间与交变周期的关系。如果 $t \ll T$，可以对单个粒子近似为恒定电场；再把不同时刻的粒子落点按时间顺序连起来。
\end{competitionbox}

\section*{十、今日小结}

\begin{enumerate}
  \item 加速电场的通式是 $W_{\text{电}}=\Delta E_k$；从静止开始且电场力做正功时，才化为 $\lvert q\rvert U = \frac12 mv^2$。
  \item 偏转电场：类平抛运动，$x$ 方向匀速 $x = v_0 t$，$y$ 方向匀加速 $a = \dfrac{qE}{m}$。
  \item 偏转位移 $y = \dfrac12 \dfrac{qU}{md}\left(\dfrac{L}{v_0}\right)^2$，与 $q$、$m$ 有关。
  \item 先加速后偏转：在从静止加速、同一偏转电场且忽略重力和相对论效应时，$y = \dfrac{U_2 L^2}{4 U_1 d}$，与 $q$、$m$ 无关。
  \item 微观粒子忽略重力，宏观带电物体要考虑重力。
\end{enumerate}
