\daytitle{18}{电容器与电场能量入门}

\begin{learningbox}{本节导读}
电容器是储存电荷和电场能量的元件。本节学习电容的定义、平行板电容器的公式、电容器的充放电，以及在电路中的两种典型连接方式。这些是电磁学实验和高考电磁综合题的基础。
\end{learningbox}

\textbf{本节读题路线：} 先判断电容器是接着电源还是已经断开，这一步决定优先固定 $U$ 还是 $Q$；理想电源保持接通时电压 $U$ 常不变，充电后断开且无漏电、无外接导通回路时电荷量 $Q$ 才近似不变。再由 $C$、$Q$、$U$、$E$ 的关系逐步推出变化，不要把决定式和定义式混用。

\section*{一、学习目标}

\begin{enumerate}
  \item 能用 $C = \dfrac{Q}{U}$ 描述电容，并说明 $Q$ 是单个极板所带电荷量的大小。
  \item 能说明平行板电容器决定式 $C = \dfrac{\varepsilon_r S}{4\pi k d}$ 中面积、距离和介质的作用。
  \item 能判断电容器充放电过程中 $Q$、$U$、$E$ 的变化。
  \item 能分析电容器在电路中的两种典型情形（电源接通/断开）。
  \item 能用图像或能量观点说明电容器储存的电场能量 $E = \dfrac12 CU^2$。
\end{enumerate}
\section*{二、初高中衔接}

初中阶段只定性接触过“电容器能储存电荷”——这是一个定性概念。

高中要把电容器量化：
\begin{itemize}
  \item 电容 $C$ 表示电容器“储存电荷的能力”。
  \item 平行板电容器的大小由极板面积 $S$、距离 $d$、介质 $\varepsilon_r$ 决定。
  \item 电容器中储存电场能量——这是很多电子设备（闪光灯、电源滤波）的基础。
\end{itemize}

\textbf{科学发展视角：} 电容器不仅是电路元件，也是传感器和储能元件。手机触控、相机闪光灯、电源滤波、超级电容储能都与电容有关。学习电容器时，要同时关注两个问题：它能储存多少电荷，也能储存多少电场能。

\section*{三、核心概念}

\begin{conceptbox}{电容}

\textbf{定义：} 电容器单个极板所带电荷量的大小 $Q$ 与两极板间电势差 $U$ 的比值。
\[
\boxed{C = \frac{Q}{U}}
\]

\begin{itemize}
  \item 单位：法拉（$\mathrm{F}$），$1\ \mathrm{F} = 1\ \mathrm{C/V}$。
  \item 常用单位：$1\ \mu\mathrm{F} = 10^{-6}\ \mathrm{F}$，$1\ \mathrm{pF} = 10^{-12}\ \mathrm{F}$。
  \item 对结构和介质确定的电容器，$C$ 由电容器本身决定，与已带电荷量 $Q$ 和两端电压 $U$ 无关。
\end{itemize}

\textbf{平行板电容器的决定式：}
\[
\boxed{C = \frac{\varepsilon_r S}{4\pi k d}}
\]

\begin{itemize}
  \item $S$：极板正对面积。
  \item $d$：极板间距。
  \item $\varepsilon_r$：相对介电常数（真空 $\varepsilon_r = 1$）。
  \item $k = 9.0 \times 10^9$（静电力常量）。
\end{itemize}

\textbf{决定式的来源：} 对理想平行板电容器，若极板足够大、板间距远小于极板尺寸并忽略边缘效应，板间电场可近似为匀强电场。若两板分别带电 $\pm Q$（$Q$ 表示单个极板电荷量的大小），正对面积为 $S$，板间充满均匀介质（相对介电常数为 $\varepsilon_r$），则板间场强可写成
\[
E=\frac{4\pi kQ}{\varepsilon_r S}.
\]
两板间电势差
\[
U=Ed=\frac{4\pi kQd}{\varepsilon_r S}.
\]
代入电容定义 $C=\dfrac{Q}{U}$，得
\[
C=\frac{Q}{U}=\frac{\varepsilon_r S}{4\pi k d}.
\]
因此 $C$ 不是由已经带了多少电荷决定的，而是由“板有多大、离多远、中间是什么介质”决定的。

\textbf{结论：} $S$ 越大 $C$ 越大，$d$ 越大 $C$ 越小。

\begin{conceptbox}{电容器的充放电}

\begin{center}
\input{figures/tikz/capacitor-circuit}

\figcaption{电容器 $RC$ 充放电回路：电流方向和大小随过程变化}\label{fig:capacitor-circuit}
\end{center}

\textbf{充电过程：}
\begin{itemize}
  \item 闭合开关 $K$，电源将电荷从一极板移到另一极板。
  \item $Q$ 增加，$U$ 增加，$E$（场强）增加。
  \item 充电电流从大到小，最后为零（电容器充满）。
\end{itemize}

\textbf{放电过程：}
\begin{itemize}
  \item 用导线连接两极板，电荷中和。
  \item $Q$ 减少，$U$ 减少，$E$ 减少。
  \item 放电电流从大到小，最后为零。
\end{itemize}

\begin{center}
\input{figures/tikz/capacitor-current-time}

\figcaption{电容器充放电的 $i$-$t$ 图像：图线与时间轴围成的面积表示电荷量变化}\label{fig:capacitor-current-time}
\end{center}

\textbf{面积意义：} 电流定义为单位时间通过导体横截面的电荷量，即 $i=\dfrac{\Delta Q}{\Delta t}$。因此在 $i$-$t$ 图像中，图线与时间轴围成的面积表示电荷量变化：
\[
\Delta Q=\int i\,dt.
\]
充电时面积等于电容器增加的电荷量；若把充电方向规定为正方向，放电电流为负，放电图像的有向面积为 $-Q_0$，面积的绝对值表示放出的电荷量。

\end{conceptbox}

\begin{conceptbox}{电容器的两类典型问题}

\begin{center}
\input{figures/tikz/capacitor-dynamic}

\figcaption{电容器动态分析：先判断不变量，再沿公式链条推变化}\label{fig:capacitor-dynamic}
\end{center}

\textbf{情况 1：电容器与电源保持连接}
\begin{itemize}
  \item $U$ 不变（始终等于电源电压）。
  \item $d \uparrow \Rightarrow C \downarrow \Rightarrow Q \downarrow \Rightarrow E \downarrow$。
  \item $S \uparrow \Rightarrow C \uparrow \Rightarrow Q \uparrow \Rightarrow E$ 不变。
\end{itemize}

\textbf{情况 2：电容器充电后与电源断开}
\begin{itemize}
  \item $Q$ 不变（电荷无处可去）。
  \item $d \uparrow \Rightarrow C \downarrow \Rightarrow U \uparrow \Rightarrow E$ 不变（$E = \dfrac{U}{d} \propto \dfrac{Q}{S}$）。
  \item $S \uparrow \Rightarrow C \uparrow \Rightarrow U \downarrow \Rightarrow E \downarrow$。
\end{itemize}

\textbf{关键结论：} 在上述理想平行板模型中，$E = \dfrac{U}{d} = \dfrac{4\pi k Q}{\varepsilon_r S}$。$Q$ 不变时，板间中部的匀强场强与 $d$ 无关，只与 $Q$、$S$ 和介质有关。

\textbf{插入电介质的特殊判断：} 若 $S$、$d$ 不变，只把空气换成相对介电常数 $\varepsilon_r>1$ 的电介质，则
\[
C'=\varepsilon_r C.
\]
\begin{center}
\input{figures/tikz/capacitor-dielectric-insertion}

\figcaption{插入电介质：结构不变时电容增大，仍先判断 $U$ 不变还是 $Q$ 不变}\label{fig:capacitor-dielectric-insertion}
\end{center}

\begin{itemize}
  \item \textbf{接电源：} $U$ 不变，$C$ 增大，所以 $Q=CU$ 增大；若 $d$ 不变，$E=U/d$ 不变。
  \item \textbf{断电源：} $Q$ 不变，$C$ 增大，所以 $U=Q/C$ 减小；若 $d$ 不变，$E=U/d$ 减小。
\end{itemize}

\textbf{方法提醒：} 介质问题不能只记“电容变大”。实际处理时仍按同一条路线：先定不变量，再由 $C=\dfrac{\varepsilon_r S}{4\pi kd}$、$Q=CU$、$E=U/d$ 推出变化。

\end{conceptbox}

\begin{conceptbox}{电容器的电场能量}

电容器充电过程中，电源做功将电荷从一极板搬运到另一极板，能量以电场能的形式储存在电容器中。

\begin{center}
\input{figures/tikz/capacitor-energy-area}

\figcaption{电容器能量来源：$U$ 随 $Q$ 线性增大，面积表示储存的电场能}\label{fig:capacitor-energy-area}
\end{center}

\[
\boxed{E_C = \frac12 CU^2 = \frac12 QU = \frac{Q^2}{2C}}
\]

\begin{itemize}
  \item 这个公式和弹簧的弹性势能 $\frac12 kx^2$ 形式上相似。
  \item 充放电过程中电场能量和电路中的其他能量相互转化。
\end{itemize}

\end{conceptbox}

\begin{learningbox}{电容器动态题的三步分析清单}
电容器动态题先确定约束条件，再写变量变化顺序。比较稳的做法是先写“谁不变”，再写“谁先变”：
\begin{enumerate}
  \item \textbf{先定不变量：} 接着电源，通常 $U$ 不变；充电后断开电源，通常 $Q$ 不变。
  \item \textbf{再看结构量：} $S$、$d$、$\varepsilon_r$ 的改变先影响 $C=\dfrac{\varepsilon_r S}{4\pi kd}$。
  \item \textbf{最后顺着关系推：} 用关系式逐步判断：
  \[
  Q=CU,\qquad E=\frac{U}{d},\qquad
  E=\frac{4\pi kQ}{\varepsilon_r S}\ \text{（断电的理想平行板）}.
  \]
\end{enumerate}
如果题目问能量，再根据已知量选择
\[
E_C=\frac12 CU^2=\frac12 QU=\frac{Q^2}{2C}.
\]
接电源时电源会参与能量转化，断电源时通常只在电容器和外力之间转化，二者不要混在一起。
\end{learningbox}

\section*{五、典型模型}

\subsection*{模型 1：平行板电容器的动态分析}

先说明“不变量”来自哪里：接着电源时，电源把两板间电压维持为 $U$，所以通常先取 $U$ 不变；充电后断开电源时，极板没有外部通路补充或带走净电荷，所以通常先取 $Q$ 不变。再由 $C$ 的变化推出 $Q$（或 $U$）的变化。

\textbf{三类变化都按同一顺序处理：}
\[
d,\ S,\ \varepsilon_r \quad\Longrightarrow\quad C
\quad\Longrightarrow\quad Q\text{ 或 }U
\quad\Longrightarrow\quad E .
\]
其中插入电介质对应 $\varepsilon_r$ 增大，电容增大。

\subsection*{模型 2：电容器与力学综合}

带电粒子在平行板电容器间的运动（结合 Day 17 的偏转知识）。改变电容器参数会影响粒子的偏转位移。

\textbf{建模接口：} 先由电容器状态确定板间场强，再把它交给力学模型：
\[
\text{接电源： } E=\frac{U}{d},\qquad
\text{断电源： } E=\frac{4\pi kQ}{\varepsilon_r S}.
\]
然后用 $a=\dfrac{qE}{m}$ 判断带电粒子的加速度方向和大小。这一步把问题分成两层：电容器先决定“场从哪里来”，粒子运动再决定“受力后怎样运动”。

\subsection*{模型 3：电容器的串并联}

\begin{center}
\input{figures/tikz/capacitor-series-parallel}

\figcaption{电容器并联与串联：并联同压，串联同荷}\label{fig:capacitor-series-parallel}
\end{center}

\textbf{并联推导：} 并联时两个电容器接在同一对节点上，所以两端电压相同，均为 $U$。总电荷量等于各电容器所带电荷量之和：
\[
Q_{\text{总}}=Q_1+Q_2=C_1U+C_2U=(C_1+C_2)U.
\]
又因为 $Q_{\text{总}}=C_{\text{总}}U$，所以
\[
\boxed{C_{\text{总}}=C_1+C_2}.
\]

\textbf{串联推导：} 串联时中间连接的极板总电荷不能凭空产生或消失，稳定后每个电容器所带电荷量大小相同，记为 $Q$。总电压等于两个电容器电压之和：
\[
U=U_1+U_2=\frac{Q}{C_1}+\frac{Q}{C_2}
=Q\left(\frac{1}{C_1}+\frac{1}{C_2}\right).
\]
又因为 $U=\dfrac{Q}{C_{\text{总}}}$，所以
\[
\boxed{\frac{1}{C_{\text{总}}}=\frac{1}{C_1}+\frac{1}{C_2}}.
\]

\textbf{理解方式：} 电容器并联相当于增大正对面积，电容变大；电容器串联相当于增大等效板间距，电容变小。

\section*{六、例题精讲}

\begin{examplebox}{电容的计算}

\textbf{题意分析：} 一个平行板电容器，极板面积 $S = 0.02\ \mathrm{m^2}$，间距 $d = 0.001\ \mathrm{m}$，真空介电常数 $\varepsilon_0 = 1/(4\pi k)$。求电容 $C$。

\textbf{物理模型：} 平行板电容器。

\textbf{解题过程：}

\[
\begin{aligned}
C &= \frac{S}{4\pi k d}
 = \frac{0.02}{4 \times 3.14 \times 9 \times 10^9 \times 0.001} \\
&\approx \frac{0.02}{1.13 \times 10^8}
 \approx 1.77 \times 10^{-10}\ \mathrm{F}
 = 177\ \mathrm{pF}
\end{aligned}
\]

\textbf{方法总结：} 电容器计算先统一单位：$S$ 用 $\mathrm{m^2}$，$d$ 用 $\mathrm{m}$；结果再换成 $\mathrm{pF}$ 或 $\mu\mathrm{F}$ 等常用单位。

\end{examplebox}

\begin{examplebox}{电容器的动态分析}

\textbf{题意分析：} 平行板电容器充电后与电源保持连接。若将两极板间距增大为原来的 2 倍，求 $C$、$Q$、$E$ 的变化。

\textbf{物理模型：} 接电源，$U$ 不变。

\textbf{解题过程：}

$d' = 2d$，$C \propto \dfrac{1}{d}$，所以 $C' = \dfrac{C}{2}$。

$Q = CU$，$U$ 不变，所以 $Q' = \dfrac{Q}{2}$。

$E = \dfrac{U}{d}$，$U$ 不变、$d$ 加倍，所以 $E' = \dfrac{E}{2}$。

\textbf{方法总结：} 动态题第一步先判断是否接电源。接电源时 $U$ 不变，再由 $C \propto \dfrac{1}{d}$ 推出其他量。

\end{examplebox}

\begin{examplebox}{电容器与电源断开}

\textbf{题意分析：} 上题中若充电后断开电源再增大极板间距，结果如何？

\textbf{物理模型：} 断电源，$Q$ 不变。

\textbf{解题过程：}

$d' = 2d$，$C' = C/2$（与上题相同）。

$U = \dfrac{Q}{C}$，$Q$ 不变，$C$ 减半，所以 $U' = 2U$。

$E = \dfrac{U}{d} = \dfrac{4\pi k Q}{\varepsilon_r S}$，在理想平行板模型中与 $d$ 无关，所以 $E' = E$。

\textbf{方法总结：} 断电后先固定 $Q$ 不变；在理想平行板且忽略边缘效应时，改变 $d$ 不改变板间中部场强。

\end{examplebox}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{电容 $C$ 由 $Q$、$U$ 决定还是由电容器本身决定：} 先区分量度式和决定式。$C=\dfrac{Q}{U}$ 用来量度电容，结构确定时 $C$ 由极板面积、间距和介质决定。
  
  \item \textbf{动态分析中分不清 $U$ 不变还是 $Q$ 不变：} 第一步先看电容器是否仍接电源：理想电源保持接通且电压恒定时 $U$ 不变；充电后与电源断开、又没有漏电或外接导通回路时，极板所带电荷量 $Q$ 才近似不变。
  
  \item \textbf{误以为 $E = \dfrac{U}{d}$ 在所有情况下都与 $d$ 有关：} 对充电后断开电源、漏电可忽略的理想平行板电容器，若只改变板间距而保持极板电荷量 $Q$ 不变，则 $E$ 与 $d$ 无关——因为 $U$ 和 $d$ 成比例变化抵消了。
  
  \item \textbf{单位换算错误：} $1\ \mu\mathrm{F} = 10^{-6}\ \mathrm{F}$，$1\ \mathrm{pF} = 10^{-12}\ \mathrm{F}$。计算前先统一单位。
  
  \item \textbf{忽略介电常数 $\varepsilon_r$：} 插入电介质（$\varepsilon_r > 1$）会使电容增大。真空或空气中 $\varepsilon_r \approx 1$。

  \item \textbf{插入介质后忘记不变量：} 先写 $C$ 变大，再按接电源或断电源判断 $U$、$Q$、$E$ 如何连锁变化。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{电容器的能量与电场力的功}

电容器储存的能量 $E_C = \dfrac12 CU^2$。如果电容器极板在力的作用下移动，要先分清做功对象：电场力做功 $W_{\text{电场}} = -\Delta E_C$，外力缓慢拉开极板时做功 $W_{\text{外}} = \Delta E_C$。

\textbf{例题：} 平行板电容器充电后（$Q$ 不变），极板间的作用力 $F$ 是多少？

\textbf{解：} 考虑极板距离增大一小段 $\Delta d$，电场能量变化 $\Delta E_C = \dfrac{Q^2}{2C'}-\dfrac{Q^2}{2C}$。由 $C = \dfrac{\varepsilon_r S}{4\pi k d}$ 可得
\[
E_C = \frac{Q^2}{2C} = \frac{2\pi k Q^2 d}{\varepsilon_r S}
\]
因此电场力沿“使 $d$ 减小”的方向，吸引力大小为：
\[
F_{\text{引}} = \left|\frac{dE_C}{dd}\right| = \frac{2\pi k Q^2}{\varepsilon_r S}
\]
在理想平行板、$Q$ 不变且忽略边缘效应时，极板间为引力，大小与 $d$ 无关。

\textbf{竞赛提示：} 处理电容器极板受力问题时，用虚功原理（能量法）比直接用 $F = QE$ 更可靠——因为某一极板受力只来自另一极板产生的电场，不能把两板间的合场强直接代入。
\end{competitionbox}

\section*{十、今日小结}

\begin{enumerate}
  \item 电容 $C = \dfrac{Q}{U}$，平行板电容器 $C \propto \dfrac{S}{d}$，与介质有关。
  \item 接电源 $\to$ $U$ 不变；断电源 $\to$ $Q$ 不变。
  \item 插入电介质使 $\varepsilon_r$ 增大，从而使 $C$ 增大；再按不变量判断 $Q$、$U$、$E$。
  \item 理想平行板电容器断电后 $Q$ 不变；忽略边缘效应时，板间中部场强 $E$ 与 $d$ 无关。
  \item 电容器储存电场能量 $E_C = \dfrac12 CU^2$。
  \item 电容器串并联计算方法与电阻相反。
\end{enumerate}

\textbf{一分钟复盘：} 做电容器动态题前，先写下“不变量”：接电源看 $U$，断电源看 $Q$。再画一条变量链：板距或面积变化 $\to C$ 变化 $\to Q/U$ 变化 $\to E$ 与能量变化；每一步都标出使用的公式。
