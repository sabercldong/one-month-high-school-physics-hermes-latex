\daytitle{22}{洛伦兹力与带电粒子在磁场中的运动}

\begin{learningbox}{本节导读}
上一节的安培力研究的是磁场对一段电流的作用。电流本质上是大量电荷的定向移动，所以本节进一步研究磁场对单个运动电荷的作用：洛伦兹力。重点是方向判断、圆周运动半径和周期、磁场边界中的几何关系，以及速度选择器、质谱仪等现代科学装置的物理原理。
\end{learningbox}

\textbf{本节读题路线：} 先判断洛伦兹力方向，确定粒子的偏转方向；再用“不做功”判断速率是否变化；最后把弯曲轨迹看成圆周运动的一段，用圆心、半径和圆心角解决几何问题。这样学，半径公式和周期公式就不再是孤立结论，而是受力图与圆周运动方程的直接结果。

\section*{一、学习目标}
\begin{enumerate}
  \item 理解洛伦兹力是磁场对运动电荷的作用力。
  \item 掌握洛伦兹力公式 $F=|q|vB\sin\theta$ 和方向判断方法。
  \item 理解磁场洛伦兹力不做功，只改变速度方向，不改变速率。
  \item 掌握带电粒子在匀强磁场中的匀速圆周运动：$r=\dfrac{mv}{|q|B}$，$T=\dfrac{2\pi m}{|q|B}$。
  \item 会分析粒子进入有界磁场时的圆心、半径、偏转角和运动时间。
  \item 了解回旋加速器中“电场加速、磁场转弯”的基本分工。
\end{enumerate}
\section*{二、初高中衔接}

Day 17 中，带电粒子在匀强电场中受到电场力，可能做类平抛运动。磁场中的情况很不同：
\begin{itemize}
  \item 电场力对正电荷沿电场方向、对负电荷反向，可能改变速率；
  \item 磁场力（高中常称洛伦兹力）始终垂直于速度方向，只改变速度方向；
  \item 电场力可以改变粒子动能，只有磁场力单独作用时，粒子速率不变。
\end{itemize}

因此，磁场题的核心不是“速率怎么增大”，而是“受力方向怎样转弯、轨迹几何怎么找”。

\textbf{科学发展视角：} 洛伦兹力是粒子加速器、质谱仪、等离子体约束和空间辐射探测的基础。现代科学常常不是直接“看见”微观粒子，而是通过电场和磁场控制它们的轨迹，再由轨迹反推粒子的速度、质量和电荷性质。

\section*{三、核心概念}

\begin{conceptbox}{洛伦兹力}

运动电荷在磁场中受到的力叫洛伦兹力。若电荷量为 $q$，速度为 $v$，磁感应强度为 $B$，速度方向与磁场方向夹角为 $\theta$，则
\[
\boxed{F = |q|vB\sin\theta}
\]

\begin{itemize}
  \item 当 $v\perp B$ 时，$F=|q|vB$。
  \item 当 $v\parallel B$ 时，$F=0$。
  \item 公式中的 $|q|$ 用电荷量大小；方向要另行判断。
\end{itemize}

\begin{center}
\input{figures/tikz/lorentz-force-direction}

\figcaption{正电荷受力方向用左手定则判断；负电荷方向相反}\label{fig:lorentz-force-direction}
\end{center}

\textbf{方向判断：} 对正电荷，四指指向速度方向，磁感线穿入手心，拇指指向洛伦兹力方向。对负电荷，方向与正电荷相反。

\end{conceptbox}

\begin{conceptbox}{安培力的微观来源}

上一节的安培力和本节的洛伦兹力不是两个互不相关的力。通电导线中有大量载流子定向移动，磁场先作用在每个运动电荷上；这些微观洛伦兹力通过导体传给整段导线，宏观上就表现为安培力。

\begin{center}
\input{figures/tikz/ampere-lorentz-micro}

\figcaption{安培力可以看成许多载流子所受洛伦兹力的宏观合力}\label{fig:ampere-lorentz-micro}
\end{center}

以导线与匀强磁场垂直为例。设单位体积内载流子数为 $n$，每个载流子电荷量大小为 $|q|$，导线横截面积为 $S$，载流子定向移动速率为 $v_d$。长度为 $L$ 的导线内载流子数约为
\[
N=nSL.
\]
每个载流子受到的洛伦兹力大小为 $|q|v_dB$，所以整段导线受到的合力大小为
\[
F=N|q|v_dB=nSL|q|v_dB.
\]
又因为电流的微观表达式为
\[
I=n|q|Sv_d,
\]
于是
\[
F=BIL.
\]
若电流方向与磁场方向成角度 $\theta$，可以把载流子速度分解成平行磁场和垂直磁场两部分。平行磁场的分量不受磁场力，只有垂直分量 $v_d\sin\theta$ 产生作用，因此得到一般式
\[
F=BIL\sin\theta.
\]

\textbf{认知提醒：} 高中计算安培力时直接用电流方向和左手定则；理解来源时，可以把电流看成大量运动电荷的定向移动。金属中真实运动的是电子，方向与约定电流相反，但用约定电流方向判断整段导线的安培力最方便。

\end{conceptbox}

\begin{conceptbox}{洛伦兹力不做功}

本节所说洛伦兹力，指磁场对运动电荷的力。它的方向始终垂直于速度方向，因此瞬时功率
\[
P = \vect{F}\cdot \vect{v}=0
\]
所以磁场洛伦兹力不做功，不改变粒子动能和速率，只改变速度方向。

\begin{center}
\input{figures/tikz/lorentz-no-work}

\figcaption{磁场洛伦兹力始终垂直速度：只改变方向，不改变速率}\label{fig:lorentz-no-work}
\end{center}

\textbf{重要区别：} 电场力可以改变带电粒子的动能；磁场力单独作用时不能改变动能。

\end{conceptbox}

\begin{conceptbox}{匀强磁场中的圆周运动}

若带电粒子以速度 $v$ 垂直进入匀强磁场，磁场洛伦兹力始终垂直速度，提供向心力：
\[
|q|vB=\frac{mv^2}{r}
\]
这一步要读成“洛伦兹力充当圆周运动所需的向心力”，不要理解成粒子同时又多受到一个叫向心力的新力。实际作用在粒子上的磁场力是 $|q|vB$；$\dfrac{mv^2}{r}$ 是匀速圆周运动所需合力大小的表达式。两者相等，表示磁场力的大小刚好满足转弯需要。

因此
\[
\boxed{r=\frac{mv}{|q|B}},\qquad
\boxed{T=\frac{2\pi m}{|q|B}}
\]

\begin{center}
\input{figures/tikz/magnetic-circular-motion}

\figcaption{带电粒子垂直进入匀强磁场后做匀速圆周运动}\label{fig:magnetic-circular-motion}
\end{center}

\begin{itemize}
  \item 半径 $r$ 与速度 $v$ 成正比。
  \item 在非相对论、匀强磁场且速度垂直磁场的圆周运动模型中，周期 $T$ 与速度 $v$ 无关，只由 $m$、$|q|$、$B$ 决定。
  \item 轨迹方向由电荷正负、速度方向和磁场方向共同决定。
\end{itemize}

\end{conceptbox}

\begin{learningbox}{洛伦兹力圆弧题的四步分析清单}
带电粒子进入磁场后，先完成方向和圆心判断，再代入半径公式。按下面四步走，几何关系会清楚很多：
\begin{enumerate}
  \item \textbf{定偏转方向：} 先看电荷正负，再由 $v$ 和 $B$ 判断洛伦兹力方向，确定轨迹偏向哪一侧。
  \item \textbf{找圆心：} 洛伦兹力始终指向圆心，所以圆心一定在速度的垂线上；入射点、出射点处都可以作速度垂线。
  \item \textbf{定半径和圆心角：} 半径来自 $r=\dfrac{mv}{|q|B}$ 或题图几何；圆心角等于速度方向转过的角度。
  \item \textbf{算时间或位置：} 时间用 $t=\dfrac{\alpha}{2\pi}T$，位置用弦长、半径和圆心角的几何关系。
\end{enumerate}
如果题目中同时有电场，先分清“电场改变速率、磁场改变方向”；只有磁场单独作用时，速率不变，圆周半径才保持不变。
\end{learningbox}

\section*{五、典型模型}

\textbf{磁场粒子题的三层拆解：} 遇到带电粒子进磁场，建议把半径公式放在“方向判断”和“圆周模型”之后使用。完整思路是：
\[
\text{方向判断}\rightarrow\text{圆周模型}\rightarrow\text{边界几何}.
\]
第一步确定粒子的偏转方向；第二步确认洛伦兹力提供向心力；第三步再看题目给的是半径、直径、弦长、圆心角还是运动时间。

\subsection*{模型 1：有界磁场中的圆弧轨迹}

粒子进入有界匀强磁场后，只在磁场内走圆弧。解题关键是找圆心：
\begin{enumerate}
  \item 入射点处，半径垂直于速度方向。
  \item 出射点处，半径也垂直于出射速度方向。
  \item 两条半径的交点就是圆心。
\end{enumerate}

\begin{center}
\input{figures/tikz/magnetic-boundary-arc}

\figcaption{有界磁场中先找圆心，再用几何关系求半径和时间}\label{fig:magnetic-boundary-arc}
\end{center}

\textbf{几何细化：} 有界磁场题常把“轨迹圆”藏起来。入射速度和出射速度的垂线交点就是圆心；圆心角 $\alpha$ 等于速度方向转过的角度，时间由圆心角决定：
\[
t=\frac{\alpha}{2\pi}T.
\]
这里最容易错的不是公式，而是把圆心找错。一旦圆心错了，半径、圆心角和运动时间都会跟着错。

\begin{center}
\input{figures/tikz/bounded-magnetic-geometry}

\figcaption{有界磁场圆弧几何：半径垂直速度，圆心角决定运动时间}\label{fig:bounded-magnetic-geometry}
\end{center}

\subsection*{模型 2：速度选择器}

若粒子同时进入互相垂直的电场和磁场，电场力与洛伦兹力方向相反。只有满足
\[
|q|E=|q|vB,\qquad \boxed{v=\frac{E}{B}}
\]
的粒子才能沿直线通过。

\subsection*{模型 3：质谱仪}

速度选择器先筛出同一速度的粒子，再让粒子进入磁场做圆周运动。由
\[
r=\frac{mv}{|q|B}
\]
可以直接比较：在 $|q|$、$v$、$B$ 相同的情况下，分子里的 $m$ 越大，轨道半径 $r$ 越大。质谱仪正是利用“同速、同场、不同半径”来分辨不同质量的粒子。

\subsection*{模型 4：回旋加速器}

回旋加速器把电场和磁场的作用分开使用：两个 D 形盒内主要有匀强磁场，粒子在盒内做半圆运动；两个盒之间的窄缝中有交变电场，粒子每次经过窄缝时都被加速一次。速度变大后，由
\[
r=\frac{mv}{|q|B}
\]
比较式子两边可以看出：在 $m$、$q$、$B$ 不变时，半径 $r$ 与速度 $v$ 成正比。粒子每过一次缝隙速度变大，下一段圆弧半径也随之变大，所以它不是在同一圆上反复转，而是从中心附近一圈圈向外运动。

\begin{center}
\input{figures/tikz/cyclotron-model}

\figcaption{回旋加速器：磁场负责转弯，缝隙中的交变电场负责加速}\label{fig:cyclotron-model}
\end{center}

回旋周期为
\[
T=\frac{2\pi m}{|q|B}
\]
这个式子里没有 $v$，所以在非相对论、匀强磁场的回旋模型中，回旋周期与速度大小无关。这个结论很关键：粒子虽然越来越快，但轨道半径也同步变大，转一圈所需时间仍保持不变。因此只要交变电压频率满足
\[
\boxed{f=\frac{1}{T}=\frac{|q|B}{2\pi m}},
\]
粒子每次回到窄缝时都能遇到合适方向的电场而继续加速。若最大轨道半径为 $R$，则射出速度和最大动能近似为
\[
v_{\max}=\frac{|q|BR}{m},\qquad E_{k\max}=\frac{q^2B^2R^2}{2m}.
\]

\textbf{认知提醒：} 磁场不做功，不能直接增加粒子的动能；真正做功的是窄缝中的电场。磁场的作用是让粒子不断转回窄缝，使电场可以一次次做功。

\section*{六、例题精讲}

\begin{examplebox}{带电粒子的圆周运动}
\textbf{题意分析：} 质子以 $v=2.0\times 10^6\ \mathrm{m/s}$ 的速度垂直进入 $B=0.50\ \mathrm{T}$ 的匀强磁场。质子质量 $m=1.67\times10^{-27}\ \mathrm{kg}$，电荷量 $q=1.60\times10^{-19}\ \mathrm{C}$。求轨道半径。

\textbf{物理模型：} 洛伦兹力提供向心力。

\begin{center}
\input{figures/tikz/lorentz-radius-example}
\end{center}

\textbf{解题过程：}
\[
r=\frac{mv}{|q|B}
=\frac{1.67\times10^{-27}\times2.0\times10^6}
{1.60\times10^{-19}\times0.50}
\approx 4.2\times10^{-2}\ \mathrm{m}
\]

\textbf{方法总结：} 半径公式来自向心力方程，应先理解来源再记忆。速度越大、质量越大，半径越大；电荷量越大、磁场越强，半径越小。
\end{examplebox}

\begin{examplebox}{半圆磁场中的运动时间}
\textbf{题意分析：} 一个带正电粒子垂直进入匀强磁场，轨迹刚好为半圆后射出。已知 $m$、$q$、$B$，求粒子在磁场中的运动时间。

\textbf{物理模型：} 圆周运动的一部分。

\begin{center}
\input{figures/tikz/magnetic-half-circle-time}
\end{center}

\textbf{解题过程：}

完整周期为
\[
T=\frac{2\pi m}{|q|B}
\]
半圆对应圆心角 $\pi$，所以时间为半个周期：
\[
t=\frac{T}{2}=\frac{\pi m}{|q|B}
\]

\textbf{方法总结：} 有界磁场时间题看“圆弧对应圆心角”，不是看弧长直观长短。
\end{examplebox}

\begin{examplebox}{速度选择器能通过的速度}
\textbf{题意分析：} 速度选择器中匀强电场强度 $E=3.0\times10^4\ \mathrm{N/C}$，匀强磁场 $B=0.20\ \mathrm{T}$，电场力和洛伦兹力方向相反。求能沿直线通过的粒子速度。

\textbf{物理模型：} 理想速度选择器中电场、磁场均匀且相互垂直；粒子直线通过意味着合力为零。

\begin{center}
\input{figures/tikz/velocity-selector-example}
\end{center}

\textbf{解题过程：}
\[
|q|E=|q|vB.
\]
两边都有 $|q|$，所以在这个理想正交场模型中，能通过的速度与粒子电荷量大小无关：
\[
v=\frac{E}{B}
=\frac{3.0\times10^4}{0.20}
=1.5\times10^5\ \mathrm{m/s}.
\]

\textbf{方法总结：} 速度选择器不是“所有粒子都不偏转”，而是只允许特定速度的粒子直线通过；速度过大或过小都会偏转。
\end{examplebox}

\begin{examplebox}{质谱仪中的半径比较}
\textbf{题意分析：} 两种一价正离子经过同一速度选择器后进入同一匀强磁场。若质量分别为 $m$ 和 $2m$，比较它们在磁场中的轨道半径。

\textbf{物理模型：} 速度相同、电荷量相同、磁场相同，半径只随质量变化。

\begin{center}
\input{figures/tikz/mass-radius-comparison}
\end{center}

\textbf{解题过程：}
\[
r=\frac{mv}{|q|B}.
\]
对质量为 $m$ 的离子：
\[
r_1=\frac{mv}{|q|B}.
\]
对质量为 $2m$ 的离子：
\[
r_2=\frac{2mv}{|q|B}=2r_1.
\]

\textbf{方法总结：} 质谱仪的核心是把“看不见的质量差异”转化为“看得见的轨迹半径差异”。
\end{examplebox}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{负电荷方向忘记反向：} 左手定则直接给出正电荷受力方向，负电荷要反向。
  \item \textbf{把“有加速度”和“速率增大”混为一谈：} 洛伦兹力可以提供向心加速度、改变速度方向，但磁场力不做功，不能单独改变速率。
  \item \textbf{把安培力和洛伦兹力割裂开：} 安培力是大量载流子所受洛伦兹力的宏观合力，二者描述的是同一磁场作用的不同层次。
  \item \textbf{把半径公式写成 $r=\dfrac{qB}{mv}$：} 半径应为 $r=\dfrac{mv}{|q|B}$。
  \item \textbf{周期误以为与速度有关：} 在非相对论、匀强磁场且垂直磁场的圆周运动模型中，$T=\dfrac{2\pi m}{|q|B}$，与速度大小无关。
  \item \textbf{边界题不找圆心：} 只画轨迹不找圆心，几何关系往往会错。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{螺旋线运动：速度不完全垂直磁场}

若粒子速度与磁场有夹角，可以把速度分解为
\[
v_\parallel = v\cos\theta,\qquad v_\perp = v\sin\theta
\]

\begin{itemize}
  \item 平行磁场的分量 $v_\parallel$ 不受洛伦兹力影响，保持匀速直线运动。
  \item 垂直磁场的分量 $v_\perp$ 产生圆周运动。
  \item 两个运动合成后，轨迹为螺旋线。
\end{itemize}

\begin{center}
\input{figures/tikz/helical-motion}

\figcaption{速度斜入磁场：平行分量匀速前进，垂直分量形成圆周运动}\label{fig:helical-motion}
\end{center}

螺旋线半径和螺距分别为
\[
r=\frac{mv_\perp}{|q|B},\qquad h=v_\parallel T
\]
这个模型是理解带电粒子在地磁场中运动、等离子体约束和粒子探测器轨迹的入门基础。

\textbf{严谨提醒：} 螺旋运动中磁场仍然不做功，总速率不变；只是把运动分解后，平行分量保持匀速，垂直分量不断改变方向。
\end{competitionbox}

\subsection*{1.\quad 霍尔效应：用洛伦兹力测磁场}

霍尔效应是洛伦兹力在现代传感器中的典型应用。导体或半导体中有电流通过时，载流子具有定向速度；若再加一个垂直于电流方向的磁场，载流子受到洛伦兹力向一侧偏转，导体两侧积累异号电荷，形成横向电势差，叫\textbf{霍尔电压}。下图按正载流子等效模型作图；若讨论金属中的电子，电子速度方向与约定电流方向相反，受力方向还要再考虑负电荷反向。

\begin{center}
\input{figures/tikz/hall-effect-model}

\figcaption{霍尔效应：载流子受洛伦兹力偏转，横向电荷分离形成霍尔电压}\label{fig:hall-effect-model}
\end{center}

\textbf{模型意义：} 霍尔传感器可以测磁场强弱，也能用于无接触测速、测电机转角和手机姿态检测。解题时仍然回到核心判断：先判断载流子速度方向，再用洛伦兹力判断偏转方向，最后由电场力与磁场力平衡理解稳定电压。

\subsection*{2.\quad 补充训练：磁场边界题的三问}

遇到有界磁场，先回答三问，再代入半径或周期公式：
\begin{enumerate}
  \item 入射点和出射点在哪里？
  \item 这两点处速度方向分别是什么？
  \item 由速度垂线找到的圆心在哪里？
\end{enumerate}
圆心确定后，半径、圆心角和时间才有可靠的几何依据。

\section*{十、今日小结}

\begin{enumerate}
  \item 洛伦兹力大小 $F=|q|vB\sin\theta$，方向与电荷正负有关。
  \item 安培力可以看成大量载流子所受洛伦兹力的宏观合力，垂直磁场时由 $I=n|q|Sv_d$ 可得 $F=BIL$。
  \item 磁场洛伦兹力始终垂直速度，因此不做功、不改变速率。
  \item 垂直进入匀强磁场时，粒子做匀速圆周运动。
  \item 半径 $r=\dfrac{mv}{|q|B}$，周期 $T=\dfrac{2\pi m}{|q|B}$。
  \item 有界磁场题先找圆心，再用几何关系求半径、角度和时间。
  \item 回旋加速器中磁场负责转弯，电场负责加速；非相对论下回旋周期与速度无关。
  \item 霍尔效应把洛伦兹力转化为可测电压，是磁传感器的重要模型。
\end{enumerate}
