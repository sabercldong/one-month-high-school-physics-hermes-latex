\daytitle{16}{电势能、电势与电势差}

\begin{learningbox}{本讲义大致内容}
上一节学习了电场的"力的属性"（电场强度 $E$），今天学习电场的"能的属性"——电势能、电势、电势差。这些概念和力学中的重力势能、高度差非常相似，可以用类比法理解。
\end{learningbox}

\section*{一、学习目标}

\begin{enumerate}
  \item 理解电场力做功与电势能变化的关系：$W_{AB} = -\Delta E_p$。
  \item 掌握电势 $\varphi = \dfrac{E_p}{q}$ 和电势差 $U_{AB} = \varphi_A - \varphi_B$。
  \item 掌握匀强电场中 $U = Ed$ 及 $E = \dfrac{U}{d}$。
  \item 理解等势面的概念和性质。
  \item 能用电势差计算电场力做的功：$W_{AB} = qU_{AB}$。
\end{enumerate}

\section*{二、初高中衔接}

重力场中有"重力势能"和"高度差"——类比到电场中：
\begin{center}
\begin{tabular}{ll}
\toprule
重力场 & 静电场 \\
\midrule
重力 $mg$ & 电场力 $qE$ \\
重力势能 $mgh$ & 电势能 $E_p = q\varphi$ \\
高度 $h$ & 电势 $\varphi$ \\
高度差 $\Delta h$ & 电势差 $U$ \\
重力做功 $mg\Delta h$ & 电场力做功 $qU$ \\
\bottomrule
\end{tabular}
\end{center}

这个类比非常重要——几乎所有在重力场中学到的关于"功和能"的知识，都可以平移到静电场中。

\section*{三、核心概念}

\begin{conceptbox}{电场力做功与电势能}

\textbf{电场力做功：} 电场力对电荷做的功 $W_{AB} = qU_{AB}$。

\textbf{电势能：} 电荷在电场中某点具有的势能。
\[
W_{AB} = -\Delta E_p = E_{pA} - E_{pB}
\]

\begin{itemize}
  \item 电场力做正功 $\to$ 电势能减少。
  \item 电场力做负功 $\to$ 电势能增加。
  \item 电势能是相对的，需要选取零势能参考点。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{电势与电势差}

\textbf{电势：}
\[
\varphi = \frac{E_p}{q}
\]

\begin{itemize}
  \item 标量，单位：伏特（$\mathrm{V}$），$1\ \mathrm{V} = 1\ \mathrm{J/C}$。
  \item 电势的高低与电场线的方向有关：沿电场线方向电势降低。
  \item 电势是相对的，需要选零电势参考点（通常选大地或无穷远）。
\end{itemize}

\textbf{电势差（电压）：}
\[
U_{AB} = \varphi_A - \varphi_B
\]

\textbf{电场力做功与电势差：}
\[
\boxed{W_{AB} = qU_{AB}}
\]

\textbf{匀强电场中电势差与场强的关系：}
\[
\boxed{U = Ed}
\]
或
\[
\boxed{E = \frac{U}{d}}
\]

\begin{itemize}
  \item $d$ 是沿电场线方向的距离（不是两点的直线距离）。
  \item 场强的单位：$\mathrm{V/m}$ 和 $\mathrm{N/C}$ 等价。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{等势面}

\textbf{定义：} 电场中电势相等的点构成的曲面。

\textbf{性质：}
\begin{itemize}
  \item 等势面与电场线处处垂直。
  \item 沿等势面移动电荷，电场力不做功。
  \item 等势面密集的地方场强大（与电场线疏密一致）。
  \item 不同等势面不相交。
\end{itemize}

\end{conceptbox}

\section*{五、典型模型}

\subsection*{模型 1：匀强电场中的电势}

平行板间电势沿电场线方向均匀降低。$A$、$B$ 两点沿电场方向相距 $d$，则 $U_{AB} = Ed$。

\subsection*{模型 2：点电荷的电势}

点电荷 $Q$ 周围距 $r$ 处的电势（取无穷远为零势点）：
\[
\varphi = k\frac{Q}{r}
\]
正电荷周围电势为正，负电荷周围电势为负。

\subsection*{模型 3：带电粒子在电场中的能量关系}

只有电场力做功时，带电粒子的动能和电势能之和守恒：
\[
\frac12 mv_1^2 + q\varphi_1 = \frac12 mv_2^2 + q\varphi_2
\]

\section*{六、例题精讲}

\begin{examplebox}{电场力做功}

\textbf{题意分析：} 在匀强电场中，将电荷 $q = +2 \times 10^{-9}\ \mathrm{C}$ 从 $A$ 点移到 $B$ 点，$A$、$B$ 沿电场方向相距 $d = 0.05\ \mathrm{m}$，电场强度 $E = 200\ \mathrm{N/C}$。求：
\begin{enumerate}
  \item $A$、$B$ 间的电势差。
  \item 电场力做的功。
  \item 若 $q$ 改为 $-2 \times 10^{-9}\ \mathrm{C}$，结果如何？
\end{enumerate}

\textbf{物理模型：} 匀强电场，$U = Ed$，$W = qU$。

\textbf{解题过程：}

\begin{enumerate}
  \item $U_{AB} = Ed = 200 \times 0.05 = 10\ \mathrm{V}$
  
  \item $W_{AB} = qU_{AB} = 2 \times 10^{-9} \times 10 = 2 \times 10^{-8}\ \mathrm{J}$
  
  \item $q' = -2 \times 10^{-9}\ \mathrm{C}$：
  \[
  W_{AB}' = q'U_{AB} = -2 \times 10^{-9} \times 10 = -2 \times 10^{-8}\ \mathrm{J}
  \]
  负功表示电场力做负功，电势能增加。
\end{enumerate}

\textbf{方法总结：} 电场力做的功只与初末位置的电势差有关，与路径无关。$q$ 为正时沿电场线方向移动做正功，$q$ 为负时做负功。

\end{examplebox}

\begin{examplebox}{电势的计算}

\textbf{题意分析：} 点电荷 $Q = +3 \times 10^{-9}\ \mathrm{C}$，取无穷远处电势为零。求距 $Q$ 分别为 $0.1\ \mathrm{m}$ 和 $0.3\ \mathrm{m}$ 处的电势。

\textbf{物理模型：} 点电荷的电势公式。

\textbf{解题过程：}

\[
\varphi_1 = k\frac{Q}{r_1} = 9 \times 10^9 \times \frac{3 \times 10^{-9}}{0.1} = 270\ \mathrm{V}
\]
\[
\varphi_2 = k\frac{Q}{r_2} = 9 \times 10^9 \times \frac{3 \times 10^{-9}}{0.3} = 90\ \mathrm{V}
\]

$U_{12} = \varphi_1 - \varphi_2 = 270 - 90 = 180\ \mathrm{V}$。

\textbf{方法总结：} 正点电荷周围电势为正，离电荷越近电势越高。两点间的电势差等于电势之差。

\end{examplebox}

\begin{examplebox}{电场力做功与路径无关}

\textbf{题意分析：} 在匀强电场中，将 $q = +1 \times 10^{-8}\ \mathrm{C}$ 的电荷从 $A$ 沿直线移到 $B$，电场力做功 $W_1 = 3 \times 10^{-6}\ \mathrm{J}$。若从 $A$ 沿另一条路径（先向右再向上）移到 $B$，电场力做功 $W_2$ 是多少？$A$、$B$ 的电势差是多少？

\textbf{物理模型：} 电场力做功与路径无关。

\textbf{解题过程：}

$W_2 = W_1 = 3 \times 10^{-6}\ \mathrm{J}$（与路径无关）。

\[
U_{AB} = \frac{W_{AB}}{q} = \frac{3 \times 10^{-6}}{1 \times 10^{-8}} = 300\ \mathrm{V}
\]

\textbf{方法总结：} 电场力做功与路径无关，只与初末位置有关。这是静电场与重力场的共同特点，都对应一个势能函数。

\end{examplebox}

\section*{七、变式训练}

\begin{enumerate}
  \item 在匀强电场中将 $q = -1 \times 10^{-8}\ \mathrm{C}$ 从 $A$ 移到 $B$，$U_{AB} = 50\ \mathrm{V}$。求电场力做功。$q$ 的电势能如何变化？
  
  \item 点电荷 $Q = -4 \times 10^{-9}\ \mathrm{C}$，求距 $Q$ 为 $0.2\ \mathrm{m}$ 处的电势。
  
  \item 匀强电场中，$A$、$B$ 相距 $0.1\ \mathrm{m}$，连线与电场方向夹角 $60^\circ$，$U_{AB} = 20\ \mathrm{V}$。求电场强度 $E$。
\end{enumerate}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{$U = Ed$ 中 $d$ 的含义：} $d$ 是沿电场线方向的距离，不是两点间的直线距离。如果 $A$、$B$ 的连线与电场方向夹角为 $\theta$，则 $d = AB \cdot \cos\theta$。
  
  \item \textbf{电势的正负：} 电势是标量，有正负。正电荷周围电势为正，负电荷周围电势为负。电势的大小比较时，$+5\ \mathrm{V} > -10\ \mathrm{V}$。
  
  \item \textbf{电场力做功正负的判断：} 电场力做功的正负由 $q$ 和 $U$ 的符号共同决定。$W = qU$，$q$ 和 $U$ 同号则做正功。
  
  \item \textbf{零电势点的选取：} 同一问题中必须使用同一个零电势参考点。通常取大地或无穷远。
  
  \item \textbf{混淆电势和电势能：} 电势 $\varphi$ 是电场的属性（与电荷无关），电势能 $E_p = q\varphi$ 是电荷在场中具有的能量（与电荷 $q$ 有关）。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{匀强电场中电势的几何关系}

在匀强电场中，沿任意方向电势均匀变化。这一性质在处理复杂几何问题时非常有用。

\textbf{结论：} 在匀强电场中，如果 $A$、$B$、$C$ 是同一等势面上的三个点，则它们电势相等。如果一条直线上电势是线性分布的，那么两点间电势差与沿电场方向的距离成正比。

\textbf{例题：} 一个边长为 $a$ 的等边三角形 $ABC$ 放在匀强电场中，已知 $\varphi_A = 10\ \mathrm{V}$、$\varphi_B = 6\ \mathrm{V}$、$\varphi_C = 2\ \mathrm{V}$。求电场强度的大小和方向。

\textbf{解：} 根据电势分布可找出等势面方向，电场线与等势面垂直且指向电势降低方向。由 $\varphi_A - \varphi_C$ 和 $AC$ 间的距离可计算出 $E$。

\textbf{竞赛小贴士：} 在匀强电场中，"两点间的电势差 = 场强 × 沿电场方向的距离"——先用等势面判断电场方向，再计算大小。
\end{competitionbox}

\section*{十、今日小结}

\begin{enumerate}
  \item 电场力做功 $W_{AB} = qU_{AB}$，与路径无关。
  \item 电势 $\varphi = \dfrac{E_p}{q}$，电势差 $U_{AB} = \varphi_A - \varphi_B$。
  \item 沿电场线方向电势降低。
  \item 匀强电场中 $U = Ed$，$E = \dfrac{U}{d}$。
  \item 等势面与电场线垂直，沿等势面移动电荷电场力不做功。
\end{enumerate}
