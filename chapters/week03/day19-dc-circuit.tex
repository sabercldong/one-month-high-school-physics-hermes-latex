\daytitle{19}{恒定电流与基本电路}

\begin{learningbox}{本节导读}
从电荷的定向移动开始，理解电流、电阻、欧姆定律，再到串联和并联电路的分析方法。这些是电学实验和后续复杂电路分析的基础。
\end{learningbox}

\textbf{本节读题路线：} 先把电路化成清楚的串并联结构，再判断各支路电流和各元件电压怎样分配；功率题先明确是某个元件的端口功率，还是纯电阻发热功率。遇到非线性元件，先读图像关系，不要直接套 $R=U/I$ 当常量。

\section*{一、学习目标}

\begin{enumerate}
  \item 理解电流 $I = \dfrac{\Delta Q}{\Delta t}$、电阻 $R = \dfrac{U}{I}$、欧姆定律 $I = \dfrac{U}{R}$。
  \item 掌握电阻定律 $R = \rho\dfrac{l}{S}$，理解电阻率 $\rho$ 的含义。
  \item 会分析串联和并联电路中 $I$、$U$、$R$ 的分配关系。
  \item 掌握电功 $W = IUt$ 和电功率 $P = IU$。
  \item 能进行简单的电路化简计算。
  \item 认识二极管等非线性元件，知道不能机械套用欧姆定律。
  \item 了解热敏、光敏等传感器常通过电阻变化输出电压信号。
\end{enumerate}
\section*{二、初高中衔接}

初中已经学过这些基本知识——电流、电压、电阻、欧姆定律、串联并联。高中在以下方面深化：
\begin{enumerate}
  \item \textbf{电流的微观解释：} $I = n\lvert q\rvert Sv$（$n$ 为载流子浓度，$\lvert q\rvert$ 为单个载流子的电荷量大小）。
  \item \textbf{电阻定律：} $R = \rho \dfrac{l}{S}$——电阻与材料、长度、横截面积的定量关系。
  \item \textbf{电功率的精确理解：} 计算某个元件的端口功率时用 $P = UI$；在纯电阻元件中，还可写成 $P = I^2R$ 或 $P = \dfrac{U^2}{R}$。
  \item \textbf{电路化简和复杂计算：} 多电阻串并联的等效电阻计算。
\end{enumerate}

\textbf{科学发展视角：} 真实电子设备从金属导线发展到半导体芯片，但基本电路思想仍然重要。传感器把温度、光照、压力等物理量转化为电信号，后续电路再进行放大、计算和控制。本节的串并联、功率和非纯电阻电路，是理解现代电子系统的入口。

\section*{三、核心概念}

\begin{conceptbox}{电流与电阻}

\textbf{电流：} 单位时间内通过导体横截面的电荷量。
\[
I = \frac{\Delta Q}{\Delta t}
\]
单位：安培（$\mathrm{A}$）。方向：正电荷定向移动的方向（与电子移动方向相反）。

\begin{center}
\input{figures/tikz/current-microscopic}

\figcaption{电流的微观模型：载流子定向移动形成电流}\label{fig:current-microscopic}
\end{center}

若单个载流子的电荷量大小为 $\lvert q\rvert$、数密度为 $n$、导体横截面积为 $S$、定向移动速率为 $v$，则可从“单位时间内穿过截面的载流子数”推出电流大小的微观表达式。

\textbf{推导：} 在很短时间 $\Delta t$ 内，能穿过截面 $S$ 的载流子，来自截面前方长度为 $v\Delta t$ 的一段导体。这个小柱体体积为
\[
V=S\cdot v\Delta t.
\]
其中载流子个数为
\[
N=nV=nSv\Delta t.
\]
这些载流子携带的电荷量为
\[
\Delta Q=N\lvert q\rvert=n\lvert q\rvert Sv\Delta t.
\]
代入电流定义 $I=\dfrac{\Delta Q}{\Delta t}$，得到
\[
\boxed{I=n\lvert q\rvert Sv}.
\]
图中采用正载流子等效示意；在金属导体中，电子实际定向移动方向与约定电流方向相反。这个公式说明电流大小不仅与载流子运动快慢有关，也与载流子多少和导体粗细有关。

\textbf{欧姆定律：}
\[
\boxed{I = \frac{U}{R}}
\]

\begin{itemize}
  \item 适用条件：线性导体，且温度等条件基本不变。
  \item 不适用于二极管、气体放电管等明显非线性元件；灯丝电阻随温度变化，严格说也不是恒定电阻。
  \item 对给定导体，在温度、形状和材料状态基本不变时，$R$ 是导体本身的性质，与外加 $U$、通过的 $I$ 无关。
\end{itemize}

\textbf{来源理解：} 对金属导体，电压越大，导体内部推动自由电子定向运动的电场越强；在温度基本不变时，定向移动速率与电场强度近似成正比，所以电流与电压近似成正比：
\[
I\propto U.
\]
把比例系数写成 $\dfrac{1}{R}$，就得到 $I=\dfrac{U}{R}$。因此欧姆定律不是所有元件的“定义式”，而是许多金属导体在一定条件下表现出的实验规律。

\textbf{电阻定律：}
\[
\boxed{R = \rho \frac{l}{S}}
\]

\begin{itemize}
  \item $\rho$：电阻率（$\Omega \cdot \mathrm{m}$），与材料和温度等状态有关。
  \item 金属的电阻率随温度升高而增大。
  \item 超导现象：某些材料温度低于临界温度时，直流电阻可降为零。
\end{itemize}

\textbf{来源理解：} 导体越长，载流子在定向移动中经历的阻碍越多，电阻越大，故 $R\propto l$；导体横截面积越大，相当于可供电流通过的“通道”越宽，电阻越小，故 $R\propto \dfrac{1}{S}$。材料不同，阻碍强弱不同，用电阻率 $\rho$ 表示，于是
\[
R=\rho\frac{l}{S}.
\]

\end{conceptbox}

\begin{conceptbox}{串联与并联电路}

\begin{center}
\input{figures/tikz/series-parallel}

\figcaption{串联（左）和并联（右）电路对比}\label{fig:series-parallel}
\end{center}

\textbf{串联电路：}
\begin{itemize}
  \item 电流处处相等：$I = I_1 = I_2$。
  \item 总电压等于各分电压之和：$U = U_1 + U_2$。
  \item 总电阻：$R = R_1 + R_2$。
  \item 电压分配：$\dfrac{U_1}{U_2} = \dfrac{R_1}{R_2}$（串联分压）。
\end{itemize}

\textbf{并联电路：}
\begin{itemize}
  \item 各支路电压相等：$U = U_1 = U_2$。
  \item 总电流等于各支路电流之和：$I = I_1 + I_2$。
  \item 总电阻：$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$。
  \item 电流分配：$\dfrac{I_1}{I_2} = \dfrac{R_2}{R_1}$（并联分流）。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{节点与回路：电路方程的守恒思想}

\begin{center}
\input{figures/tikz/kirchhoff-circuit-laws}

\figcaption{节点电流守恒与回路电压守恒}\label{fig:kirchhoff-circuit-laws}
\end{center}

串联、并联公式不是孤立记忆出来的，它们背后分别对应两条守恒思想。

\textbf{节点电流守恒：} 稳恒电路中，导线交汇处不能持续积累电荷。若某节点有若干电流流入、若干电流流出，则
\[
\sum I_{\text{入}}=\sum I_{\text{出}}.
\]
并联电路中“干路电流等于各支路电流之和”，本质上就是节点处的电荷守恒。

\textbf{回路电压守恒：} 一个电荷沿闭合回路走一圈又回到出发点，电势的总变化为零。电源使电势升高，电阻使电势降低，因此闭合回路中
\[
\sum U_{\text{升}}=\sum U_{\text{降}}.
\]
串联电路中“总电压等于各分电压之和”，本质上就是回路中的能量守恒。

\textbf{学习要求：} 高中阶段遇到能直接化简的串并联电路，优先用串并联关系；遇到分叉较多、难以一眼化简的电路，可以先标出节点和回路，再用“电流守恒、能量守恒”的思想建立方程。

\end{conceptbox}

\begin{conceptbox}{电功与电功率}

\textbf{电功：} 电场力推动电荷通过元件时，电能转化为其他形式能的量。恒定电流通过电压为 $U$ 的元件、历时 $t$，电功为
\[
W = IUt
\]

\textbf{焦耳定律（电热）：}
\[
Q = I^2 Rt
\]

\textbf{焦耳定律的来源：} 电流通过电阻时，电场对电荷做功，电能转化为内能。电功率普遍为
\[
P=UI.
\]
对纯电阻，欧姆定律给出 $U=IR$，所以发热功率
\[
P_{\text{热}}=UI=I^2R.
\]
经过时间 $t$，产生的热量为
\[
Q=P_{\text{热}}t=I^2Rt.
\]
在非纯电阻电路中，$I^2Rt$ 仍表示发热量，但 $UIt$ 还包含转化为机械能、化学能等其他形式的能量。

\textbf{电功率：}
\[
\boxed{P = IU}
\]

\begin{itemize}
  \item 纯电阻电路（如定值电阻、电炉丝；白炽灯丝只在温度近似稳定的小范围内可近似处理）：$P = IU = I^2R = \dfrac{U^2}{R}$。
  \item 正常工作的非纯电阻用电器（如电动机）：输入电功率 $P_{\text{入}}=IU$，线圈发热功率 $P_{\text{热}}=I^2R$，通常 $P_{\text{入}}>P_{\text{热}}$，差值转化为机械能等其他形式。
\end{itemize}

\end{conceptbox}

\section*{五、典型模型}

\subsection*{模型 1：串联分压 / 并联分流}

串分压：电压与电阻成正比，大电阻分大电压。
并分流：电流与电阻成反比，大电阻分小电流。

\textbf{模型例题：} $R_1=4\ \Omega$、$R_2=8\ \Omega$ 串联接在 $12\ \mathrm{V}$ 电源两端，求两电阻分得的电压。

\textbf{解：} 串联电路电流相同，电压按电阻成正比分配：
\[
U_1:U_2=R_1:R_2=4:8=1:2.
\]
总电压为 $12\ \mathrm{V}$，所以
\[
U_1=4\ \mathrm{V},\qquad U_2=8\ \mathrm{V}.
\]
\textbf{提醒：} 串联分压不是“平均分压”，而是按电阻比例分。

\subsection*{模型 2：电路化简}

找等电位点 $\to$ 判断串并联关系 $\to$ 逐级求等效电阻。

\subsection*{模型 3：非纯电阻电路}

电动机：$P_{\text{电}} = UI$，$P_{\text{热}} = I^2R$，$P_{\text{机}} = UI - I^2R$。

\begin{center}
\input{figures/tikz/non-ohmic-motor-model}

\figcaption{非纯电阻电路模型：输入电功率分成发热功率和机械功率}\label{fig:non-ohmic-motor-model}
\end{center}

\textbf{关键判断：} 电动机、电解槽、正在充电的电池都不是纯电阻元件。它们消耗的总电功率是 $UI$，其中只有 $I^2R$ 是线圈或内部电阻发热，不能用 $U^2/R$ 计算总功率。

\subsection*{模型 4：伏安特性曲线与二极管}

欧姆定律适用于线性导体，特征是 $I$-$U$ 图像近似为过原点的直线。二极管是典型的非线性元件，具有明显的\textbf{单向导电性}：正向电压达到一定程度后，电流迅速增大；反向接法时，在高中常见范围内电流很小。

\begin{center}
\input{figures/tikz/diode-iv-characteristic}

\figcaption{二极管的伏安特性：非线性、单向导电，不能直接用 $R=U/I$ 当作恒定电阻}\label{fig:diode-iv-characteristic}
\end{center}

\textbf{学习边界：} 高中阶段不要求解释半导体内部的能带结构，但要会从伏安特性曲线判断元件是否满足欧姆定律。若图像不是直线，或者电阻随电压、电流明显变化，就不能把它当成恒定电阻处理。

\subsection*{模型 5：传感器的分压读数}

许多传感器不是直接“显示温度或光强”，而是先让某个电学量随外界条件改变。例如热敏电阻、光敏电阻和应变片的电阻会随温度、光照或形变变化。把它们接入分压电路，就能把物理量变化转化为输出电压变化。

\begin{center}
\input{figures/tikz/sensor-voltage-divider}

\figcaption{传感器分压模型：外界物理量改变 $R_x$，电路把变化转化为输出电压}\label{fig:sensor-voltage-divider}
\end{center}

若输出电压取在传感器 $R_x$ 两端，则
\[
U_{\text{出}}=E\frac{R_x}{R_0+R_x}.
\]
因此 $R_x$ 增大时，$U_{\text{出}}$ 增大；$R_x$ 减小时，$U_{\text{出}}$ 减小。若输出电压取在固定电阻 $R_0$ 两端，变化方向则相反。

\textbf{学习边界：} 本节只要求会把它看成“可变电阻 + 分压电路”。真实传感器还需要标定、放大和数据处理，这些会在实验与科学探究中继续出现。

\section*{六、例题精讲}

\begin{examplebox}{串并联电路的计算}

\textbf{题意分析：} $R_1 = 6\ \Omega$，$R_2 = 12\ \Omega$ 并联后与 $R_3 = 4\ \Omega$ 串联，接在 $U = 12\ \mathrm{V}$ 的电源上。求：
\begin{enumerate}
  \item 电路总电阻。
  \item 干路电流。
  \item $R_1$、$R_2$、$R_3$ 各自的电压和电流。
\end{enumerate}

\textbf{物理模型：} 混联电路。

\begin{center}
\input{figures/tikz/mixed-circuit-example}

\figcaption{混联电路：先合并并联部分，再与 $R_3$ 串联}\label{fig:mixed-circuit-example}
\end{center}

\textbf{解题过程：}

\begin{enumerate}
  \item $R_{12} = \dfrac{R_1 R_2}{R_1 + R_2} = \dfrac{6 \times 12}{6 + 12} = 4\ \Omega$
  
  $R_{\text{总}} = R_{12} + R_3 = 4 + 4 = 8\ \Omega$
  
  \item $I_{\text{总}} = \dfrac{U}{R_{\text{总}}} = \dfrac{12}{8} = 1.5\ \mathrm{A}$
  
  \item $U_3 = I_{\text{总}} R_3 = 1.5 \times 4 = 6\ \mathrm{V}$
  
  $U_{12} = U - U_3 = 12 - 6 = 6\ \mathrm{V}$（并联部分电压）
  
  $I_1 = \dfrac{U_{12}}{R_1} = \dfrac{6}{6} = 1\ \mathrm{A}$，$I_2 = \dfrac{U_{12}}{R_2} = \dfrac{6}{12} = 0.5\ \mathrm{A}$
\end{enumerate}

\textbf{方法总结：} 混联电路的解题顺序：先合并并联部分 $\to$ 求总电阻 $\to$ 求总电流 $\to$ 逐级反推各支路。

\end{examplebox}

\begin{examplebox}{电功率计算}

\textbf{题意分析：} 标有“$220\ \mathrm{V}$、$100\ \mathrm{W}$”的灯泡：
\begin{enumerate}
  \item 正常发光时电流和电阻是多少？
  \item 接在 $110\ \mathrm{V}$ 电源上时实际功率是多少？（假设电阻不变）
\end{enumerate}

\textbf{物理模型：} 纯电阻电路。

\textbf{解题过程：}

\begin{enumerate}
  \item $I = \dfrac{P}{U} = \dfrac{100}{220} \approx 0.455\ \mathrm{A}$
  
  $R = \dfrac{U^2}{P} = \dfrac{220^2}{100} = 484\ \Omega$
  
  \item $P_{\text{实}} = \dfrac{U_{\text{实}}^2}{R} = \dfrac{110^2}{484} = \dfrac{12100}{484} = 25\ \mathrm{W}$
\end{enumerate}

\textbf{方法总结：} 本题已经说明“假设电阻不变”，因此可以用同一个 $R$ 计算实际功率。若考虑灯丝温度变化，电阻并非严格不变。

\end{examplebox}

\begin{examplebox}{非纯电阻电路}

\textbf{题意分析：} 一台电动机的线圈电阻 $R = 1\ \Omega$，接在 $U = 220\ \mathrm{V}$ 电源上工作时电流 $I = 10\ \mathrm{A}$。求：
\begin{enumerate}
  \item 输入电功率。
  \item 发热功率。
  \item 输出机械功率和效率。
\end{enumerate}

\textbf{物理模型：} 非纯电阻电路，$P = UI \neq I^2R$。

\begin{center}
\input{figures/tikz/non-ohmic-motor-example}

\figcaption{非纯电阻例题图：电动机输入功率不等于线圈发热功率}\label{fig:non-ohmic-motor-example}
\end{center}

\textbf{解题过程：}

\begin{enumerate}
  \item $P_{\text{电}} = UI = 220 \times 10 = 2200\ \mathrm{W}$
  
  \item $P_{\text{热}} = I^2 R = 10^2 \times 1 = 100\ \mathrm{W}$
  
  \item $P_{\text{机}} = P_{\text{电}} - P_{\text{热}} = 2200 - 100 = 2100\ \mathrm{W}$
  
  效率 $\eta = \dfrac{P_{\text{机}}}{P_{\text{电}}} = \dfrac{2100}{2200} \approx 95.5\%$
\end{enumerate}

\textbf{方法总结：} 非纯电阻电路不能直接用 $P = I^2R$ 或 $P = U^2/R$ 算总功率，必须用 $P = UI$。发热功率一定用 $P = I^2R$。

\end{examplebox}

  \end{center}

  \item 某元件的 $I$-$U$ 图像不是过原点直线，能否把 $R=U/I$ 当作该元件的恒定电阻？为什么？

  \item 某传感器接成分压电路，输出电压取在传感器两端。若外界条件使传感器电阻增大，输出电压怎样变化？
\end{enumerate}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{混联电路中串并联关系判断错：} 电流只有一条路径 $\to$ 串联；电流分叉 $\to$ 并联。找等电位点法是判断串并联的可靠方法。
  
  \item \textbf{非纯电阻电路用错公式：} 只有纯电阻才能用 $P = I^2R = U^2/R$ 算总功率。有电动机的电路中 $P = UI \neq I^2R$。
  
  \item \textbf{并联总电阻小于任何一个分电阻：} $n$ 个相同的电阻 $R$ 并联，总电阻为 $\dfrac{R}{n}$。
  
  \item \textbf{串联分压时大电阻分大电压：} 不是大电阻分大电流（串联电流相等，不存在分电流）。
  
  \item \textbf{误以为焦耳定律 $Q = I^2Rt$ 只适用于纯电阻电路：} 对任何有电阻发热的导体部分，它都可用于计算该部分产生的电热；但在非纯电阻电路中，整个用电器消耗的电能不全变成热，通常 $Q \neq IUt$。

  \item \textbf{把二极管当普通电阻：} 二极管的伏安特性是非线性的，且正反向性质不同，不能直接套串并联电阻公式。

  \item \textbf{传感器题不看输出端接在哪里：} 同一个可变电阻，输出取在它两端或固定电阻两端，电压变化方向可能相反。

  \item \textbf{复杂电路只凭直觉猜串并联：} 分叉较多时，先看节点电流是否守恒、闭合回路中电压升降是否平衡，再判断能否化简。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{电路的化简技巧——对称法}

如果电路具有对称性，可以利用对称性简化计算。

\textbf{例题：} 一个正方体框架每条棱的电阻为 $R$，求体对角线两个顶点间的等效电阻。

\begin{center}

\figcaption{正方体电阻网络：从体对角线两端接入电流}\label{fig:cube-resistor-network}
\end{center}

\begin{center}
\input{figures/tikz/cube-equivalent-network}

\figcaption{正方体电阻网络的对称化简：同层等电位点可以合并}\label{fig:cube-equivalent-network}
\end{center}

\textbf{解：} 设电流从体对角线一端 $A$ 流入，从另一端 $B$ 流出。与 $A$ 相邻的三个顶点等电位，可合并为一组；与 $B$ 相邻的三个顶点也等电位，可合并为一组。于是电路化为三段串联：
\[
R_{\text{总}} = \frac{R}{3}+\frac{R}{6}+\frac{R}{3}=\frac{5}{6}R
\]

\textbf{竞赛小贴士：} 遇到复杂网络电阻问题，先观察对称性。等电位点可以合并、电流对称的支路可以等分，这些技巧能大幅简化计算。
\end{competitionbox}

\section*{十、今日小结}

\begin{enumerate}
  \item 欧姆定律 $I = \dfrac{U}{R}$，电阻定律 $R = \rho\dfrac{l}{S}$。
  \item 串联：$I$ 相等，$U$ 分压，$R = R_1 + R_2$。
  \item 并联：$U$ 相等，$I$ 分流，$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$。
  \item 节点电流守恒来自电荷守恒，回路电压守恒来自能量守恒。
  \item 电功 $W=UIt$，电功率 $P = IU$，焦耳定律 $Q = I^2Rt$。
  \item 非纯电阻电路中 $P_{\text{电}} = UI$，$P_{\text{热}} = I^2R$，两者不等。
  \item 二极管等非线性元件的伏安特性不是直线，不能当作恒定电阻处理。
  \item 热敏、光敏等传感器常可看成可变电阻，借助分压电路把物理量变化转化为电压信号。
\end{enumerate}

\textbf{一分钟复盘：} 任取一个电路，先把串并联关系化简，再标每个元件的 $I$、$U$、$P$；遇到电动机、二极管或传感器，先判断它还能不能当纯电阻。
