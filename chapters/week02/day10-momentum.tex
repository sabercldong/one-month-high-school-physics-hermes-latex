\daytitle{10}{冲量、动量与动量守恒}

\begin{learningbox}{本讲义大致内容}
力和加速度解决瞬时问题，能量和动能定理解决过程问题，而动量和动量守恒解决\textbf{碰撞、爆炸、反冲}等瞬间相互作用问题。它是继牛顿定律和能量方法之后的第三个核心工具。
\end{learningbox}

\section*{一、学习目标}

\begin{enumerate}
  \item 掌握冲量 $I = Ft$ 和动量 $p = mv$ 的概念。
  \item 掌握动量定理 $F_{\text{合}}t = \Delta p$，会用动量定理解释缓冲现象。
  \item 理解动量守恒的条件：系统不受外力或合外力为零。
  \item 掌握弹性碰撞、完全非弹性碰撞的特点和公式。
  \item 会用动量守恒解决碰撞、爆炸、反冲问题。
\end{enumerate}

\section*{二、初高中衔接}

初中物理对碰撞只有定性的了解——"碰撞时力很大、时间很短"。高中把碰撞过程精确量化：

碰撞中发生了什么？
\begin{enumerate}
  \item 碰撞时间极短（通常千分之一秒）。
  \item 碰撞力极大（可达重力的几千倍）。
  \item 因此，重力等外力在碰撞过程中可以忽略。
\end{enumerate}

结论：\textbf{碰撞过程中，系统的总动量近似守恒。}

\section*{三、核心概念}

\begin{conceptbox}{冲量与动量}

\textbf{动量：}
\[
\boxed{p = mv}
\]
\begin{itemize}
  \item 矢量，方向与速度方向相同。
  \item 单位：$\mathrm{kg \cdot m/s}$。
\end{itemize}

\textbf{冲量：}
\[
\boxed{I = F t}
\]
\begin{itemize}
  \item 矢量，方向与力 $F$ 方向相同。
  \item 单位：$\mathrm{N \cdot s}$（与动量单位等价）。
  \item 冲量是力在时间上的积累效应；若力变化，$F$ 取平均力。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{动量定理}

\[
\boxed{F_{\text{合}} t = \Delta p = p_2 - p_1 = mv_2 - mv_1}
\]

\begin{itemize}
  \item 合外力的冲量等于物体动量的变化。
  \item 动量定理不关心中间过程，只关心初末动量。
  \item 与动能定理类似，但动量定理处理的是\textbf{时间}积累，动能定理处理的是\textbf{位移}积累。
\end{itemize}

\textbf{生活应用：} 跳远时沙坑、汽车安全气囊、鸡蛋落在海绵上——都是通过延长作用时间 $t$ 来减小平均作用力 $F$（因为 $F_{\text{合}} t = \Delta p$ 恒定）。

\end{conceptbox}

\begin{conceptbox}{动量守恒定律}

\textbf{条件：} 系统不受外力，或合外力为零。

\textbf{定律：}
\[
\boxed{m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'}
\]

\begin{itemize}
  \item 系统内力（碰撞中两物体的相互作用力）不改变总动量。
  \item 动量守恒是矢量守恒——在一维问题中要规定正方向。
  \item 碰撞、爆炸、反冲的时间极短，外力远小于内力，可近似认为动量守恒。
\end{itemize}

\end{conceptbox}

\begin{conceptbox}{碰撞的分类}

\textbf{弹性碰撞：}
\begin{itemize}
  \item 动量守恒 + 动能守恒。
  \item 没有能量损失（理想情况）。
  \item 两个方程联立可解出 $v_1'$ 和 $v_2'$。
  \item 以一维正碰、$v_2=0$ 为例，结果为：
  \[
  v_1' = \frac{m_1 - m_2}{m_1 + m_2} v_1,\qquad
  v_2' = \frac{2m_1}{m_1 + m_2} v_1
  \]
  （若 $v_2\neq 0$，公式更复杂，用动量守恒+动能守恒联立求解即可）
\end{itemize}

\textbf{完全非弹性碰撞：}
\begin{itemize}
  \item 动量守恒，但动能不守恒（损失最大）。
  \item 碰后两物体粘在一起以共同速度运动：
  \[
  m_1 v_1 + m_2 v_2 = (m_1 + m_2) v'
  \]
\end{itemize}

\textbf{非弹性碰撞：} 介于两者之间，动量守恒，动能部分损失。

\end{conceptbox}

\section*{四、公式与适用条件}

\begin{center}
\begin{tabular}{lll}
\toprule
公式 & 意义 & 适用条件 \\
\midrule
$p = mv$ & 动量 & 任何运动 \\
$I = Ft$ & 冲量 & 恒力 \\
$F_{\text{合}} t = \Delta p$ & 动量定理 & $F_{\text{合}}$ 为合外力（变力取平均） \\
$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$ & 动量守恒 & 合外力为零 \\
$\frac12 m_1 v_1^2 = \frac12 m_1 v_1'^2 + \frac12 m_2 v_2'^2$ & 动能守恒 & 弹性碰撞，$v_2=0$ \\
\bottomrule
\end{tabular}
\end{center}

\section*{五、典型模型}

\subsection*{模型 1：子弹打木块}

子弹射入木块（完全非弹性碰撞）：
\[
m v_0 = (m + M) v'
\]
损失的动能转化为内能：
\[
Q = \frac12 m v_0^2 - \frac12 (m+M) v'^2
\]

\subsection*{模型 2：爆炸/反冲}

系统内力远大于外力，动量守恒，但动能增加（化学能/内能转化为动能）。

反冲：$0 = m_1 v_1 + m_2 v_2$（总动量守恒，初动量为零）。

\subsection*{模型 3：人船模型}

人在船上行走，人与船系统水平方向动量守恒（初动量为零）：
\[
m_{\text{人}} v_{\text{人}} + m_{\text{船}} v_{\text{船}} = 0
\]
由此可得位移关系：
\[
m_{\text{人}} x_{\text{人}} + m_{\text{船}} x_{\text{船}} = 0
\]
且人相对船的位移等于船长的相反数：$x_{\text{人}} - x_{\text{船}} = L$（人从船头走到船尾，相对船走了 $L$）。

联立可解得 $x_{\text{船}} = -\dfrac{m}{m+M} L$（负号表示船向反方向移动）。

\section*{六、例题精讲}

\begin{examplebox}{动量定理的应用}

\textbf{题意分析：} 质量为 $m = 0.5\ \mathrm{kg}$ 的足球以 $v_0 = 10\ \mathrm{m/s}$ 的速度飞来，运动员用头顶球后球以 $v = 8\ \mathrm{m/s}$ 的速度反向飞出，头与球的接触时间 $t = 0.05\ \mathrm{s}$。求足球受到的平均作用力。

\textbf{物理模型：} 动量定理，取初速度方向为正。

\textbf{解题过程：}

初动量：$p_1 = mv_0 = 0.5 \times 10 = 5\ \mathrm{kg \cdot m/s}$
末动量：$p_2 = m(-v) = 0.5 \times (-8) = -4\ \mathrm{kg \cdot m/s}$
动量变化：$\Delta p = p_2 - p_1 = -4 - 5 = -9\ \mathrm{kg \cdot m/s}$

由动量定理（这里 $F$ 表示足球所受平均合外力）：
\[
F_{\text{合}} t = \Delta p,\qquad F_{\text{合}} \times 0.05 = -9
\]
\[
F_{\text{合}} = -180\ \mathrm{N}
\]

负号表示平均作用力方向与初速度方向相反。

\textbf{方法总结：} 动量定理一定要考虑方向，在一条直线上用正负号表示。

\end{examplebox}

\begin{examplebox}{弹性碰撞}

\textbf{题意分析：} 质量为 $m_1 = 2\ \mathrm{kg}$ 的小球以 $v_1 = 3\ \mathrm{m/s}$ 的速度碰撞静止的 $m_2 = 1\ \mathrm{kg}$ 小球，发生弹性碰撞。求碰后两球的速度。

\textbf{物理模型：} 弹性碰撞，动量守恒 + 动能守恒。

\textbf{解题过程：}

动量守恒：
\[
2 \times 3 + 0 = 2 v_1' + 1 \times v_2'
\]
\[
6 = 2 v_1' + v_2'
\]

动能守恒：
\[
\frac12 \times 2 \times 3^2 = \frac12 \times 2 \times v_1'^2 + \frac12 \times 1 \times v_2'^2
\]
\[
9 = v_1'^2 + 0.5 v_2'^2
\]

解方程组（或用公式 $v_1' = \frac{m_1-m_2}{m_1+m_2}v_1$）：
\[
v_1' = \frac{2-1}{2+1} \times 3 = 1\ \mathrm{m/s},\qquad
v_2' = \frac{2 \times 2}{2+1} \times 3 = 4\ \mathrm{m/s}
\]

\textbf{方法总结：} 弹性碰撞中，$m_1$ 碰后的速度公式可以直接用——两个极端情况：$m_1 = m_2$ 时速度交换，$m_1 \gg m_2$ 时 $m_1$ 几乎不变。

\end{examplebox}

\begin{examplebox}{完全非弹性碰撞——子弹打木块}

\textbf{题意分析：} 质量为 $m = 10\ \mathrm{g}$ 的子弹以 $v_0 = 400\ \mathrm{m/s}$ 射入质量为 $M = 0.99\ \mathrm{kg}$ 的静止木块并留在其中，$g = 10\ \mathrm{m/s^2}$。求：
\begin{enumerate}
  \item 子弹和木块的共同速度。
  \item 系统损失的动能。
  \item 若木块在粗糙水平面上，$\mu = 0.2$，求滑行距离。
\end{enumerate}

\textbf{物理模型：} 完全非弹性碰撞 + 动能定理。

\textbf{解题过程：}

\begin{enumerate}
  \item 动量守恒：
  \[
  m v_0 = (m + M) v',\qquad 0.01 \times 400 = 1 \times v'
  \]
  \[
  v' = 4\ \mathrm{m/s}
  \]
  
  \item 损失动能：
  \[
  \Delta E_k = \frac12 m v_0^2 - \frac12 (m+M) v'^2
  \]
  \[
  = \frac12 \times 0.01 \times 400^2 - \frac12 \times 1 \times 4^2
  \]
  \[
  = 800 - 8 = 792\ \mathrm{J}
  \]
  
  \item 木块滑行（动能定理）：
  \[
  -\mu (m+M) g x = 0 - \frac12 (m+M) v'^2
  \]
  \[
  x = \frac{v'^2}{2\mu g} = \frac{16}{2 \times 0.2 \times 10} = 4\ \mathrm{m}
  \]
\end{enumerate}

\textbf{方法总结：}
\begin{enumerate}
  \item 子弹打木块是典型的完全非弹性碰撞，动量守恒但动能损失很大。
  \item 损失的能量转化为内能（子弹和木块摩擦生热）。
  \item 后续运动用动能定理或牛顿定律处理。
\end{enumerate}

\end{examplebox}

\section*{七、变式训练}

\begin{enumerate}
  \item 质量为 $m = 60\ \mathrm{kg}$ 的人以 $v_0 = 5\ \mathrm{m/s}$ 的速度跳上静止在光滑水平面上的 $M = 120\ \mathrm{kg}$ 的小车。求人和小车的共同速度。若人与车之间的摩擦因数为 $\mu = 0.3$，求人相对车的滑行距离。
  
  \item $m_1 = 4\ \mathrm{kg}$ 的小球以 $v_1 = 2\ \mathrm{m/s}$ 正面碰撞静止的 $m_2 = 2\ \mathrm{kg}$ 小球，碰后 $m_1$ 以 $v_1' = -0.5\ \mathrm{m/s}$（反向弹回）。判断碰撞类型并求 $v_2'$。
  
  \item 质量为 $M = 150\ \mathrm{kg}$ 的船上站着一个质量为 $m = 60\ \mathrm{kg}$ 的人，船长 $L = 5\ \mathrm{m}$，船静止在水面上（阻力不计）。人从船头走到船尾，求船相对于岸移动的距离。
\end{enumerate}

\section*{八、易错点}

\begin{mistakebox}
\begin{enumerate}
  \item \textbf{动量守恒中忽略方向：} 动量是矢量，必须规定正方向。速度方向与正方向相反时要加负号。
  
  \item \textbf{动量定理中 $F_{\text{合}}t = \Delta p$ 的 $F_{\text{合}}$ 是合力：} 不是某个单独的力。例如缓冲问题中，$F_{\text{合}}$ 是安全气囊对人的平均作用力减去重力。
  
  \item \textbf{误以为碰撞中动能一定守恒：} 只有弹性碰撞动能守恒。完全非弹性碰撞动能损失最大。
  
  \item \textbf{系统选择错误：} 动量守恒的前提是系统合外力为零。如果把地球也算进系统，重力就是内力了——但高中阶段一般不这么处理。
  
  \item \textbf{弹性碰撞和完全非弹性碰撞公式搞混：} 弹性碰撞碰后分开、速度不同；完全非弹性碰撞碰后粘在一起、速度相同。
\end{enumerate}
\end{mistakebox}

\section*{九、竞赛入门补充}

\begin{competitionbox}
\textbf{恢复系数}

恢复系数 $e$ 描述碰撞中动能的保持程度：
\[
e = \frac{v_2' - v_1'}{v_1 - v_2}
\]

\begin{itemize}
  \item $e = 1$：弹性碰撞（动能守恒）。
  \item $e = 0$：完全非弹性碰撞（碰后共速）。
  \item $0 < e < 1$：非弹性碰撞。
\end{itemize}

\textbf{例题：} 一个小球从 $h_1$ 高处自由落下，与地面碰撞后弹起 $h_2$ 高（$h_2 < h_1$）。求恢复系数。

\textbf{解：} 碰地前速度 $v_1 = \sqrt{2gh_1}$（向下），碰后速度 $v_1' = \sqrt{2gh_2}$（向上）。地面碰前速度 $v_2=0$，碰后 $v_2'=0$。

\[
e = \frac{v_2' - v_1'}{v_1 - v_2} = \frac{0 - (-\sqrt{2gh_2})}{\sqrt{2gh_1} - 0} = \sqrt{\frac{h_2}{h_1}}
\]

\textbf{竞赛小贴士：} 恢复系数结合动量守恒，可以完全描述一维两体碰撞——两个方程两个未知数，总能解。
\end{competitionbox}

\section*{十、今日小结}

\begin{enumerate}
  \item 动量 $p = mv$，冲量 $I = Ft$，动量定理 $F_{\text{合}} t = \Delta p$。
  \item 动量守恒条件：系统合外力为零（碰撞中可近似）。
  \item 弹性碰撞：动量守恒 $+$ 动能守恒。
  \item 完全非弹性碰撞：动量守恒，碰后共速，动能损失最大。
  \item 反冲/爆炸：初动量为零，各部分动量矢量和为零。
\end{enumerate}
